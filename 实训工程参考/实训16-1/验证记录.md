## 五、与教材/参考工程的差异

| 位置 | 差异 | 原因 |
| --- | --- | --- |
| 登录请求 | 教材 16.2 示例用 `requests.post`；本工程用 `api.post("/users/login")` | 封装后只保留一个请求入口；对登录的 401 单独提示「用户名或密码错误」 |
| 指标区 | 教材 16.4 未要求指标；本工程保留「单位总数」「本页显示」 | 与 15-1 页面连续；总数直接取接口 `total` |
| 空态验证 | 教材用业务空结果；本工程用「搜索不存在的名称」制造空结果 | 不删种子数据，更接近真实使用 |
| 401 触发 | 教材示例用受保护接口；本工程用写接口触发 | `GET /departments` 按契约是公开接口，无效令牌仍可读 |
| 翻页 | 只取第 1 页，每页 10 条，无翻页 UI | 本章聚焦取数与三态；翻页与多页导航在 17-1 |
| 15-1 的搜索/筛选 | 名称搜索保留，改为后端 `full_name` 查询参数；「只看有地址」未保留 | 搜索是 15-1 已有功能，用查询参数接回；地址筛选本章不做 |
| 表格宽度 | 用 `width="stretch"` | 当前 Streamlit 推荐写法 |
