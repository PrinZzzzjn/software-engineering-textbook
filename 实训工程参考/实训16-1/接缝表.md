## 三、下游：16-1 → 17-1

| 位置 | 16-1 现状 | 17-1 处理 |
| --- | --- | --- |
| `app.py` | 单文件，含登录门禁与单位页 | 拆成入口 + `pages/` 多页 |
| `_render_login` | 定义在 `app.py` | 迁到 `auth.py`，提供 `render_login` / `require_login` |
| 登录守卫 | `if "access_token" not in st.session_state` | 改为每页调用 `auth.require_login()` |
| 表格配置 | 写在页面里 | 抽到 `components/table.py::render_table` |
| 分页 | 固定第 1 页，每页 10 条 | `session_state` 保存 `page/page_size`，用 `pagination_bar` 翻页 |
| 指标 | 总数、本页条数 | 保留，按页刷新 |
| `config.py` / `api_client.py` | 已成型 | 原样复用，不改接口 |
| 三态 | spinner / info / error | 保留；多页时补 403 提示 |
| 错误处理 | 页面捕获 `ApiError` | 保留；可抽公共提示函数 |

17-1 不得依赖：

- `app.py::_render_login` 这个函数名与位置；
- 固定 `PAGE_SIZE = 10` 且不可翻页的假设；
- 页面内联的表格列配置结构。

## 四、接口契约对齐

事实源：`实训工程参考/_shared/接口契约清单.md` 与 13-1 `/docs`。

| 接口 | 方法 | 认证 | 本工程用法 | 失败处理 |
| --- | --- | --- | --- | --- |
| `/health` | GET | 否 | 侧边栏连通性检查 | 连接错误 `ApiError(0)` |
| `/users/login` | POST | 否 | 登录，取 `access_token` 与 `user` | 401 提示账号密码错误 |
| `/departments` | GET | 否 | `page=1&page_size=10`，取 `items/total` | 404/连接错误显示 error |
| `/departments` | POST | admin | 新增，成功 201 | 400/401/422 显示 detail |

字段：`dept_code`（1–20，唯一）、`full_name`（1–100）、`address`（≤500，可空）。前端不改字段名，不传后端未声明的排序参数。

## 五、不可越过的边界

- 本章不引入 `auth.py`、`components/`、`pages/`，保持单页。
- 不做编辑、删除、翻页 UI；
- 不把令牌写进日志或页面文本；
- 不改接口路径、字段与状态码；
- 不改教材正文；差异记录在 `验证记录.md`。
