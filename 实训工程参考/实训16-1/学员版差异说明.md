# 实训 16-1 学员版差异说明

> 教师版 = `项目/` 完整完成态；学员版 = `starter/`（15-1 完成态）+ 教材五步。

## 一、起点（可直接发给学员）

`starter/` 包含：

```text
app.py            # 15-1 完成态：12 条假数据、指标、表格、筛选、新增
requirements.txt  # streamlit、pandas、requests
README.md
起点说明.md
```

起点**不含**：`config.py`、`api_client.py`、登录表单、接口调用、三态、`verify_app.py`。

## 二、教师版比学员版多什么

| 内容 | 教师版 | 学员版 |
| --- | --- | --- |
| 请求层 | `config.py` + `api_client.py` | 由学员完成 |
| 登录 | 完整登录门禁与错误提示 | 由学员完成 |
| 数据源 | 真实 `GET/POST /departments` | 起点仍是 12 条假数据 |
| 三态 | spinner / info / error + 401 回登录 | 由学员完成 |
| 自测 | `verify_app.py` 27 项 | 不发放；只给三条手工路径 |
| 排错记录 | `联调排错记录.md` 三次实验 | 只给记录模板 |
| 文档 | README、分步指南、验证记录、难度评分 | 只给运行说明与阶段任务单 |

## 三、发放时的具体做法

1. 复制 `starter/` 到学员目录，保留 `起点说明.md`。
2. 不发放 `项目/verify_app.py`；教师在本机对临时库运行。
3. 可发放 `分步实现指南.md` 的「阶段目标 + 验收」两列，删除代码块。
4. 不发放 `验证记录.md`、`难度评分.md`、本文件（含实测结论与通过线）。
5. 课堂时间不足时，允许先不做侧边栏用户信息与健康检查；四统一、登录、三态不可省。

## 四、学员成果的最低检查

| 检查 | 通过标准 |
| --- | --- |
| 请求四要素 | 能指出 URL、方法、参数、请求头，并与 `/docs` 对照 |
| 客户端 | 页面无完整 URL；地址、超时、请求头、错误四处收拢 |
| 登录 | 令牌进 `session_state`；错误密码有可读提示 |
| 列表 | 先取 `items`；表格字段与契约逐字一致 |
| 三态 | 加载、空、错误都有反馈；空态不是 error |
| 错误处理 | 400/401/422 均有可读提示；422 不是字典列表 |
| 排错 | 能按「状态码 → detail → `/docs` → 代码」复述一次 |

## 五、可选裁剪

- 课时不足：去掉指标区与侧边栏健康检查，保留登录、列表、新增、三态。
- 无真实后端：可用教师提供的只读 Mock 服务，但仍按同一契约与状态码。
- 课后扩展中的「器材列表」可作为补考或加分项。
- CSV 导出与「只看有地址」可暂时移除；名称搜索建议保留，并改为 `full_name` 查询参数。
