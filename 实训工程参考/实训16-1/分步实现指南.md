| 要素 | 写法 | 本实训取值 |
| --- | --- | --- |
| 地址 | `BASE_URL + 路径` | `http://127.0.0.1:8000` + `/health` |
| 方法 | `requests.get/post` | 查用 GET，登录与新增用 POST |
| 参数 | `params=` / `json=` | 分页用 `params`，请求体用 `json` |
| 请求头 | `headers={"Authorization": ...}` | 登录后带 `Bearer <token>` |

`/health` 是服务级健康检查，不属于业务模块；业务路径直接挂在根下，例如 `/departments`，没有 `/api/v1`。

## 2. 接登录（约 40 分钟）

### 2.1 未登录只渲染登录表单

```python
if "access_token" not in st.session_state:
    _render_login()

```

`st.stop()` 阻止未登录时继续执行后面的列表请求。

### 2.2 登录并把令牌放进 session_state

```python
def _render_login() -> None:
    st.title("🗂️ 执勤电子年鉴")
    st.caption("请使用系统账号登录（演示账号 admin / admin123）")

    notice = st.session_state.pop("login_notice", None)
    if notice:
        st.warning(notice)

    with st.form("login_form"):
        username = st.text_input("用户名", value="admin", key="login_username")
        password = st.text_input("密码", type="password", key="login_password")
        submitted = st.form_submit_button("登录", type="primary", key="login_submit")

    if not submitted:
        return
    if not username or not password:
        st.error("请输入用户名和密码")
        return

    try:
        data = api.post(
            "/users/login",
            json={"username": username, "password": password},
        )
    except api.ApiError as exc:
        # 这里的 401 是账号或密码错误，不是令牌过期
        st.error("用户名或密码错误" if exc.status_code == 401 else exc.detail)
        return

    st.session_state["access_token"] = data["access_token"]
    st.session_state["current_user"] = data.get("user", {})
    st.rerun()
```

三个要点：

- 密码框必须 `type="password"`；
- 令牌不能放在普通变量里，Streamlit 每次交互都会重跑脚本；
- 登录成功先写 `session_state`，再 `st.rerun()`，让页面带着登录态重新渲染。

**验收**：正确账号进入单位页；错误密码出现可读提示；刷新浏览器后需要重新登录（令牌只在会话内）。

### 3.2 `api_client.py`：四个统一

```python
import requests
import streamlit as st

from config import API_BASE_URL, API_PREFIX, REQUEST_TIMEOUT


class ApiError(Exception):
    def __init__(self, status_code: int, detail: str):
        self.status_code = status_code
        self.detail = detail
        super().__init__(detail)


def _url(path: str) -> str:
    return f"{API_BASE_URL}{API_PREFIX}{path}"


def _headers() -> dict:
    token = st.session_state.get("access_token")
    return {"Authorization": f"Bearer {token}"} if token else {}


def _request(method: str, path: str, **kwargs):
    try:
        resp = requests.request(
            method,
            _url(path),
            headers=_headers(),
            timeout=REQUEST_TIMEOUT,
            **kwargs,
        )
    except requests.RequestException as exc:
        raise ApiError(0, f"无法连接后端服务：{exc}") from exc

    if resp.status_code == 401:
        st.session_state.pop("access_token", None)
        raise ApiError(401, "登录已过期，请重新登录")

    if not resp.ok:
        try:
            detail = resp.json().get("detail", resp.text)
        except ValueError:
            detail = resp.text
        if isinstance(detail, list):
            detail = "；".join(str(item.get("msg", item)) for item in detail)
        raise ApiError(resp.status_code, str(detail))

    return resp.json() if resp.content else None


def get(path: str, params: dict | None = None):
    return _request("GET", path, params=params)


def post(path: str, json: dict | None = None):
    return _request("POST", path, json=json)


def put(path: str, json: dict | None = None):
    return _request("PUT", path, json=json)


def delete(path: str):
    return _request("DELETE", path)
```

四个统一：

| 统一项 | 实现 | 目的 |
| --- | --- | --- |
| 地址 | `config.API_BASE_URL` + `_url` | 换端口只改一处 |
| 请求头 | `_headers` | 自动带令牌（令牌注入） |
| 超时 | `REQUEST_TIMEOUT` | 请求不会无限挂起 |
| 错误 | `ApiError` | 页面只捕获一种异常 |

两条易错结论：401 要清除登录态；422 的 `detail` 是列表，显示前要压平。

**验收**：页面里不再出现完整 URL；所有请求都经过 `api.get` / `api.post`。

再发请求：

```python
try:
    with st.spinner("正在加载单位列表..."):
        data = api.get("/departments", params=params)
except api.ApiError as exc:
    if exc.status_code == 401:
        # 令牌过期：清除登录态，重跑后回到登录页并提示
        st.session_state["login_notice"] = exc.detail
```

## 5. 排错与自测（约 15 分钟）

### 5.1 故意制造一次 404

把 `config.py` 的 `API_PREFIX` 临时改成 `"/api/v1"`，页面会显示 `Not Found`。按顺序记录：

| 顺序 | 看到什么 | 结论 |
| --- | --- | --- |
| 状态码 | 404 | 地址或资源不存在 |
| detail | `Not Found` | 后端没有这个路径，不是令牌问题 |
| `/docs` | 业务路径是 `/departments` | 不该有版本前缀 |
| 代码 | `API_PREFIX` 被改 | 恢复为空字符串 |

### 5.2 再制造一次 401

登录后把 `session_state["access_token"]` 改成 `invalid-token`，再提交新增：

- 后端返回 401，detail 为「令牌无效」；
- `api_client` 清除令牌并抛出「登录已过期，请重新登录」；
- 页面写 `login_notice` 后重跑，回到登录页并显示 warning。

> 注意：`GET /departments` 是公开接口，无效令牌仍能读列表；401 主要出现在写接口。

## 常见错误对照

| 报错/现象 | 原因 | 处理 |
| --- | --- | --- |
| 连不上后端 | 后端没启动或地址/端口错 | 先访问 `/health` |
| 404 | 多写 `/api/v1`、路径拼写错、尾斜杠 | 对照 `/docs` |
| 401 但列表正常 | 列表公开，写接口才要管理员 | 用写接口验证令牌 |
| 422 页面显示一串字典 | 没压平 `detail` 列表 | 在 `_request` 里拼成一句话 |
| 表格有行无值 | 字段名不一致或没取 `items` | 逐字核对契约 |
| 空数据显示成报错 | 把 `items=[]` 当失败 | 用 `st.info` 而不是 `st.error` |
| 新增后列表没变 | 成功后没重跑 | flash + `st.rerun()` |
| 登录后立刻回登录页 | 令牌没进 `session_state` 或被 401 清除 | 检查登录写入与 401 分支 |
| 页面白屏 | 未捕获异常 | 页面只捕获 `ApiError`，错误后 `st.stop()` |
