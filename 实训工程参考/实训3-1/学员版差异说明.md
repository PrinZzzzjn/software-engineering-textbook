# 实训 3-1 学员版差异说明

## 一、裁剪原则

学员版不是把教师版删几段，而是以教师完成态为事实源**重新扩写**：

- 保留教学必需的完整代码、逐行解释、命令与检查点；
- 删除教师自动测试、验证记录、难度评分、接缝表与课堂管理内容；
- 不提供教师测试的预期断言与测试代码，避免学生直接对答案；
- 每阶段先“自己做 3 分钟”再看完整代码，保留动手环节。

与旧版最大的区别：旧版要求删除 `分步实现指南.md`，学员只有任务与排错提示；新版把逐行讲解作为学员材料的核心，因为学员基础较弱，需要“看得懂每一行”再写。

## 二、学员包结构

```text
实训手册/实训3-1/
├── README.md               任务、4 学时安排、验收与提交
├── 分步实现指南.md         六段式语法讲解、完整代码、命令与检查点
├── 记录表.md               五种状态码必填 + 选填 + 幂等句式
└── starter/
    ├── main.py             空白起点，只含任务注释
    ├── warmup.py           字典/列表语法热身
    └── requirements.txt
```

## 三、保留、替换与删除清单

| 教师版内容 | 学员版处理 | 具体操作与理由 |
| --- | --- | --- |
| `项目/main.py` | **不直接发放** | 含完整答案；学员手册按阶段给出教学用完整代码，但要求先自己做再对照 |
| `项目/tests/test_api.py` | **删除** | 含全部预期断言，属于教师验收答案 |
| `项目/README.md`、`项目/requirements.txt` | **删除** | 学员只从 `starter/` 安装和启动，避免两套工程说明 |
| `分步实现指南.md`（教师版） | **扩写为学员版** | 保留代码与阶段，补语法卡片、逐行解释、操作细节、检查点；删除教师组织要点与答案索引 |
| `README.md`（教师版） | **替换** | 学员版保留任务、4 学时安排、验收、排错、提交、扩展；删除教材映射、教师步骤表、自动测试明细 |
| `starter/main.py` | **保留空白起点** | 只留任务注释，不预填 `FastAPI()`、`/health`、字典或端点 |
| `starter/warmup.py` | **新增** | 语法热身，不涉及端点 |
| `starter/requirements.txt` | **保留** | 只保留 `fastapi`、`uvicorn[standard]` |
| `验证记录.md` | **删除** | 教师实测输出，不进入学员包 |
| `难度评分.md` | **删除** | 仅用于教师课程设计 |
| `接缝表.md` | **删除** | 仅用于教师衔接相邻实训 |
| `学员版差异说明.md` | **删除** | 裁剪规则本身不进入学员包 |

## 四、发放前检查

- [ ] 学员包中不存在 `项目/`、教师测试、验证记录、难度评分、接缝表。
- [ ] `starter/main.py` 只有任务注释，没有可运行应用或答案。
- [ ] 学员手册的完整代码与 `实训工程参考/实训3-1/项目/main.py` 逐字一致。
- [ ] 记录表“实际状态码”与“结论”为空，等待真实请求后填写。
- [ ] 学员按 README 和分步指南能从空文件独立启动，不需要教师目录中的任何文件。
- [ ] 学员手册给出 `/docs` 空白时的 `/openapi.json` + `curl` 备用通道。
