# 实训 3-1 学员版差异说明

## 一、裁剪原则

学员版只保留 **starter、精简版 README、空白记录表**。学生应通过四个 TODO 独立完成五端点，不能从提交包中直接看到完成态代码、自动测试答案或教师实测结果。

## 二、删除、保留与替换清单

| 完整版内容 | 学员版处理 | 具体操作与理由 |
| --- | --- | --- |
| `starter/main.py` | **保留** | 原样保留内存字典、GET 列表和四个 TODO，不预填任何答案 |
| `starter/requirements.txt` | **保留** | 原样保留现有学员材料的依赖声明，不与教师完成态混用 |
| `README.md` | **替换** | 用学员精简版替换教师版；保留目标、边界、准备、90 分钟安排、六步任务、验收、排错、提交与扩展 |
| 状态码记录表 | **新增空白表** | 表头为“方法 / URL / 输入 / 预期状态码 / 实际状态码 / 结论”；不得预填实际状态码，附 100 字以内幂等性说明区域 |
| `项目/main.py` | **删除** | 这是教材代码 3-4-1 完整答案 |
| `项目/tests/test_api.py` | **删除** | 测试含全部预期响应与状态码，属于教师验收答案 |
| `项目/README.md`、`项目/requirements.txt` | **删除** | 学员只从 starter 安装和启动，避免同时出现两套工程说明 |
| `分步实现指南.md` | **删除** | 含各函数及完整文件答案；学员 README 只保留操作提示，不保留代码答案 |
| `验证记录.md` | **删除** | 含教师实测输出，不作为学生提交材料 |
| `难度评分.md` | **删除** | 仅用于教师课程设计 |
| `接缝表.md` | **删除** | 仅用于教师衔接相邻实训 |
| `学员版差异说明.md` | **删除** | 裁剪规则本身不进入学生包 |

## 三、学员精简版 README 应保留的内容

1. **任务信息**：名称、对应教材 3.2/3.4、2 学时、独立完成。
2. **学习目标**：五端点可调用；200、201、204、400、404 齐全；删除无正文；能解释幂等性。
3. **明确边界**：单文件、内存字典、当前手写检查为 400，422 只作后续比较。
4. **六步安排**：10 + 30 + 20 + 15 + 10 + 5 分钟，与教材一致。
5. **快速开始**：只指向 `starter/`，文档端口统一为 8000。
6. **排错提示**：可保留教材“现象 → 先查什么”，不能直接附完整函数。
7. **提交清单**：自己的 `main.py`、真实记录表、100 字以内幂等性说明。
8. **课后扩展**：分页参数、Pydantic 模型、编码重复规则与复习任务。

教师版中的教材映射、文件答案索引、自动测试明细、实测输出、难度分析与后续工程不兼容说明均不进入学员精简版。

## 四、学员包目标结构

```text
实训3-1/
├── README.md          学员精简版，无答案链接
├── 记录表.md          空白待填，含幂等性说明区域
└── starter/
    ├── main.py        原样保留 TODO
    └── requirements.txt
```

## 五、发放前检查

- [ ] 学员包中不存在 `项目/`、`分步实现指南.md` 或教师验证材料。
- [ ] starter 仍只有 GET 列表，四个 TODO 没有被答案替换。
- [ ] README 的相对链接均指向学员包内现存文件。
- [ ] 记录表“实际状态码”和“结论”为空，等待真实请求后填写。
- [ ] 学员按 README 能从 starter 独立启动，不需要教师目录中的任何文件。
