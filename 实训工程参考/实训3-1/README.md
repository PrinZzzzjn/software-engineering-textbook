# 实训 3-1：一个资源的四个 HTTP 方法（教师工程参考）

> 对应教材：第 3 章 3.2–3.4 与章末「◆ 实训 3-1」  
> 学时：4 学时，180 分钟  
> 用途：教师备课、课堂演示与验收。`项目/` 含完整答案，不直接发给学生；学生从 `starter/` 的空起点开始，按 `实训手册/实训3-1/` 的分步指南学习。

## 一、概览

本实训从一个空目录开始：先写出最小应用与 `/health`，再逐步补列表、详情、新增、修改、删除五个端点。每一步都能在 `/docs` 中验证，最后得到一个可用的单文件服务。

完成态的 `项目/main.py` 与教材 3.3.4 的代码 3-3-5、3-3-6 一致，另含最小应用一步练习用的 `/health`；内存字典保存数据，列表返回 `{items, total}`，新增返回 201，修改返回 200，删除返回 204 且无响应体；缺字段或编码重复返回 400，资源不存在返回 404。

## 三、边界

- 第 1 步的 `/health` 只用于练习最小应用，不属于五个资源端点。
- 只实现 `/departments` 集合路径及 `/departments/{dept_code}` 详情路径，不增加任何路由前缀。
- 只用单文件与内存字典；进程重启后恢复为 D001 一条记录，不写外部文件，不做持久化。
- 请求体使用 `data: dict`，字段检查写在函数入口；本阶段缺字段返回 400，不提前引入输入模型与 422。
- 不加分页、排序、过滤、`response_model`、额外字段或额外业务规则；这些内容留到后续实训。

## 四、准备

1. 教师与学生均应读完教材 3.1–3.4，能区分方法、URL、请求体与状态码。
2. 推荐 Python 3.12 或兼容版本，准备 pip、浏览器和 PowerShell。
3. 教师演示使用 `项目/`，学生练习只领取 `starter/` 与空白状态码记录表。
4. 运行依赖见 `项目/requirements.txt`；自动验证另需 `httpx`、`pytest`。
5. 虚拟环境应建在仓库之外，避免把环境目录混入提交。

## 八、快速开始

在 `项目/` 目录执行（课堂文档统一使用端口 8000）：

```powershell
python -m pip install -r requirements.txt
uvicorn main:app --port 8000
```

浏览器打开 `http://127.0.0.1:8000/docs`。另开 PowerShell，在同一目录执行自动验证：

```powershell
python -m pip install httpx pytest
python -m pytest tests/test_api.py
```

也可以从本实训根目录运行：

```powershell
python -m pytest 项目/tests/test_api.py
```

预期十一项测试全部通过。测试会重置内存数据，不影响下一次独立运行；若服务仍在运行，测试不会占用或改动其监听端口。

## 十、排错

| 现象 | 先查什么 | 处理方向 |
| --- | --- | --- |
| 启动报 `ModuleNotFoundError: fastapi` | 依赖是否安装、是否在正确环境 | 执行 `python -m pip install -r requirements.txt` |
| `Could not import module "main"` | 当前目录是否有 `main.py` | 进入文件所在目录再启动 |
| `/docs` 打不开 | 服务是否启动、端口是否被占用 | 检查启动命令与端口 |
| `/docs` 空白 | 内网是否拿不到 Swagger UI 的 CDN 资源 | 用 `/openapi.json` 或教师提供的本地 Swagger；空白不是学员代码错误 |
| `SyntaxError` | 引号、括号、冒号是否全角 | 切英文输入法，改成半角 |
| 命令照抄报错 | 课堂是 bash 还是 PowerShell | 本材料 bash 为主；PowerShell 用对照命令 |
| 所有接口 404 | 装饰器路径、请求方法、是否启动了正确目录的应用 | 对照五个装饰器，统一使用 `/departments` |
| 新增返回 307 | 集合 URL 末尾斜杠是否不一致 | 请求与装饰器统一写成 `/departments` |
| 新增仍返回 200 | `@app.post` 是否声明 `status_code=status.HTTP_201_CREATED` | 补装饰器参数并重启 |
| 删除返回 200 或带正文 | DELETE 装饰器与函数返回语句 | 声明 204，成功路径不返回内容 |
| 重复删除仍返回 200 | 删除前是否判断编码存在 | 不存在时抛出 `HTTPException(404)` |
| 修改后字段未变 | 请求体键名与代码读取键名 | 统一 `full_name`、`address` |
| 缺字段返回 500 | 是否直接使用不存在的字典键 | 使用 `data.get(...)` 并在函数入口检查 |
| 缺字段变成 422 | 是否提前换用了输入模型 | 本阶段恢复 `data: dict`；422 留作后续对照 |
| 测试提示缺少模块 | 当前 Python 环境是否安装了依赖 | 在同一环境安装运行依赖、`httpx`、`pytest` |

## 十一、提交

学生提交：

1. 可独立启动的 `main.py`；
2. 真实填写的状态码记录表：按 `实训手册/实训3-1/记录表.md` 的五行必填（200、201、204、400、404），其余选填；204 行同时记录响应体为空；
3. 100 字以内的幂等性说明，明确 GET、PUT、DELETE 幂等，POST 不幂等，并说明判断依据；可使用学员手册给的四句句式，但内容必须自己填。

教师验收时应重启学生应用，抽查“新增 → 修改 → 删除 → 重复删除”链路，不能只检查代码文本。`项目/`、`验证记录.md`、`难度评分.md` 和本参考中的其他教师材料不进入学生提交包。
