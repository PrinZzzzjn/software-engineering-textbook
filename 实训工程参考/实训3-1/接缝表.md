# 实训 3-1 接缝表

## 一、前置接缝：无上一实训

第 2 章没有实训，因此本实训没有“上一实训产物”依赖，起点定义为：**零基础 + 已读教材 3.1–3.4 + 教材 3.4 示例**。`starter/` 自包含，学生不需要从其他实训复制文件、接口或数据。

| 对照项 | 上一实训 | 本实训 |
| --- | --- | --- |
| 起点 | 无 | `starter/main.py` 提供 FastAPI 应用、D001 内存字典、GET 列表及四个 TODO |
| 新增文件 | 不适用 | 学生补全自己的 `main.py`，新建状态码记录表与幂等性说明 |
| 修改文件 | 不适用 | 在 `starter/main.py` 中补详情、新增、修改、删除及所需导入 |
| 删除文件 | 不适用 | 无 |
| 不兼容点 | 不适用 | 无历史接口需要兼容；路径从起点起固定为 `/departments` |

教师只需确认学生能启动 starter 并看到列表，不要求先完成其他工程。

## 二、本实训输出契约

| 类别 | 固定输出 |
| --- | --- |
| 文件 | 单文件 `main.py`，五个端点均在同一文件 |
| 数据 | `DEPARTMENTS` 内存字典，初始只有 D001；重启恢复初始值 |
| 请求体 | `data: dict`，函数内手写字段检查 |
| 路由 | `/departments`、`/departments/{dept_code}`，无额外前缀 |
| 列表 | 200，`{items, total}`，无分页参数 |
| 写操作 | POST 201，PUT 200，DELETE 204 且无正文 |
| 失败 | 缺字段或重复编码 400，资源不存在 404；本阶段没有 422 |

## 三、到下一实训 4-1 的演进

下一实训仍以 department 为示例，但从“能写出端点”推进到“能划分接口与模块职责”。4-1 自带起点，本实训产物可独立提交，不要求学生携带同一文件续写。

| 维度 | 实训 3-1 | 实训 4-1 | 教师衔接提示 |
| --- | --- | --- | --- |
| 代码组织 | 单文件 `main.py` | `app/modules/department/` 下六文件：`controller.py`、`service.py`、`crud.py`、`model.py`、`schema.py`、`param.py`，由应用入口登记路由 | 先指出当前五函数职责，再演示职责如何搬到六文件 |
| 请求数据 | 手写 `data: dict` 与 `data.get(...)` | Pydantic 输入模型与字段声明 | 字典仍可用于本阶段内存保存，变化重点是请求与输出模型 |
| 输入失败 | 缺字段由函数返回 400 | 字段缺失、类型或约束错误由框架返回 422 | 400 不再作为缺字段的正式口径；重复编码仍为 400 |
| 列表查询 | 无查询参数，返回全部记录 | 引入 `page`、`page_size` | 同一 URL 的可用查询参数发生变化 |
| 输出约束 | 函数直接返回字典，未声明 `response_model` | 使用输出模型与 `response_model` | OpenAPI 文档和响应字段约束更明确 |
| 保留行为 | `/departments`、五端点、`{items, total}`、201/204、重复 400、不存在 404 | 保持这些核心契约 | 重构不能把路径改回单数或改变删除正文 |

## 四、3-1 → 4-1 不兼容点

1. **新增 422**：3-1 的缺字段请求得到 400；4-1 使用 Pydantic 后，同类请求在进入函数前得到 422。沿用 3-1 的状态码记录时必须更新预期。
2. **列表出现分页参数**：3-1 的 `GET /departments` 没有 `page`、`page_size`；4-1 引入这两个参数及相应约束，列表不再等同于“无条件返回全部”。
3. **引入 `response_model`**：3-1 直接返回字典；4-1 由输出模型约束响应字段与文档，不能再假设请求体或返回体可任意携带字段。
4. **导入与启动结构变化**：3-1 的全部函数位于根目录 `main.py`；4-1 的处理函数移入模块。不能只复制 3-1 的某个函数就期待六文件工程自动生效，必须同时检查模块导入与路由登记。

## 五、交接检查

- [ ] 学生能说明五端点为何是“四个方法、五个端点”。
- [ ] 学生能区分手写检查产生的 400 与后续模型校验产生的 422。
- [ ] 学生能保留 `/departments` 路径、列表 `items/total` 和 DELETE 204 无正文。
- [ ] 进入 4-1 前，教师明确提示分页参数、`response_model` 与六文件职责是新增内容，而非 3-1 漏做项。
