# 实训 13-1 学员版差异说明

> 教师版 = `项目/` 完整完成态；学员版 = `starter/` 起点 + 教材步骤。本文件列出裁剪点，避免把答案随起点发出。

## 一、起点（可直接发给学员）

`starter/` 是 **12-1 完成态**，包含：

- 五个业务模块、analytics、三条执勤规则、幂等 seed；
- `tests/` 5 条接口测试；
- 项目 README 与依赖文件。

`starter/` **不含**：

```text
app/core/pagination.py
app/core/database.py 的 commit_or_rollback
app/modules/duty_record/service.py 的 create_duty_records
五个 *ListOut 与 response_model
tests/test_integration.py
tests/test_quality.py
问题清单.md / 联调记录.md / 交付清单.md / 已知问题.md
```

以上正是 13-1 的改造与交付内容。

## 二、教师版比学员版多什么

| 内容 | 教师版 | 学员版 |
| --- | --- | --- |
| 五类质量改造 | 已完成，逐文件可对照 | 由学员完成 |
| 12 步联调用例 | `tests/test_integration.py` 固定 12 条 | 只给联调记录表模板，用例由学员自写 |
| 质量用例 | `tests/test_quality.py` 10 条 | **不发放**（含验收答案） |
| 四份交付文档 | 已填写的完整版本 | 只发空白模板 |
| 问题清单 | 12 条，位置到函数 | 只发五类表头 |
| 已知问题 | 6 条，已分级 | 只发三级表头 |

## 三、发放时的具体做法

1. 复制 `starter/` 到学员目录，删除其中 12-1 的 `README.md`（避免与 13-1 任务说明混淆），保留 `起点说明.md`。
2. 不发放 `项目/tests/test_quality.py`；`test_integration.py` 可作为验收工具保留，或改为手工联调记录表。
3. 四份文档只发模板：`问题清单.md`、`联调记录.md`、`交付清单.md`、`已知问题.md` 的表头与填表说明。
4. 教师版 `项目/` 仅在课后或评讲时开放；开放前可删去 `test_quality.py` 与四份答案文档。
5. 不发放本文件与 `验证记录.md`（含具体实测数字与差异结论）。

## 四、学员成果的最低检查

| 检查 | 通过标准 |
| --- | --- |
| 基线 | 改造前 `python -m pytest -q` 为 5 passed，且记录在交付清单 |
| 回归 | 改造后 12-1 的 5 条断言未被修改且仍通过 |
| 五类 | 问题清单五类各至少一条，位置到文件与函数 |
| 安全 | 响应无 `password_hash`；401/403/422 各有一条用例或实测记录 |
| 事务 | 批量失败后无半批数据；异常路径有回滚 |
| 联调 | 12 步全部有「实际」与「结论」 |
| 交付 | 五项齐全；已知问题不写「无」 |
| 卫生 | 无 `duty.db`、`venv/`、`__pycache__`、`.pytest_cache` |

## 五、可选裁剪

- 课时不足时，批量写入与批内重叠可降为选做；其余必做项不变。
- 无 pytest 环境时，12 步联调可改为手工表格，但必须留下请求与响应证据。
- 前端实训（15-1 起）只依赖本实训的接口契约，不依赖四份文档；文档可延后批改。
