## 三、边界与不变量

### 3.1 五类清单与本工程的落点

| 类别 | 教材常见问题 | 本工程现状 | 13-1 动作 |
| --- | --- | --- | --- |
| 安全 | 密码明文、响应带密码、管理接口无权限、输入不校验 | 12-1 已哈希、已挂管理员依赖、已用 `Field` 校验 | 列表补输出模型；补 401/403/422 断言 |
| 错误 | 400/500 混用、全部 500 | 状态码分工已正确 | 五档状态码各固化为一条用例 |
| 重复 | 单位与人员分页代码一样 | 五个模块各写一遍 | 抽到 `paginate` |
| 性能 | 列表不分页、循环里查库 | 列表已分页；重叠查询取回全部冲突 | 改 `.first()`；统计聚合记入已知问题 |
| 规范 | 字段名与结构不一致 | 列表结构一致，但有死代码 | 统一列表输出模型；检查其它未使用代码 |

### 3.2 事务边界

- 一个业务动作一个事务：先校验，最后调用一次 `commit_or_rollback`。
- 提交失败先 `rollback()` 再继续抛出；不吞异常假装成功。
- `get_db` 在请求异常时也回滚，避免会话停在失败事务。
- 只读接口不提交事务。
- 批量写入 `create_duty_records`：逐条校验 → 批内重叠检查 → `add_all` → 一次提交；任何一条不通过都在写入前抛出。

### 3.3 联调顺序

登录 → 建普通用户 → 普通用户登录 → 验证 403 → 建单位 → 建人员（与哨位）→ 建执勤记录 → 验证重叠 400 → 查年度统计 → 查时段分布 → 无令牌 401 → 缺字段 422。逐步记录见 `项目/联调记录.md`。

### 3.4 契约对账

- 事实源是代码与 `/docs`；`_shared/接口契约清单.md` 是汇总，教材正文是教学说明。
- 本实训不新增、不修改端点，只给列表加输出模型；路径、字段、状态码不变。
- 发现文档与代码不一致时，改文档并记入已知问题，不回改教材。

### 3.5 其他不变量

- 12-1 的 5 条测试逐字保留，不得为了让新用例通过而改旧断言。
- 认证仍为 PBKDF2 盐哈希 + `TOKEN_STORE`，不引入 JWT、passlib、python-jose。
- 应用版本从 0.3.0 升到 0.4.0；运行依赖不变。
- 不新增表、不加索引、不建汇总表；性能只要求识别。
- 教材明确「不必自定义异常类，也不必注册全局处理器」，本工程遵守。

## 六、操作步骤（最低必做）

1. **跑基线（10 分钟）**：在 `项目/` 记录改动前的通过数。起点应为 `5 passed`；环境未激活会报 `ModuleNotFoundError`。
2. **问题定位（15 分钟）**：`git grep -n "password"`、`git grep -n "commit"`、对比五个 `crud.list_page`；每类至少写一条进问题清单，先不改。
3. **修 3 个代表性问题（25 分钟）**：从安全、错误、重复、性能、规范五类里选 3 个，按“问题 → 修复动作 → 验证方式”做完并重跑相关测试。
4. **8 步主链路联调（25 分钟）**：登录 → 建单位 → 建人员 → 建记录 → 重叠 400 → 年度统计 → 无令牌 401 → 缺字段 422；逐步记录期望与实际。
5. **交付清单与小结（10 分钟）**：补一页交付清单与已知问题；用两分钟说清“做了什么 / 能跑什么 / 还有什么问题”。
6. **提交（5 分钟）**：一次提交，信息说明改了什么；`git status` 干净。

> 五类全量修复、事务完整改造、12 步全链路、四份完整文档为课后扩展；课堂不要求全部完成。详细代码与命令见 [分步实现指南.md](分步实现指南.md)。

## 十、常见问题与排错

| 现象 | 先查什么 |
| --- | --- |
| 测试全部失败 | 虚拟环境、依赖版本、是否在项目根目录运行 |
| `ModuleNotFoundError: No module named 'main'` | 在项目根目录用 `python -m pytest` |
| 401 与 403 混淆 | 认证依赖是否先执行、角色字段是否为 `admin` |
| 响应仍带 `password_hash` | 是否直接返回 ORM 对象、输出模型是否生效 |
| 批量失败后仍有数据 | `commit()` 是否在循环内、异常分支是否 `rollback()` |
| 普通用户能看管理数据 | 管理接口是否挂 `get_current_admin_user` |
| 建人员 422 | `dept_code` 字段名、单位是否存在 |
| 统计数字不符 | 年份参数、记录是否落在统计区间、口径按 `start_time` |
| 联调 404 | `include_router` 前缀、尾斜杠、路径参数 |
| 文档与代码不一致 | 以代码与 `/docs` 为准，列已知问题并同步文档 |
