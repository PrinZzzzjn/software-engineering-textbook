## 三、真实 Uvicorn 进程验证

工作目录：`实训工程参考/实训4-1/项目/`。启动命令：

```powershell
$env:PYTHONDONTWRITEBYTECODE="1"
& "$env:TEMP\train41-venv\Scripts\uvicorn.exe" main:app --port 8011
```

服务启动后，以 `Invoke-WebRequest` 真实访问 8011，并用 httpx 再核对 UTF-8 JSON 字段。关键请求为：

```powershell
Invoke-WebRequest -Uri "http://127.0.0.1:8011/docs" -UseBasicParsing
Invoke-WebRequest -Uri "http://127.0.0.1:8011/departments" -UseBasicParsing
# POST 以 UTF-8 字节提交 D8011 / 接口验证中队 / 实训楼
# DELETE 请求 http://127.0.0.1:8011/departments/D8011
```

| 方法 | URL | 输入 | 预期状态码 | 实际状态码与响应 | 结论 |
| --- | --- | --- | --- | ---: | --- |
| GET | `/docs` | 无 | 200 | 200；`Content-Type: text/html; charset=utf-8` | 一致 |
| GET | `/departments` | 新进程空表 | 200 | 200；`{"items":[],"total":0}` | 一致 |
| POST | `/departments` | `D8011`、接口验证中队、实训楼 | 201 | 201；httpx 复核 `Body matches payload: True` | 一致 |
| DELETE | `/departments/D8011` | 路径参数 D8011 | 204 | 204；响应正文 **0 字节** | 一致 |

httpx 复核的真实输出：

```text
GET /docs -> 200 ; Content-Type: text/html; charset=utf-8
GET /departments -> 200 ; Body: {"items":[],"total":0}
POST /departments -> 201 ; Body matches payload: True
DELETE /departments/D8011 -> 204 ; Body bytes: 0
```

首次 PowerShell 输出中的中文显示为乱码，是 Windows PowerShell 对无 BOM UTF-8 响应的显示解码问题；httpx 按 UTF-8 解析后，响应三个字段与请求完全相等，应用响应无字段错误。

验证后停止后台命令 `gahhtmwvky`，再检查监听端口：

```powershell
$listener = Get-NetTCPConnection -LocalPort 8011 -State Listen -ErrorAction SilentlyContinue
```

真实结果为 `Port 8011 listener stopped`，确认服务进程已关闭。
