# 综合实训 4-1 学员版差异说明

## 一、裁剪原则

学员版以教师完成态为事实源**重新扩写**，不是把教师版删几段：

- 保留教学必需的完整代码、逐行解释、命令与检查点；
- 删除教师自动测试、验证记录、难度评分与接缝表；
- 课堂统一使用单位示例，自选对象的完整改编转为课后；
- `starter/` 只留骨架与 TODO，不预填 crud、service、controller 的答案；
- 每阶段先“自己做 3 分钟”再看完整文件，保留动手环节。

## 三、完整版 → 学员版对照

| 文件/内容 | 处理 | 学员版状态与教学意图 |
| --- | --- | --- |
| `main.py` | **留 + 替换** | 保留 FastAPI 创建与 `include_router(..., prefix="")`；删去完成态可选 `/health`，学生聚焦模块装配 |
| `app/__init__.py`、`app/modules/__init__.py` | **留** | 空包标记直接可用，避免导入问题干扰主目标 |
| `department/__init__.py` | **留** | 空包标记直接可用 |
| `department/model.py` | **留 + 替换** | 保留三字段 dataclass；保留一条 D001 示例记录便于观察，阶段 2 要求改成空表 |
| `department/schema.py` | **留** | Create/Update/Out/Page 四模型与完成态一致，学生读懂并验证，不重复输入 |
| `department/param.py` | **留** | `DepartmentQueryParams` 与完成态一致，学生直接使用分页模型 |
| `department/crud.py` | **替换** | 五个函数签名保留；课堂 B 档只要求补 `list_all/create`，其余保留 `NotImplementedError` 供教师演示/课后补全，不写规则 |
| `department/service.py` | **删 + 替换** | 删除完成态 `HTTPException` 导入及规则实现；课堂 B 档只要求补 `list_departments/create_department`，其余保留 `NotImplementedError` |
| `department/controller.py` | **删 + 替换** | 删除五组装饰器和路由函数、删除 `Depends`/`status` 导入；保留 router 与 TODO 清单；课堂 B 档只登记 GET 列表与 POST 新增两个接口 |
| `tests/test_api.py` | **删** | 学员骨架不放完成态自动测试，避免答案泄露；教师用完整版测试验收 |
| `项目/README.md` | **不复制** | 学员按学员 README 和分步指南启动，完成态说明不混入骨架 |
| `requirements.txt` | **留原骨架版本** | 保留 fastapi、uvicorn[standard]、pydantic |
| 教师 `分步实现指南.md` | **扩写为学员版** | 保留代码与阶段，补语法卡片、逐行解释、操作细节、检查点；删除教师组织要点与验证细节 |
| 教师 `设计文档.md` | **替换为模板** | 单位示例 + 空格待填，学生补必填性、状态码与一条规则性失败 |
| 教师 `验证记录.md`、`难度评分.md`、`接缝表.md` | **删除** | 教师材料，不进入学员包 |

## 四、已修正的旧内容

| 原骨架内容 | 学员版修正 | 理由 |
| --- | --- | --- |
| controller 注释“教材 4.6 代码 4-6-7” | “教材 **4.5** 代码 **4-5-7**” | 当前教材六文件最小实现位于 4.5 |
| 根路由 `prefix="/api/v1"` | `prefix=""` | 教材 4.5 与本实训路径均为 `/departments` |
| 学员任务“自选业务对象” | 课堂统一单位，自选对象课后 | 降低课堂同时改编字段、路径和调用链的负担 |

## 五、发放与回收建议

1. 教师保留 `项目/`、`设计文档.md`、`验证记录.md`、`难度评分.md`、`接缝表.md`；学生领取 `实训手册/实训4-1/`。
2. 学生需补的核心是 crud、service、controller；课堂统一单位，课后可替换自选对象。
3. 骨架的 D001 数据仅用于起步观察，阶段 2 改成空表，保证每条验证可重复。
4. 学生提交时不包含教师测试答案、`__pycache__`、虚拟环境或临时文件。
5. 验收时比较职责与契约，不要求函数逐字相同；字段、路径、状态码和分层边界必须一致。
