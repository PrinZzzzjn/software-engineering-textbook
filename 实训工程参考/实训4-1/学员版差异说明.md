# 综合实训 4-1 学员版差异说明

学员版位于 `starter/`，从既有学生手册骨架复制后仅修正教材节号与路径前缀。目标是让学生补关键职责，而不是从零敲完所有文件，也不是拿到完成态答案。

## 完整版 → 学员版对照

| 文件/内容 | 处理 | 学员版状态与教学意图 |
| --- | --- | --- |
| `main.py` | **留 + 替换** | 保留 FastAPI 创建和 `include_router(..., prefix="")`；删去完成态可选 `/health`，学生聚焦模块装配 |
| `app/__init__.py`、`app/modules/__init__.py` | **留** | 空包标记直接可用，避免导入问题干扰主目标 |
| `department/__init__.py` | **留** | 空包标记直接可用 |
| `department/model.py` | **留 + 替换** | 保留三字段 dataclass；增加教学说明，并用一条 D01 示例记录替换完成态的空 `TABLE`，便于学生在 `/docs` 观察数据 |
| `department/schema.py` | **留** | Create/Update/Out/Page 四模型与完成态一致，学生不必重复输入已知 Pydantic 声明 |
| `department/param.py` | **留** | `DeptQuery` 与完成态一致，学生直接使用分页模型 |
| `department/crud.py` | **替换** | 五个函数签名保留，函数体替换为 `raise NotImplementedError(...)`；要求学生补纯存取，不写规则 |
| `department/service.py` | **删 + 替换** | 删除完成态 `HTTPException` 导入及规则实现，五个服务函数体替换为 `NotImplementedError`；由学生补 400/404 与分页 |
| `department/controller.py` | **删 + 替换** | 删除五组装饰器和路由函数、删除 `Depends`/`status` 导入；保留 router 与 TODO 清单，由学生登记五接口 |
| `tests/test_api.py` | **删** | 学员骨架不放完成态自动测试，避免答案泄露；教师用完整版测试验收 |
| `项目/README.md` | **不复制** | 学员按主 README 和分步指南启动，完成态说明不混入骨架 |
| `requirements.txt` | **留原骨架版本** | 保留 fastapi、uvicorn[standard]、pydantic；pydantic 虽由 FastAPI 带入，显式列出便于学生识别本课模型依赖 |

## 已修正的旧内容

| 原骨架内容 | 学员版修正 | 理由 |
| --- | --- | --- |
| controller 注释“教材 4.6 代码 4-6-7” | “教材 **4.5** 代码 **4-5-7**” | 当前教材六文件最小实现位于 4.5，旧引用过期 |
| 根路由 `prefix="/api/v1"` | `prefix=""` | 教材 4.5 与本实训路径均为 `/departments`，本阶段没有版本前缀 |

其余 TODO、骨架文件和一条示例数据均保持教学意图，没有将原学生目录改动；修改只发生在新交付的 `starter/` 副本。

## 发放与回收建议

1. 教师保留 `项目/`、`设计文档.md`、`验证记录.md`，学生只领取 `starter/` 与任务说明。
2. 学生需补的核心是 crud、service、controller；若替换自选对象，再同步调整 model/schema/param 和路径。
3. 骨架的 D01 数据仅用于起步观察，完成态与测试使用空表，保证每条用例可重复。
4. 学生提交时不包含教师测试答案、`__pycache__`、虚拟环境或临时文件。
5. 验收时可将学生补全的三个文件与完成态比较职责，不要求函数逐字相同，但字段、路径、状态码和分层契约必须一致。
