## 阶段 1 跑起来（20 分钟）

新建 `tests/conftest.py`。与教材代码 12-3-1 相同，只有开头三行是教师版增强：在导入 `main` 之前把数据库指向系统临时目录，测试结束删除，仓库不生成 `duty.db`（对应教材 12.4 的课后扩展「独立测试库」）。学员按教材可直接删掉这三行。

```python
"""测试夹具：client、admin_headers 与管理员种子。

对应教材 12.3 的代码 12-3-1。唯一的教师版增强：在导入 main 之前把
DATABASE_URL 指向系统临时目录，测试不碰开发库，也不在仓库生成 duty.db
（对应教材 12.4「独立测试库」的课后扩展）。
"""

import os
import shutil
import tempfile
from pathlib import Path

_TEST_DB_DIR = tempfile.mkdtemp(prefix="duty121-test-")
os.environ["DATABASE_URL"] = "sqlite:///" + str(Path(_TEST_DB_DIR) / "duty.db")

import pytest  # noqa: E402
from fastapi.testclient import TestClient  # noqa: E402

from app.core.database import SessionLocal, engine  # noqa: E402
from app.core.security import get_password_hash  # noqa: E402
from app.modules.user.model import User  # noqa: E402
from main import app  # noqa: E402


@pytest.fixture(scope="session", autouse=True)
def seed_admin():
    """在测试进程里确保管理员账号存在，供各登录用例共用。"""
    db = SessionLocal()
    try:
        if db.query(User).filter(User.username == "admin").first() is None:
            db.add(
                User(
                    username="admin",
                    password_hash=get_password_hash("admin123"),
                    role="admin",
                    is_active=1,
                )
            )
            db.commit()
    finally:
        db.close()


@pytest.fixture
def client():
    return TestClient(app)


@pytest.fixture
def admin_headers(client):
    resp = client.post(
        "/users/login", json={"username": "admin", "password": "admin123"}
    )
    token = resp.json()["access_token"]
    return {"Authorization": f"Bearer {token}"}


@pytest.fixture(scope="session", autouse=True)
def cleanup_test_database():
    """整轮测试结束后释放连接并删除临时库（教师版增强）。"""
    yield
    engine.dispose()
    shutil.rmtree(_TEST_DB_DIR, ignore_errors=True)
```

新建 `tests/test_auth.py`，先只写第一条：

```python
def test_login_success(client):
    resp = client.post(
        "/users/login", json={"username": "admin", "password": "admin123"}
    )
    assert resp.status_code == 200
    assert "access_token" in resp.json()
```

在项目根目录运行：

```powershell
python -m pytest -q
```

预期：

```text
.                                                                        [100%]
1 passed
```

做错会看到：`ModuleNotFoundError: No module named 'main'`——不在项目根目录运行；`401`——`seed_admin` 未执行，或测试进程里没有管理员账号。

把密码改成 `wrong` 再运行，会看到失败：

```text
>       assert resp.status_code == 200
E       assert 401 == 200
```

读法是「实际 == 期望」：实际 401、期望 200。密码错了本来就该 401，是测试写错了。改回 `admin123`，测试重新变绿。

## 阶段 3 单位与执勤测试（50 分钟）

新建 `tests/test_department.py`：

import uuid


def test_create_department_duplicate(client, admin_headers):

新建 `tests/test_duty.py`：

```python
import random
from datetime import date, timedelta


def test_duty_record_touching(client, admin_headers):
    """前一段 12:00 结束、后一段 12:00 开始，首尾相接不算冲突。"""
    day = date.today() + timedelta(days=random.randint(1000, 2000))
    base = {"personnel_certificate_number": "P001", "workstation_id": "W001"}
    first = {**base, "start_time": f"{day}T08:00:00", "end_time": f"{day}T12:00:00"}
    second = {**base, "start_time": f"{day}T12:00:00", "end_time": f"{day}T14:00:00"}
    assert (
        client.post("/duty-records", json=first, headers=admin_headers).status_code
        == 201
    )
    assert (
        client.post("/duty-records", json=second, headers=admin_headers).status_code
        == 201
    )


def test_duty_record_overlap(client, admin_headers):
    """例 12-1：08:00–12:00 之后再来 11:00–13:00，应返回 400。"""
    day = date.today() + timedelta(days=random.randint(1000, 2000))
    base = {"personnel_certificate_number": "P001", "workstation_id": "W001"}
    first = {**base, "start_time": f"{day}T08:00:00", "end_time": f"{day}T12:00:00"}
    second = {**base, "start_time": f"{day}T11:00:00", "end_time": f"{day}T13:00:00"}
    assert (
        client.post("/duty-records", json=first, headers=admin_headers).status_code
        == 201
    )
    assert (
        client.post("/duty-records", json=second, headers=admin_headers).status_code
        == 400
    )
```

运行两次：

```powershell
python -m pytest -q
python -m pytest -q
```

两次都应为：

```text
.....                                                                    [100%]
5 passed
```

做错会看到：单位测试第一次就 400——编码写死了或 uuid 没生效；执勤第一条 400——`P001` 或 `W001` 不存在（确认从项目根目录运行，`main.py` 的 seed 已执行）；第二条 400——日期不是每次不同，或重叠条件写错。

## 阶段 4 故意改坏并定位（30 分钟）

从下面三处选一处，按「改坏 → 运行对应文件 → 填五栏记录 → 恢复 → 重跑」执行。

```

```

### 改坏 2：单位查重条件写反

### 改坏 3：重叠判断多一个等号

打开 `app/modules/duty_record/crud.py` 的 `find_overlap()`，把

```python
DutyRecord.end_time > start_time,
```

DutyRecord.end_time >= start_time,

```powershell
python -m pytest -q tests/test_duty.py
```

实际输出：

```text
>       assert (
E       AssertionError: assert 400 == 201
FAILED tests/test_duty.py::test_duty_record_touching
1 failed, 1 passed
```

判断：首尾相接本是合法安排，却被判成冲突，是代码 bug。恢复 `>`。
