# 实训 12-1 学员版差异说明

> 完整版（本目录 `项目/`）→ 学员版（`starter/` + 课堂任务）的裁剪口径。
> 原则：保留「写测试、跑测试、读失败」的训练价值，去掉现成答案与教师验收材料。

## 一、直接保留

| 内容 | 说明 |
| --- | --- |
| 11-1 完成态全部业务代码 | 即 `starter/`：五个模块 + analytics + 三条规则，`app/` 与 `main.py` 原样 |
| `main.py` 的幂等 seed | `P001`、`W001`、`admin/admin123` 是执勤与登录测试的前置数据 |
| `README.md` 的测试分层表与状态码定位表 | 作为任务书模板 |
| 分步指南的阶段目标、运行命令与预期输出 | 保留；代码由学生自己写 |

## 二、必须删除或留空

| 位置 | 处理 | 原因 |
| --- | --- | --- |
| `tests/` 整个目录 | 不进入学员版 | 本章从零建立测试；直接给答案会失去「失败—定位—修复」的训练 |
| `tests/conftest.py` 的临时测试库三行 | 学员版不提供 | 教材把独立测试库列为课后扩展；课堂按教材用项目库 + uuid/随机日期 |
| 三份改坏后的实际输出 | 不进入任务书 | 学生要自己运行、自己读失败信息 |
| `验证记录.md`、`难度评分.md`、`接缝表.md`、`分步实现指南.md` | 不进入学员版 | 教师用 |

## 三、替换为课堂任务

| 完整版 | 学员版替换 |
| --- | --- |
| 完整 `tests/`（5 条） | 空目录 + 四条测试的名称、路径与期望表 |
| 已写好的 `conftest.py` | 只给夹具名与作用（`seed_admin`、`client`、`admin_headers`），代码由学生写 |
| 三处改坏的完整步骤 | 给出三个改坏点所在文件与函数，学生自己改、自己读输出 |
| 失败定位记录（教师版已填） | 空五栏表：现象、实际值、期望值、判断、处理 |

## 四、建议的学员版文件结构

```text
学员版/
├── 项目/                       # 11-1 完成态，无 tests/
│   ├── app/
│   ├── main.py
│   └── README.md
├── 任务书.md                   # 四条测试、三类路径、三处改坏点、五栏模板
└── 提交模板.md                 # tests/ 清单 + 定位记录 + 两次运行结果
```

## 五、评分建议

| 项 | 分值 | 判定 |
| --- | ---: | --- |
| 夹具可复用 | 15 | 客户端与令牌抽出 fixture；`seed_admin` 不重复建管理员 |
| 四条测试可运行 | 30 | 每次缺一条扣 8；连续两次不一致扣 10 |
| 三类路径覆盖 | 20 | 正常/边界/异常各至少一条，缺一类扣 7 |
| 数据可重复 | 10 | 编码或日期写死、第二次失败不得分 |
| 失败定位记录 | 15 | 五栏缺一栏扣 3；判断写成「改测试」而无依据扣 5 |
| 改坏能被抓到 | 10 | 至少一处改坏使对应文件变红，恢复后全绿 |

## 六、差异化

- **基础较弱**：只要求登录成功、登录失败、单位重复三条；执勤测试给出随机日期的两行；改坏只做登录一处。
- **学有余力**：补齐三处改坏；为统计模块加参数化用例；把临时测试库做成默认；把测试接入 pre-commit。
