# 实训 12-1 起点说明

本目录是 **实训 11-1 的完成态**，作为 12-1 的学员起点。它包含：

- department、personnel、user、workstation、duty_record 五个业务模块；
- analytics 统计模块（年度统计、时段分布）与三条执勤规则；
- `main.py` 的幂等 seed：D001/D002、P001/P002、W001/W002、4 条 2026 年执勤记录、`admin/admin123`。

起点中**没有** `tests/`。第 12 章从零建立：

```text
tests/conftest.py        # seed_admin、client、admin_headers
tests/test_auth.py       # 登录成功、登录失败
tests/test_department.py # 单位编码重复
tests/test_duty.py       # 首尾相接、时间重叠
```

这正是 12-1 要补的内容。此前各章的验证以手工请求与检查为主，测试只在教师验证脚本中存在，不随本起点发放。

使用方式：

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pip install pytest httpx
python -m uvicorn main:app --port 8000
```

先确认起点可跑：`GET /health` 200；`GET /duty-records` 的 `total` 为 4；`GET /workstations` 的 `total` 为 2；`admin/admin123` 登录 200。
