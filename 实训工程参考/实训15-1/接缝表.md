# 实训 15-1 接缝表

> 说明本实训与上游第 14 章骨架、下游 16-1 的接缝。

> **B 档口径（2026-11-23）**：课堂只做单位页搜索 + 指标 + 表格 + 空态；表单/新增课后。
## 一、上游：第 14 章 → 15-1

| 接缝 | 第 14 章提供的 | 15-1 的使用方式 | 是否改变 |
| --- | --- | --- | --- |
| 单页骨架 | `app.py`：`set_page_config`、标题、提示 | 保留页面配置与标题，补四块内容 | 只增不改 |
| 依赖 | `streamlit`、`pandas` | 原样使用 | 不变 |
| 状态 | 无 | 新增 `session_state.departments` 与 `flash_message` | 新增 |
| 数据 | 无 | 12 条假数据，字段按接口契约 | 新增 |

## 二、本实训的文件边界

| 文件 | 类型 | 说明 |
| --- | --- | --- |
| `项目/app.py` | 完成态 | 单文件，所有组件与状态 |
| `项目/verify_app.py` | 教师自测 | AppTest 驱动，不入学员起点 |
| `项目/requirements.txt` | 依赖 | `streamlit`、`pandas` |
| `项目/README.md` | 说明 | 组件表、状态顺序、自测与限制 |
| `starter/app.py` | 学员起点 | 只有标题与提示 |

## 三、下游：15-1 → 16-1

16-1 要把假数据换成真实接口，可保留与必须替换的部分：

| 位置 | 15-1 现状 | 16-1 处理 |
| --- | --- | --- |
| `SEED_DEPARTMENTS` | 12 条常量 | 删除，改由 `GET /departments` 获取 |
| `_init_state` | 复制假数据 | 改为缓存登录态与令牌，不再缓存业务数据 |
| 新增分支 | 追加到 `session_state.departments` | 改为 `POST /departments`，成功后刷新列表 |
| 筛选函数 `_filter` | 本地列表过滤 | 名称搜索改为 `full_name` 查询参数；「只看有地址」不保留 |
| 指标 | 对本地列表计数 | 改为对接口返回的 `total` 与当前页数据计数 |
| 表格 | `st.dataframe` + `column_config` | 保留 |
| 空态 | `st.info` | 保留，并补「加载失败」与「未登录」两种提示 |
| 表单校验 | 本地重复编码检查 | 保留非空校验；重复编码与长度交给后端 400/422 |

下游不得依赖：

- `SEED_DEPARTMENTS` 这个常量名；
- `session_state.departments` 这份本地缓存；
- 「提交后一定成功」的假设（16-1 起会出现 401/400/422）。

## 四、接口契约对齐

本实训的假数据字段与 `_shared/接口契约清单.md` 一致：

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `dept_code` | str | 1–20，唯一 |
| `full_name` | str | 1–100 |
| `address` | str \| 空 | ≤500 |

新增表单的必填与长度提示应与后端一致；前端校验不能替代后端校验，16-1 要处理 422。

## 五、不可越过的边界

- 本章不接后端、不引入 `requests`。
- 不改教材正文；组件取舍与差异记录在 `验证记录.md`。
- 不改接口字段名迁就界面。
- 假数据只用于 15-1；16-1 必须删除，避免真假两套数据并存。
