## 1. 读需求、列组件清单（约 30 分钟）

先把页面拆成四块，再为每块选组件。本工程的选择：

| 区域 | 组件 | 类别 |
| --- | --- | --- |
| 指标区 | `st.columns` + `st.metric` ×3 | 容器 + 展示 |
| 筛选区 | `st.text_input`、`st.checkbox`、`st.button` | 输入 + 交互 |
| 表格区 | `st.dataframe` + `st.column_config`、`st.download_button`、`st.info` | 展示 + 交互 |
| 新增区 | `st.tabs`、`st.form` + `st.form_submit_button`、`st.error`/`st.success` | 容器 + 交互 + 展示 |

为什么选表格而不是 `st.table`：`st.table` 把全部数据一次性静态渲染，不能滚动、不能排序、列宽不可控；`st.dataframe` 支持滚动与列配置。

为什么选 `st.form` 而不是三个独立的 `text_input`：独立输入每改一个字符就触发一次重跑；表单把值攒到提交时一次处理。

**验收**：清单里四类都出现；能说出每一处同类替代的取舍。

## 2. 搭输入区（约 40 分钟）

### 2.1 搜索与复选框

```python
left, right = st.columns([3, 1])
with left:
    keyword = st.text_input(
        "搜索单位",
        placeholder="输入单位编码或名称，例如 D001 / 一中队",
        key="keyword",
    )
with right:
    only_with_address = st.checkbox("只看有地址的单位", key="only_with_address")
    st.button("清空搜索", key="clear_keyword", on_click=_clear_keyword)
```

清空按钮必须用回调：

```python
def _clear_keyword() -> None:
    st.session_state["keyword"] = ""
```

如果写成 `if st.button(...): st.session_state["keyword"] = ""`，会在 `text_input` 已实例化之后修改它的状态，触发 `StreamlitAPIException`。

### 2.2 新增表单

```python
with st.form("create_department", clear_on_submit=True):
    col_code, col_name = st.columns(2)
    with col_code:
        dept_code = st.text_input("单位编码 *", key="new_dept_code")
    with col_name:
        full_name = st.text_input("单位名称 *", key="new_full_name")
    address = st.text_input("地址", key="new_address")
    submitted = st.form_submit_button("提交", type="primary", key="submit_dept")
```

**验收**：在表单里连续输入不会触发整页重跑；点「提交」只执行一次处理。

## 3. 搭展示区（约 45 分钟）

### 3.1 指标

```python
metric_total, metric_address, metric_filtered = st.columns(3)
metric_total.metric("单位总数", len(all_items))
metric_address.metric(
    "已填地址", sum(1 for item in all_items if (item.get("address") or "").strip())
)
metric_filtered.metric("当前筛选结果", len(filtered))
```

### 3.2 表格

```python
table = pd.DataFrame(filtered)[["dept_code", "full_name", "address"]]
dept_config = {
    "dept_code": st.column_config.TextColumn("单位编码", width="small"),
    "full_name": st.column_config.TextColumn("单位名称"),
    "address": st.column_config.TextColumn("地址", width="large"),
}
st.dataframe(table, width="stretch", hide_index=True, column_config=dept_config)
```

三个要点：显式选列固定顺序；`column_config` 的键必须与字段名逐字一致；`hide_index=True` 去掉左侧行号。

**验收**：表头为中文，行号消失，编码列窄、地址列宽。

## 4. 加交互与空态（约 30 分钟）

### 4.1 先过滤再渲染

```python
def _filter(items, keyword: str, only_with_address: bool):
    keyword = keyword.strip().lower()
    result = []
    for item in items:
        if keyword and keyword not in item["dept_code"].lower() and keyword not in item["full_name"].lower():
            continue
        if only_with_address and not (item.get("address") or "").strip():
            continue
        result.append(item)
    return result

filtered = _filter(all_items, keyword, only_with_address)
```

指标里的「当前筛选结果」必须在过滤之后计算；否则显示的是全量。

### 4.2 空态

```python
if filtered:
    st.dataframe(...)
else:
    st.info("没有符合条件的单位，请调整搜索条件或取消筛选。")
```

**验收**：搜索「不存在」时出现提示，不出现空表，也不报错。

## 5. 整合与自测（约 15 分钟）

### 5.1 状态与重跑顺序

首次运行放入假数据：

```python
def _init_state() -> None:
    if "departments" not in st.session_state:
        st.session_state.departments = [row.copy() for row in SEED_DEPARTMENTS]
```

新增成功后不要直接 `st.success` 就结束：表格在页签里先执行，当次还看不到新行。用 flash + 重跑：

```python
st.session_state["flash_message"] = f"已新增单位 {code} - {name}"
st.rerun()
```

页面顶部：

```python
flash = st.session_state.pop("flash_message", None)
if flash:
    st.success(flash)
```

### 5.2 校验

```python
if not code or not name:
    st.error("单位编码和单位名称不能为空")
elif any(item["dept_code"] == code for item in st.session_state.departments):
    st.error(f"单位编码 {code} 已存在")
else:
    st.session_state.departments.append({...})
```

### 5.3 三条自测路径

| 路径 | 操作 | 期望 |
| --- | --- | --- |
| 空结果 | 搜索「不存在」 | 出现提示，无空表，无报错 |
| 超长文本 | 地址填 100 字 | 表格换行，不撑破布局 |
| 重复提交 | 连续提交 D001 | 第二次提示「已存在」，行数不变 |

## 常见错误对照

| 报错/现象 | 原因 | 处理 |
| --- | --- | --- |
| `StreamlitAPIException: st.session_state.key cannot be modified after...` | 控件实例化后改其状态 | 用 `on_click` 回调 |
| 输入一个字就整页重跑 | 输入不在 `st.form` 内 | 用 `st.form` 包住 |
| 新增后当次看不到 | 表格先于新增渲染 | flash + `st.rerun()` |
| 表头仍是英文 | `column_config` 键名不一致 | 逐字核对字段名 |
| 空结果报 `IndexError` | 过滤后直接取 `[0]` | 补空态分支 |
| 指标与表格数字不一致 | 指标用了全量数据 | 都用 `filtered` |
| 中文 CSV 打开乱码 | 未加 BOM | `encode("utf-8-sig")` |
