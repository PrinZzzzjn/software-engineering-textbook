# 实训 15-1 学员版差异说明

> 教师版 = `项目/` 完整完成态；学员版 = `starter/` 骨架 + 教材五步。

## 一、起点（可直接发给学员）

`starter/` 包含：

```text
app.py            # set_page_config + 标题 + 待完成提示
requirements.txt  # streamlit、pandas
README.md
起点说明.md
```

起点**不含**：假数据、指标、表格、筛选、空态、新增表单、`verify_app.py`。

## 二、教师版比学员版多什么

| 内容 | 教师版 | 学员版 |
| --- | --- | --- |
| 组件实现 | 完整 `app.py` | 由学员完成 |
| 假数据 | 12 条 | 学员自备 10–20 条 |
| 自测脚本 | `verify_app.py` 18 项 | 不发放；只给三条手工路径 |
| 项目 README | 组件表、状态顺序、验收对照 | 只给运行说明 |
| 分步指南 | 含完整代码与排错 | 可发“阶段任务单”，删代码片段 |

## 三、发放时的具体做法

1. 复制 `starter/` 到学员目录，保留 `起点说明.md`。
2. 不发放 `项目/verify_app.py`；如需要自动验收，教师在本机运行。
3. 可发放 `分步实现指南.md` 的“阶段目标 + 验收”两列，删除代码块。
4. 不发放 `验证记录.md`、`难度评分.md`、本文件（含实测结论与通过线）。
5. 若课堂时间不足，允许只做搜索 + 一个必填输入；但四类组件与空态不可省。

## 四、学员成果的最低检查

| 检查 | 通过标准 |
| --- | --- |
| 四类组件 | 能在代码中指出输入、展示、交互、容器各至少一个 |
| 表格 | 中文列名、无行号、列宽合理 |
| 表单 | 填写时不重跑；提交后一次处理 |
| 筛选 | 条件生效；空结果有提示 |
| 新增 | 提交后表格可见；重复编码被拒绝 |
| 完整性 | 单页可启动，无异常堆栈 |

## 五、可选裁剪

- 课时不足：去掉 CSV 导出与清空按钮，保留搜索、复选框、空态、新增。
- 无 pandas 环境：可用 `st.table` 展示列表，但需说明与 `st.dataframe` 的差异。
- 课后扩展中的“换哨位场景”可作为补考或加分项。
