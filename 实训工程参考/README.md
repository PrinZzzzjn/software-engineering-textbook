## 二、统一口径（所有实训必须遵守）

1. 接口路径无 `/api/v1` 前缀，资源用名词复数（`/departments` 等）。
2. 列表响应 `{items, total}`；新增 201、修改 200、删除 204 且无正文；重复资源 400、不存在 404、模型校验 422。
3. 主线示例资源为 **department**：3-1 单文件内存版 → 4-1 六文件内存版 → 5-1 工程化与 Git → 6-1 落库。
4. 数据库第 6 章才引入（`app/core/database.py`），认证第 8 章引入（hashlib 盐哈希 + TOKEN_STORE，无 JWT/passlib），`tests/` 第 12 章才进入工程；此前的实训不得提前出现这些文件。
5. 接口契约事实源：`项目参考/duty-simplified/`，汇总见 [_shared/接口契约清单.md](_shared/接口契约清单.md)。

## 四、如何验证一个实训

以后端实训为例（在各实训目录下执行，详细记录见该实训 `验证记录.md`）：

```powershell
python -m venv venv
venv\Scripts\Activate.ps1
pip install -r 项目\requirements.txt
pytest 项目\tests            # 3-1 / 4-1 / 6-1 / 7-1 / 8-1 / 9-1 / 10-1 / 11-1 / 12-1 / 13-1
python verify_api.py        # 5-1（该章工程刻意不含 tests/）
uvicorn main:app --port 8000  # 在 项目/ 目录内启动，访问 /docs 与 /health
```

要求：验证记录不允许出现「未验证」；每个实训至少回归上一实训的一个核心接口。进入 8-1 后接口需带 `Authorization: Bearer <token>`，9-1 后管理端点还需管理员角色。
