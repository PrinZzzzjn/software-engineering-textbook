# 实训 17-1 接缝表

> 说明本实训与上游 16-1 单页工程、下游 18-1 编辑与状态的接缝。

> **B 档口径（2026-11-23）**：课堂只做页面守卫 + 翻页；多页目录由教师快照提供。
## 一、上游：16-1 → 17-1

| 接缝 | 16-1 提供的 | 17-1 的处理 | 是否改变 |
| --- | --- | --- | --- |
| 入口 `app.py` | 单文件，含登录门禁、单位页、新增 | 只留门禁、首页说明与后端状态；单位页移入 `pages/` | 拆分 |
| `_render_login` | 定义在 `app.py` | 迁到 `auth.py::render_login`，补 `require_login` / `render_user_box` | 迁移 |
| 登录守卫 | `if "access_token" not in st.session_state` 在入口 | 每个子页面首行调用 `auth.require_login()` | 替换 |
| 表格渲染 | 页面内联 `st.dataframe` + `column_config` | 抽到 `components/table.py::render_table` | 抽取 |
| 分页 | 固定第 1 页，每页 10 条，不可翻 | `session_state` 保存页码与每页条数，`pagination_bar` 翻页 | 新增 |
| 搜索 | `full_name` 查询参数 | 保留，搜索变化时页码重置为 1 | 修改 |
| 指标 | 当前条件总数、本页条数 | 保留，翻页后按页刷新 | 保留 |
| 三态 | spinner / info / error + 401 回登录 | 原样保留到两个页面 | 保留 |
| `config.py` / `api_client.py` | 已成型 | 逐字复用，不改接口 | 保留 |
| 数据页 | 无（16-1 只有单位页） | 新增 `pages/2_数据统计.py`，接 `/personnel` 与 `/analytics` | 新增 |

## 二、本实训的文件边界

| 文件 | 类型 | 说明 |
| --- | --- | --- |
| `项目/app.py` | 入口 | 首页、门禁、导航说明；53 行 |
| `项目/auth.py` | 守卫 | 登录、登出、`require_login`、侧边栏用户信息；82 行 |
| `项目/api_client.py` | 请求层 | 与 16-1 一致；84 行 |
| `项目/config.py` | 配置 | 基地址、前缀、超时、默认分页；19 行 |
| `项目/components/table.py` | 复用组件 | `render_table`、`pagination_bar`；76 行 |
| `项目/pages/1_单位管理.py` | 页面 | 四区、搜索、分页、新增；130 行 |
| `项目/pages/2_数据统计.py` | 页面 | 人员/年份、三指标、月度与时段表；117 行 |
| `项目/verify_app.py` | 教师自测 | 结构与导航 + AppTest，59 项 |

本实训不提供 `starter/`：学员起点就是 16-1 的完成态 `项目/`。

## 三、下游：17-1 → 18-1

| 位置 | 17-1 现状 | 18-1 处理 |
| --- | --- | --- |
| 单位页操作区 | 只有新增 | 增加编辑、删除与二次确认 |
| `session_state` | 页码、每页条数、flash | 增加选中行、编辑中的表单状态 |
| `components/table.py` | 表格 + 分页 | 可增加行选择或操作列 |
| 页面数量 | 两页 | 增加人员、哨位、执勤记录页 |
| `auth.py` | 守卫与用户信息 | 原样复用；如需角色判断再加 |
| `api_client.py` | `get/post/put/delete` 齐全 | `put` / `delete` 在 18-1 首次使用 |
| `config.py` | 地址、超时、分页 | 不改 |

17-1 不得依赖：

- 单位页只能看不能改的假设；
- `components/table.py` 只有两个函数的实现细节；
- 页码只存在函数局部变量的写法。

## 四、接口契约对齐

事实源：`实训工程参考/_shared/接口契约清单.md` 与 13-1 `/docs`。

| 接口 | 方法 | 认证 | 本工程用法 | 失败处理 |
| --- | --- | --- | --- | --- |
| `/health` | GET | 否 | 首页与侧边栏连通性检查 | 连接错误 `ApiError(0)` |
| `/users/login` | POST | 否 | 登录，取 `access_token` 与 `user` | 401 提示账号密码错误 |
| `/departments` | GET | 否 | `page`、`page_size`、可选 `full_name` | 404/连接错误显示 error |
| `/departments` | POST | admin | 新增，成功 201 | 400/401/422 显示 detail |
| `/personnel` | GET | 否 | `page=1&page_size=100` 取人员下拉 | 连接错误显示 error |
| `/analytics/staff-duty-yearly` | GET | 否 | 人员编号 + 年份，年度与月度 | 400 显示 detail |
| `/analytics/duty-time-distribution` | GET | 否 | 人员编号 + 年份，24 小时分布 | 400 显示 detail |

前端不传 `sort_by`、`order` 等后端未声明的参数；列表响应只读 `items` 与 `total`。

## 五、不可越过的边界

- 不做编辑、删除（18-1）；
- 不做图表与主题美化（19-1）；
- 不做统一错误组件与交付清单（20-1）；
- 不新增后端接口，不改字段与状态码；
- 不改教材正文；差异记录在 `验证记录.md`。
