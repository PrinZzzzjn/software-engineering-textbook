# 实训 17-1 前端页面设计项目案例

> **B 档口径（2026-11-23）**：课堂只做页面守卫 + 翻页；多页目录由教师快照提供。
本实训把 16-1 的单页单位管理扩成一套页面：用 `pages/` 目录让导航自动生成，把登录守卫、请求封装、表格分页与配置按职责分开，再按「标题—筛选—内容—操作」四个区域重排单位页，并新增数据统计页。完成态见 `项目/`，实跑证据见 `验证记录.md`。

## 三、边界与不变量

### 3.1 目录与职责

| 位置 | 职责 | 本工程做法 |
| --- | --- | --- |
| `app.py` | 入口、登录门禁、首页导航说明 | 不含任何业务表格代码 |
| `auth.py` | 登录、登出、`require_login` | 守卫只写一次，各页调用 |
| `api_client.py` | 地址、超时、令牌、错误四统一 | 与 16-1 逐字一致 |
| `pages/` | 每个文件一个页面 | 两页；新增页面只加文件 |
| `components/table.py` | `render_table` 与 `pagination_bar` | 单位页与统计页共用 |
| `config.py` | 基地址、前缀、超时、默认分页 | 与 16-1 一致 |

### 3.2 多页与命名

- 文件名 `1_单位管理.py`、`2_数据统计.py`：数字决定顺序，去掉数字前缀成为导航名；
- 导航名用「对象 + 动作」的用户语言，不用 `department_crud`、`analytics2`；
- 导航项只有两项，不建二级分组；超过五项再按「基础数据 / 业务数据 / 统计」分组。

### 3.3 页面四个区域

单位页固定为：标题区 → 筛选区（带边框容器）→ 内容区（指标 + 表格 + 分页）→ 操作区（新增表单）。

- 筛选与标题分开：搜索与每页条数不挤在标题下；
- 操作不压在表格中间：新增表单在表格与分页下方；
- 窄屏用比例列 `[3, 1]` 自动堆叠，表格 `width="stretch"`，不写固定像素宽度；
- 教材 17.3 的三列示例含排序字段与排序方式；本工程后端排序固定、契约不允许 `sort_by`，故第二列改为「每页条数」，差异记入 `验证记录.md`。

### 3.4 守卫与接口契约

- 每个子页面第一行逻辑即 `auth.require_login()`；未登录显示 warning 并 `st.stop()`；
- 验证方式包括直接打开子页面文件，确认被拦截且不发请求；
- 前端守卫只是体验，写接口的 401/403 仍由后端判定；
- 业务路径无 `/api/v1`；列表响应 `{items, total}`；统计接口按人员编号与年份查询。

### 3.5 不做的范围

- 不做编辑、删除（18-1）；
- 不做样式美化与图表（19-1）；
- 不做统一错误提示组件与交付清单（20-1）；
- 不新增后端接口，不改字段与状态码；
- 不改教材正文；差异记录在 `验证记录.md`。

## 六、操作步骤

1. **建多页面骨架（35 分钟）**：`app.py` 只留 `set_page_config`、登录门禁与首页说明；把单位页整体移到 `pages/1_单位管理.py`；新建 `pages/2_数据统计.py` 接 `/personnel` 与 `/analytics`。启动后侧边栏自动出现两项，不需要手写菜单。
2. **整理目录（35 分钟）**：把 16-1 的 `_render_login` 迁到 `auth.py`，提供 `render_login` / `require_login` / `render_user_box`；表格与分页抽到 `components/table.py`；`config.py`、`api_client.py` 原样保留。
3. **规划区域与响应式（30 分钟）**：单位页按四区排列；筛选区用 `st.container(border=True)` + `st.columns([3, 1])`；内容区先指标再表格；操作区放在表格下方。窄屏时列自动堆叠。
4. **评价并改一版层级（35 分钟）**：做十秒测试，记录「我在哪、能查什么、下一步点哪」；至少改一处分组、对齐、对比或顺序。本工程的改进：把搜索从标题下移到带边框筛选区、给内容与操作加区标题、分页条居中。
5. **加守卫与统一命名（25 分钟）**：两个子页面首行调用 `require_login()`；直接访问子页面地址应被拦截；导航名统一为「单位管理」「数据统计」；最后跑 `verify_app.py`。

详细代码与验收见 [分步实现指南.md](分步实现指南.md)。

| 验收项 | 判定方式 |
| --- | --- |
| 多页面可用 | `pages/` 下两个页面被自动发现，侧边栏可切换 |
| 目录清楚 | 入口、守卫、请求、页面、复用组件、配置各一处；入口无业务表格代码 |

## 十、常见问题与排错

| 现象 | 先查什么 |
| --- | --- |
| 侧边栏没有页面 | 文件是否在 `pages/` 下；是否用 `.py` 后缀；是否多加了目录层级 |
| 页面 404 | 文件名是否有空格或特殊符号；是否按 `1_`、`2_` 编号 |
| 守卫被绕过 | 是否只在 `app.py` 加了守卫；每个子页面是否都调用 `require_login()` |
| `set_page_config` 报错 | 它必须是页面里的第一个 Streamlit 调用 |
| 切换页面后登录丢失 | 是否用了普通变量存令牌；应存 `st.session_state` |
| 翻页后搜索条件错乱 | 搜索词或每页条数变化时是否把页码重置为 1 |
| 窄屏错位 | 是否用了固定像素宽度；改用比例列与 `width="stretch"` |
| 导航名难懂 | 用「对象 + 动作」命名，避免缩写与代码语言 |
| 层级仍不清楚 | 先查分组与顺序，再查配色；颜色不能代替分区 |
| 统计页显示 400 | 人员不存在或年份格式错误；先看接口 `detail` |
