### 2.2 把登录逻辑迁到 `auth.py`

```python
import streamlit as st

import api_client as api


def current_user() -> dict:
    return st.session_state.get("current_user", {})


def is_logged_in() -> bool:
    return bool(st.session_state.get("access_token"))


def render_login() -> None:
    """渲染登录表单；登录成功后写入令牌并重跑页面。"""
    st.title("🗂️ 执勤电子年鉴")
    st.caption("请使用系统账号登录（演示账号 admin / admin123）")

    notice = st.session_state.pop("login_notice", None)
    if notice:
        st.warning(notice)

    with st.form("login_form"):
        username = st.text_input("用户名", value="admin", key="login_username")
        password = st.text_input("密码", type="password", key="login_password")
        submitted = st.form_submit_button("登录", type="primary", key="login_submit")

    if not submitted:
        return
    if not username or not password:
        st.error("请输入用户名和密码")
        return

    try:
        data = api.post("/users/login", json={"username": username, "password": password})
    except api.ApiError as exc:
        st.error("用户名或密码错误" if exc.status_code == 401 else exc.detail)
        return

    st.session_state["access_token"] = data["access_token"]
    st.session_state["current_user"] = data.get("user", {})
    st.rerun()


def require_login() -> None:
    if not is_logged_in():
        st.warning("请先登录后再访问该页面")
        render_login()
        st.stop()


def render_user_box() -> None:
    user = current_user()
    if not user:
        return
    with st.sidebar:
        st.divider()
        st.caption(f"当前用户：{user.get('username', '-')}")
        st.caption(f"角色：{user.get('role', '-')}")
        try:
            status = api.get("/health")
            st.success(f"后端正常：{status.get('status', 'ok')}")
        except api.ApiError as exc:
            st.error(exc.detail)
        if st.button("退出登录", width="stretch", key="logout"):
            st.session_state.clear()
            st.rerun()
```

## 3. 规划区域与响应式（约 30 分钟）

单位页固定四区，代码顺序就是用户阅读顺序：

```python
# 标题区
st.title("🏢 单位管理")
st.caption("维护执勤业务中的单位信息：查询、分页与新增。")

# 筛选区：放进带边框容器，用比例列
with st.container(border=True):
    col_keyword, col_size = st.columns([3, 1])
    with col_keyword:
        keyword = st.text_input("单位名称", placeholder="输入名称片段，例如 一中队", key="dept_keyword")
    with col_size:
        page_size = st.selectbox("每页条数", [5, DEFAULT_PAGE_SIZE, 20], index=1, key="dept_page_size")

# 内容区
st.subheader("单位列表")
metric_total, metric_page = st.columns(2)
metric_total.metric("单位数（当前条件）", total)
metric_page.metric("本页显示", len(items))
# 表格 + 分页 ...

# 操作区：在表格下方，不压在表格中间
st.subheader("新增单位")
with st.container(border=True):
    with st.form("create_department", clear_on_submit=True):
        ...
```

比例列 `[3, 1]` 在主区与辅助区之间分配空间，窗口变窄时自动堆叠；表格用 `width="stretch"` 填满容器。不写固定像素宽度，也不自己算坐标。

教材 17.3 的示例筛选区是 `[2, 1, 1]` 三列（名称、排序字段、排序方式）。本工程后端排序固定，契约明确前端不传 `sort_by`，因此第三列改为「每页条数」，仍是三件事：查什么、看多少、怎么翻。

**验收**：主操作在首屏可见；把窗口调窄，两列自动上下堆叠；表格不溢出。

## 4. 评价并改一版层级（约 35 分钟）

### 4.1 十秒测试

新用户第一次打开单位页，十秒内应能说出：

1. 我在哪：标题「单位管理」+ 一句话说明；
2. 能查什么：筛选区里的名称与每页条数；
3. 下一步点哪：内容区的分页，或操作区的新增表单。

说不出，先改区域与顺序，不要先改颜色。

### 4.2 四个手段与对应的改进

| 手段 | 改前 | 改后 |
| --- | --- | --- |
| 分组 | 搜索框直接跟在标题下 | 搜索与每页条数进带边框容器，和内容分开 |
| 对齐 | 指标、表格、按钮边界不一致 | 区标题统一 `st.subheader`，表格占满容器，分页条居中 |
| 对比 | 标题与区标题权重相近 | 页面标题 > 区标题 > 说明文字，三层清楚 |
| 顺序 | 新增表单在列表上方 | 筛选 → 内容 → 操作，操作区移到最后 |

### 4.3 层级失败的三种样子

| 现象 | 根因 | 改法 |
| --- | --- | --- |
| 所有功能堆在一页 | 没有多页面与任务分区 | 拆到 `pages/`，一页一类任务 |
| 按钮紧挨表格 | 操作与内容没有边界 | 操作区加区标题并下移 |
| 导航名用代码语言 | 名称没有对应用户任务 | 改成「单位管理」「数据统计」 |

**验收**：能指出改前改后各一处，并说明改的是分组、对齐、对比还是顺序；只说「加了颜色」不算。

## 5. 加守卫与统一命名（约 25 分钟）

### 5.1 每个子页面顶部加守卫


- 新开浏览器会话，直接访问 `http://127.0.0.1:8501/单位管理`：应看到「请先登录后再访问该页面」与登录表单；
- 登录后再访问同一地址：正常显示单位页；

## 常见错误对照

| 报错/现象 | 原因 | 处理 |
| --- | --- | --- |
| 侧边栏没有页面 | 文件不在 `pages/` 或后缀不对 | 放到 `pages/` 下，用 `.py` |
| `set_page_config` 报错 | 不是页面第一个 Streamlit 调用 | 移到最上面 |
| 守卫被绕过 | 只在 `app.py` 加了守卫 | 每个子页面顶部调用 `require_login()` |
| 页面切换后要重新登录 | 令牌存普通变量 | 存 `st.session_state` |
| 第 2 页搜索后空白 | 搜索后没把页码重置为 1 | 搜索词或每页条数变化时重置页码 |
| 翻页按钮点击无效 | 返回页码没写回 `session_state` | 比较新旧页码，变化后 `st.rerun()` |
| 窄屏重叠/溢出 | 固定像素宽度 | 比例列 + `width="stretch"` |
| 统计页 400 | 人员不存在或年份格式错 | 先看 `detail`，再查人员编号 |
| 统计页没有数据 | 年份选错（种子记录在 2026） | 切到 2026 或换人员 |
| 导航名看不懂 | 文件名用了代码语言 | 改成用户语言 |
| 层级仍不清楚 | 只改了颜色 | 回到分组与顺序 |
