# 实训 17-1 学员版差异说明

> 教师版 = `项目/` 完整完成态；学员版 = 16-1 完成态 + 教材五步。本实训不另发 `starter/`。

## 一、起点（可直接发给学员）

复制 `实训16-1/项目/` 作为起点，保留：

```text
app.py            # 单页：登录 + 单位列表 + 新增 + 三态
config.py
api_client.py
requirements.txt
README.md
```

起点**不含**：`pages/`、`auth.py`、`components/`、数据统计页、分页 UI、`verify_app.py`。

如需把 16-1 的 `app.py` 压成最小起点，可删除其中的单位列表与新增代码，只留登录门禁；但保留完整单页更接近真实交接场景。

## 二、教师版比学员版多什么

| 内容 | 教师版 | 学员版 |
| --- | --- | --- |
| 多页面 | `pages/` 两页，导航自动生成 | 由学员拆 |
| 守卫 | `auth.py` + 每页 `require_login()` | 由学员迁移与逐页添加 |
| 复用组件 | `components/table.py` 表格与分页 | 由学员抽取 |
| 分页 | 页码与每页条数进 `session_state` | 由学员实现 |
| 数据统计页 | 人员/年份 + 三个指标 + 两张表 | 由学员新建 |
| 层级改进 | 四区与改进说明 | 由学员完成并说明手段 |
| 自测 | `verify_app.py` 59 项 | 不发放；只给手工路径 |
| 文档 | README、分步指南、验证记录、难度评分、接缝表 | 只给起点说明与阶段任务单 |

## 三、发放时的具体做法

1. 复制 16-1 `项目/` 到学员目录，删除 `verify_app.py` 与 `联调排错记录.md`。
2. 可发放 `分步实现指南.md` 的「阶段目标 + 验收」两列，删除代码块。
3. 不发放 `验证记录.md`、`难度评分.md`、`接缝表.md`、本文件。
4. 课堂时间不足时，可只做单位页 + 一个占位统计页，但守卫与四区不可省。
5. 若课时紧张，允许先复制 `components/table.py`，再让学员解释它为什么放在 `components/`。

## 四、学员成果的最低检查

| 检查 | 通过标准 |
| --- | --- |
| 多页面 | 侧边栏出现至少两个页面，切换正常 |
| 目录 | 入口无业务表格；守卫、请求、组件、配置各一处 |
| 区域 | 四区按「标题—筛选—内容—操作」排列，操作不压表格 |
| 层级 | 能说出十秒测试结果，并指出一处改进属于哪个手段 |
| 守卫 | 新会话直接访问子页面被拦截，且不发业务请求 |
| 命名 | 导航名能预测页面内容，不用代码语言 |
| 分页 | 搜索或每页条数变化时回到第 1 页，翻页不越界 |

## 五、可选裁剪

- 课时不足：统计页只保留人员/年份筛选与一个指标，两张表可课后补。
- 无真实后端：可用教师提供的只读 Mock，但仍保持同一契约与状态码。
- 课后扩展中的面包屑与页面区域规划说明可作为加分项。
- 编辑、删除与更多业务页明确留给 18-1，本实训不提前实现。
