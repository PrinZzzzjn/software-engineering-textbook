# 实训 6-1 学员起点说明

本目录是**实训 5-1 的完成态**（单位六文件内存版 + 根入口 + 依赖 + 配置示例 + 忽略规则 + README），六个 `department` 文件仍是 `dataclass` + 内存列表 `TABLE` 的写法。本实训要把它改造成 **SQLite 数据库版**，数据在服务重启后仍然存在。

这里不是空白 TODO 骨架，也不提供答案代码。请按教材 6.1–6.3 与 `分步实现指南.md` 完成改造。

## 需要改动的 4 处

1. **新增 `app/core/`**
   - `app/core/__init__.py`（空文件，让目录成为包）
   - `app/core/database.py`：提供 `engine`、`SessionLocal`、`Base`、`get_db`
   - 要求：`DATABASE_URL` 从环境变量读取，未设置时回落到 `sqlite:///./duty.db`；`get_db` 用 `yield` 交出会话并在 `finally` 关闭。

2. **改写 `app/modules/department/model.py`**
   - 删除 `@dataclass` 与 `TABLE`，改为继承 `Base` 的 SQLAlchemy 模型
   - 表名 `departments`；`dept_code` 主键、`full_name` 必填、`address` 可空
   - 三个字段的长度上限沿用 20 / 100 / 500

3. **改写 `app/modules/department/crud.py`**
   - 不再遍历 `model.TABLE`
   - 每个函数接收 `db: Session`，用 `query`、`add`、`commit`、`refresh`、`delete` 完成读写
   - 列表查询要带固定排序（`dept_code` 升序）、`offset` 与 `limit`，并单独返回总数

4. **改 `main.py` 与根目录配置**
   - `main.py` 增加建表三行：导入 `Base` 与 `engine`、导入单位模型、`Base.metadata.create_all(bind=engine)`
   - 增加幂等 seed：D001 一中队 / D002 二中队，已存在则跳过
   - `requirements.txt` 增加 `sqlalchemy`
   - `.gitignore` 补 `*.db-journal`（SQLite 运行期日志文件）

## 接线级的小改（不改变职责）

- `service.py`：每个函数多收一个 `db` 参数并传给 `crud`；列表里用 `page`、`page_size` 算 `offset`，把 `items` 与 `total` 组装成响应。
- `controller.py`：每个接口加 `db: Session = Depends(get_db)`；列表参数仍由 `param.py` 注入。
- `schema.py`：输入、输出字段不变；保留 `DepartmentUpdate` 与 `DepartmentPage`，列表用 `response_model=DepartmentPage`，修改接口使用 `DepartmentUpdate`；`DepartmentOut` 增加 `from_attributes=True`。
- `param.py`：字段与边界不变，类名沿用 4.5 的 `DepartmentQueryParams`。

`controller`、`service`、`schema`、`param` 的分层与字段契约不应在这四个文件之外被改动；数据库替换集中在上面 4 处。

## 起点检查

python -c "from app.modules.department import controller; print(controller.router.prefix)"

本目录的 `README.md` 是 5-1 原文档，其中最后提到的 `..\verify_api.py` 属于 5-1 实训根目录，不在本起点包内；本实训改用任务书的八条手工检查清单，不依赖该脚本。
