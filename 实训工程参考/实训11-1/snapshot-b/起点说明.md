# 实训 11-1 起点说明

本目录是 **实训 10-1 的完成态**，作为 11-1 的学员起点。它包含：

- department、personnel、user、workstation、duty_record 五个模块；
- 管理员依赖、分页骨架、三条执勤规则与 26 项教师测试；
- `main.py` 的幂等 seed：D001/D002、P001/P002、W001/W002、4 条 2026 年执勤记录、`admin/admin123`。

起点中**没有** `app/modules/analytics/`，`GET /analytics/staff-duty-yearly` 与 `GET /analytics/duty-time-distribution` 应为 404。这正是 11-1 要补的内容。

使用方式：

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m uvicorn main:app --port 8000
```

先确认起点可跑：`GET /health` 200；`GET /duty-records` 的 `total` 为 4；`GET /workstations` 的 `total` 为 2；`admin/admin123` 登录 200。
