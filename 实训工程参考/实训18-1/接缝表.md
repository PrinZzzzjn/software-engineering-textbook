## 一、上游：17-1 → 18-1

## 四、接口契约对齐

事实源：`实训工程参考/_shared/接口契约清单.md` 与 13-1 `/docs`。

| 接口 | 方法 | 认证 | 本工程用法 | 失败处理 |
| --- | --- | --- | --- | --- |
| `/health` | GET | 否 | 首页与侧边栏连通性检查 | 连接错误 `ApiError(0)` |
| `/users/login` | POST | 否 | 登录，取 `access_token` 与 `user` | 401 提示账号密码错误 |
| `/departments` | GET | 否 | `page`、`page_size`、可选 `full_name` | 显示 detail |
| `/departments` | POST | admin | 新增，成功 201 | 400/401/422 显示 detail |
| `/departments/{code}` | PUT | admin | 编辑名称、地址；编码禁用 | 404/401/422 显示 detail |
| `/departments/{code}` | DELETE | admin | 二次确认后删除，成功 204 | 404/401 显示 detail |
| `/personnel` | GET | 否 | `page`、`page_size`、可选 `name`、`dept_code` | 显示 detail |
| `/personnel` | POST / PUT / DELETE | admin | 新增、编辑、删除；证件号禁用 | 400/404/401/422 |
| `/workstations` | GET | 否 | `page`、`page_size`、可选 `dept_code` | 显示 detail |
| `/workstations` | POST / PUT / DELETE | admin | 新增、编辑、删除；编号禁用；`is_active` 0/1 | 400/404/401/422 |
| `/duty-records` | GET | 否 | `page`、`page_size`、可选人员/哨位 | 显示 detail |
| `/duty-records` | POST | admin | 新增；时间为 ISO 字符串 | 400/401/422 |
| `/duty-records/{id}` | DELETE | admin | 二次确认后删除，成功 204 | 404/401 |
| `/analytics/*` | GET | 否 | 统计页回归，不改 | 400 显示 detail |

前端不传 `sort_by`、`order` 等后端未声明的参数；列表响应只读 `items` 与 `total`；`/duty-records` 没有 PUT，页面不提供编辑。

## 五、不可越过的边界

- 不做图表与主题美化（19-1）；
- 不做统一错误组件与交付清单（20-1）；
- 不新增后端接口，不改字段与状态码；
- 不为单位删除在前端硬造「有关联就不能删」的业务规则；
- 不改教材正文；差异记录在 `验证记录.md`。
