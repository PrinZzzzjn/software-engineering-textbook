# 实训 8-1 学员版差异说明

本文件说明教师参考包与拟发布学员版之间的取舍：哪些内容保留、哪些必须删除、学员版应补充哪些契约，以及旧 8-1 手册需要修正的口径。目标是让学员独立完成实现，同时不因信息缺失而做错接口。

## 一、版本定位

- **教师参考包**（本目录）：完整完成态 `项目/`、33 项测试、真实验证记录、难度评分、接缝表、分步实现指南。
- **学员版**：7-1 完成态工程 + 任务书 + 接口契约 + 验收清单 + 常见问题；不含 user 模块实现、不含 security 实现、不含新增测试与真实运行记录。

学员版不是把教师版「删几段代码」，而是保留**可验证的契约**、移除**可直接抄写的实现**。契约必须足够精确，否则学生即使理解正确，也会因字段名、状态码或路径不同被判错。

## 四、学员版必须给出的契约

以下信息不是答案，而是接口验收标准，必须写清楚：

### 4.1 路径与方法

| 方法 | 路径 | 认证 |
| --- | --- | --- |
| POST | `/users` | 否 |
| POST | `/users/login` | 否 |
| GET | `/users/me` | `Authorization: Bearer <token>` |

集合路径无尾斜杠；不加版本化前缀；`prefix=""`。

### 4.2 状态码与响应字段

| 场景 | 状态码 | 响应字段 |
| --- | --- | --- |
| 注册成功 | 201 | `id`、`username`、`role`、`is_active` |
| 用户名重复 | 400 | `detail` |
| 密码少于 6 位 | 422 | `detail`（Pydantic 校验结构） |
| 登录成功 | 200 | `access_token`、`token_type`、`user` |
| 登录失败 | 401 | `detail` |
| `/me` 无令牌 | 401 | `detail` |
| `/me` 令牌无效 | 401 | `detail` |
| `/me` 成功 | 200 | `id`、`role` |

登录响应的 `user` 只含 `id`、`username`、`role`、`is_active`；任何响应不得出现 `password_hash`。推荐 detail 文案：重复用户名「用户名已存在」、登录失败「用户名或密码错误」、无令牌「未提供令牌」、令牌无效「令牌无效」。教师测试按这四句判定，学员版应明确给出。

### 4.3 users 字段

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `id` | 整数 | 主键、自增 |
| `username` | 字符串 | 唯一、非空、最长 100 |
| `password_hash` | 字符串 | 非空，格式 `盐$迭代次数$摘要` |
| `role` | 字符串 | 默认 `normal`；seed admin 为 `admin` |
| `is_active` | 整数 | 默认 1 |

不建 users 到 departments 的外键。

### 4.4 安全与已知行为

- 密码哈希格式 `盐$迭代次数$摘要`；盐随机，同一密码两次注册结果不同；数据库不存明文。
- 令牌为随机字符串，服务端登记 `token -> user_id`；令牌本身不携带角色。
- 服务重启后旧令牌失效，账号仍在；这是本阶段已知行为。
- 客户端传 `role` 不生效；注册一律 `normal`。
- 必须提供幂等方式创建 `admin/admin123`，重复启动不重复插入、不覆盖密码。

## 五、旧 8-1 手册需要修正的口径

| 旧手册口径 | 学员版修正 | 说明 |
| --- | --- | --- |
| 路由带版本化前缀 | 全部改为无前缀路径 | 与教材本版一致 |
| 集合路径带尾斜杠 | `/users`、`/departments`、`/personnel` 均无尾斜杠 | 不依赖框架重定向 |
| 用重定向现象做排错项 | 删除该排错项，改为「路径写错」检查 | 旧排错项已过期，容易把正确实现判成错误 |
| 步骤 2 后 `/docs` 出现用户分组 | 改为「步骤 2 只建表，步骤 4 挂路由后才出现分组」 | 无路由就没有分组 |
| 8-1 工程只保留 department + user | 必须保留 personnel 全部行为 | 总计划要求，为 10-1 铺垫 |
| 用户模块五文件 | 按六文件体例补齐 `param.py` | 与 4-1/7-1 体例一致，为 9-1 预留 |
| 未要求 admin 账号 | 明确要求幂等 `admin/admin123` | 9-1 需要管理员账号 |
| 注册路径写成 `/users/register` | 改为 `POST /users` | 以教材 8-3-3 为准 |
| 测试或验收只测新接口 | 增加 department/personnel 回归 | 防止新增认证破坏旧功能 |
| 允许引入第三方密码库 | 明确只用 `hashlib` 与 `secrets` | 教材边界与依赖最小化 |

## 六、建议的学员版目录

```text
实训8-1-学员版/
├── 实训任务书.md          目标、边界、时间、交付、评分
├── 接口与字段.md          路径、状态码、响应字段、users 字段
├── 验收清单.md            学生自测与教师评分共用
├── 常见问题.md            现象与排查方向
├── 起点说明.md            已有能力、要新增的文件、依赖检查
└── 项目/                  7-1 完成态（含 23 项旧测试）
    ├── main.py
    ├── app/
    │   ├── core/database.py
    │   └── modules/department、personnel
    └── tests/test_api.py
```

学员在自己目录中新增 `app/core/security.py` 与 `app/modules/user/`，并修改 `main.py`。不要在 `项目/` 原目录上直接改后再提交教师版，避免把答案混入起点。

## 七、评分建议

| 维度 | 分值 | 细目 |
| --- | --- | --- |
| 注册 | 15 | 201、字段正确、重复 400、短密码 422、`role` 不可注入 |
| 登录 | 20 | 200、三字段、`token_type=bearer`、错误密码 401、无密码哈希 |
| 当前用户 | 15 | 无令牌 401、有效令牌 200、无效令牌 401、只回 id/role |
| 安全实现 | 20 | 盐哈希格式、同密不同哈希、明文不落库、令牌服务端登记、角色从库读 |
| admin seed | 10 | `admin/admin123` 可登录、`role=admin`、重复启动不重复 |
| 旧接口回归 | 15 | department 与 personnel 的列表、过滤、CRUD 状态码不变 |
| 工程与文档 | 5 | 无禁用依赖、无运行数据入库、README 说明接口与重启行为 |
| 合计 | 100 | — |

越界实现不扣分但不加分：403、用户列表、修改角色、禁用、登出、令牌过期。若学员做了扩展且未破坏必做项，可在平时分另加最多 5 分，总分不超过 100。

## 八、学员版不应出现的提示

- 完整 `security.py`、完整 user 六文件、`main.py` 的完整装配代码。
- 教师版 10 项用户测试的源码或精确断言。
- 真实令牌、真实密码哈希、真实数据库文件。
- 「复制这段即可」的整段答案。
- 9-1 的 403 依赖、用户列表、修改/禁用实现。
- 对旧接口加认证依赖的示例代码。
