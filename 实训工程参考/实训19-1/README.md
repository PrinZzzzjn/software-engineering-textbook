# 实训 19-1 界面优化与数据可视化项目案例

本实训在 18-1 的五个业务页面上做视觉与信息组织升级：用 `.streamlit/config.toml` 统一主题，把数据统计页改成「侧边栏筛选—指标卡总览—折线/柱状图—明细表」的仪表盘；其余四页的写操作、守卫、分页与状态规则原样保留。完成态见 `项目/`，实跑证据见 `验证记录.md`。

## 二、教学目标与教材映射

完成本实训后，学生应能：

1. 写出 `.streamlit/config.toml` 的 `[theme]` 节，说明常用键与「改完必须重启」的生效方式。
2. 用 `st.metric` 的 `label`、`value`、`format`、`icon`、`border` 做一行指标卡，并保证数字来自统计接口。
3. 把接口返回的列表转成 `DataFrame`，用 `set_index` 或 `x` 指定横轴，用 `st.line_chart` / `st.bar_chart` 画趋势与对比。
4. 用 `st.sidebar`、`st.columns`、`st.container(border=True)` 按「总览—趋势—明细」组织仪表盘。
5. 说明 `color`、`height`、`width="stretch"` 的作用，并处理空数据、窄屏与图表可核对性。

## 三、边界与不变量

### 3.1 目录与职责

| 位置 | 职责 | 本工程做法 |
| --- | --- | --- |
| `.streamlit/config.toml` | 全站主题与浏览器配置 | 新增；浅色底、青绿主色、深色正文 |
| `app.py` | 入口、登录门禁、首页导航说明 | 导航说明改为仪表盘描述 |
| `auth.py` | 登录、登出、`require_login` | 与 18-1 逐字一致 |
| `api_client.py` | 地址、超时、令牌、错误四统一 | 与 18-1 一致 |
| `components/table.py` | `render_table` 与 `pagination_bar` | 原样复用；明细表也用 `render_table` |
| `components/feedback.py` | `set_flash` / `show_flash` | 原样复用 |
| `pages/2_数据统计.py` | 仪表盘 | 本实训主要改动：侧边栏 + 指标 + 两张图 + 明细 |
| 其余四个页面 | 业务读写 | 只改文件头注释，逻辑与状态规则不变 |
| `config.py` | 基地址、前缀、超时、默认分页 | 只更新注释，指向主题配置文件 |

### 3.2 主题与图表色

- 主色 `#0F766E` 用于按钮、链接与选中态；页面底色 `#F8FAFC`，卡片 `#FFFFFF`，正文 `#0F172A`；
- 图表色 `#0D9488` 是主色的邻近色，全页只用这一个图表色；
- 主题只写在 `config.toml`，不写自定义 CSS；改完必须重启 Streamlit。

### 3.3 数据与口径

| 指标 | 来源字段 | 口径 |
| --- | --- | --- |
| 总执勤天数 | `total_duty_days` | 按执勤开始日期去重，跨天记录按跨越日期各计一天 |
| 总执勤时长（小时） | `total_duty_hours` | 结束减开始累加，保留两位小数 |
| 执勤记录数 | `total_records` | 当年该人员的记录条数 |
| 高峰时段数 | `len(peak_hours)` | 按开始小时计数，并列高峰全部计入 |

- 指标卡数字只从接口取，不在前端手填；
- 24 小时分布只画有记录的小时；月度分布无数据时提示，不画空图；
- 明细来自 `GET /duty-records`，按人员筛选后在前端按年份过滤。

### 3.4 不做的范围

- 不改 18-1 的写操作、守卫、分页与反馈规则；
- 不新增后端接口，不改字段与状态码；
- 不做 20-1 的统一错误提示与交付清单；
- 不引入 Altair、Plotly、Matplotlib 等额外依赖；
- 不改教材正文；差异记录在 `验证记录.md`。

## 六、操作步骤

1. **配置主题（30 分钟）**：在项目根目录新建 `.streamlit/config.toml`，写 `[theme]` 的 `base`、`primaryColor`、`backgroundColor`、`secondaryBackgroundColor`、`textColor`、`font`，并在 `[browser]` 关闭使用统计；重启 Streamlit，确认按钮、底色与正文颜色变化。
2. **做指标卡（35 分钟）**：把人员与年份筛选移进 `st.sidebar`；取 `/analytics/*` 两个接口，用 `st.columns(4)` 排四个 `st.metric`；天数与记录数用 `format="%d"`，时长用 `"%.1f"`，每个指标加 `icon` 与 `border=True`。
3. **画图表（45 分钟）**：把 `time_distribution` 与 `duty_by_month` 转成 `DataFrame`，用 `set_index` 设横轴；有记录时画 `st.line_chart(y="count", color="#0D9488", height=260, width="stretch")` 与 `st.bar_chart(y="days", ...)`；无记录时用 `st.info` 提示。
4. **组合仪表盘（50 分钟）**：两张图并排放进 `st.container(border=True)` 卡片，图下补口径与「查看数据表」；下方用 `render_table` 展示当年明细；窄屏检查列是否堆叠、图表是否溢出。

详细代码与验收见 [分步实现指南.md](分步实现指南.md)。

## 十、常见问题与排错

| 现象 | 先查什么 |
| --- | --- |
| 主题不生效 | 是否重启；键名是否写成 `primary_color` 之类的错误形式 |
| 指标数字对不上 | 是否手填；字段名是否写错；人员与年份是否同时传入 |
| 图表空白 | `data` 是否为 `DataFrame`；`x`/`y` 列名是否存在 |
| 图表横轴不对 | 是否用 `set_index("hour"/"month")` 或写对 `x=` |
| 两张图颜色不一致 | 是否共用同一个图表色常量 |
| 图表太窄或溢出 | 是否用比例列与 `width="stretch"`；是否写了固定宽度 |
| 空年份仍画图 | 是否先判断记录数再调用图表接口 |
| 页面很花 | 主色是否只有一个；是否又加了自定义 CSS |
| 统计页筛选找不到 | 是否写在 `with st.sidebar:` 内 |
| 明细为空但指标有数 | 明细按 `start_time` 年份过滤；检查时间字符串前缀 |
