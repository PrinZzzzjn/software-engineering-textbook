# 实训 19-1 教师版与学员版差异说明

## 一、教师版包含什么

| 内容 | 教师版 | 学员版 |
| --- | --- | --- |
| 教材步骤与验收标准 | `README.md`、`分步实现指南.md` | 保留 |
| 主题配置 | 完整 `.streamlit/config.toml` | 给键名表与取值要求，学员自己写 |
| 指标卡 | 四个指标的完整写法 | 给字段与格式要求，不给完整代码 |
| 两张图 | 完整参数与空数据处理 | 给图表选择与参数表，学员自己接数据 |
| 仪表盘布局 | 侧边栏 + 并排卡片 + 明细 | 给线框与层级要求，不给像素级结构 |
| 自测脚本 | `verify_app.py` 119 项 | **不提供** |
| 验证记录 | 全量证据 | **不提供** |
| 难度评分与接缝表 | 提供 | **不提供** |

## 二、学员必须自己完成的部分

1. 新建 `.streamlit/config.toml`，写 `[theme]` 六个常用键，并重启验证；
2. 把统计页筛选移入 `st.sidebar`；
3. 用 `st.columns(4)` 做四个指标卡，数字从 `/analytics/*` 取，格式与图标正确；
4. 把 24 小时分布与月度分布转成 `DataFrame`，画折线与柱状，设置 `y`、`color`、`height`、`width`；
5. 两张图并排放进带边框的卡片，图下补口径与可展开数据表；
6. 在图表下方给当年明细；
7. 处理空数据、窄屏与回归：18-1 的写操作、守卫、分页、反馈和 401 仍要通过。

## 三、允许提供的骨架

教师可以给不含业务数据的界面骨架，例如：

```python
left, right = st.columns(2, gap="medium")

with left:
    with st.container(border=True):
        st.subheader("24 小时分布")
        st.caption("按执勤开始时间的小时统计")
        # 学员在此画图

with right:
    with st.container(border=True):
        st.subheader("月度分布")
        st.caption("每月执勤天数")
        # 学员在此画图
```

但不得提供：接口字段到图表的完整转换、四个 `st.metric` 的完整参数、空数据判断的成品代码、`verify_app.py` 的断言。

## 四、评分点建议（100 分）

| 维度 | 分值 | 观测点 |
| --- | ---: | --- |
| 主题 | 15 | 六个键齐全；主色只有一个；重启后生效；未用自定义 CSS 兜底 |
| 指标卡 | 20 | 四项数字与接口一致；`format` 与 `icon` 正确；切换人员/年份会变 |
| 折线图 | 20 | `DataFrame`；横轴小时；`y="count"`；高度与颜色正确；高峰可读 |
| 柱状图 | 15 | 横轴月份；`y="days"`；与折线同色同高；类型与对比目的匹配 |
| 布局与说明 | 15 | 侧边栏筛选；两张图并排；图下口径；明细可核对 |
| 空数据与窄屏 | 10 | 空年份有提示不画图；窄屏图表不溢出 |
| 回归 | 5 | 18-1 五页写操作、守卫、分页、401 未被改坏 |

## 五、常见不合格形态

| 形态 | 问题 | 扣分建议 |
| --- | --- | --- |
| 指标数字写死 | 切换人员/年份不变 | 指标卡整项不得分 |
| 图表传列表 | 页面报错或空白 | 对应图表不得分 |
| 两张图颜色各异 | 视觉不统一 | 主题或图表项扣分 |
| 空年份画全 0 图 | 误导读图 | 空数据项不得分 |
| 固定宽度导致溢出 | 窄屏不可用 | 布局项扣分 |
| 为美化改坏写操作 | 18-1 功能回退 | 回归项不得分，并要求修复 |
| 主题写在页面 CSS 里 | 换页失效、升级易坏 | 主题项按「未使用主题配置」处理 |
| 把统计页做成图表堆砌 | 首屏无重点、信息层级混乱 | 布局与说明项扣分 |
