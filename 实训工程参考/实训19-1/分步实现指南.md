**验收**：侧边栏有五个页面；单位页能新增、编辑、删除；统计页能看到 P001 2026 年的 2 天、16 小时、3 条记录，但还没有图表。

## 1. 配置主题（约 30 分钟）

### 1.1 新建配置文件

在项目根目录新建 `.streamlit/config.toml`：

```toml
[theme]
base = "light"
primaryColor = "#0F766E"
backgroundColor = "#F8FAFC"
secondaryBackgroundColor = "#FFFFFF"
textColor = "#0F172A"
font = "sans serif"

[browser]
gatherUsageStats = false
```

六个键的分工：

| 键 | 作用 | 本工程取值 |
| --- | --- | --- |
| `base` | 明色或暗色基底 | `light` |
| `primaryColor` | 按钮、链接、选中态 | `#0F766E` 青绿 |
| `backgroundColor` | 页面底色 | `#F8FAFC` 浅灰 |
| `secondaryBackgroundColor` | 卡片、侧边栏底色 | `#FFFFFF` 纯白 |
| `textColor` | 正文颜色 | `#0F172A` 深蓝黑 |
| `font` | 字体族 | `sans serif` |

### 1.2 生效方式

改完必须重启 Streamlit。若颜色没变，先查两件事：

1. 进程是否真的重启（旧进程还占着 8501）；
2. 键名是否拼对（`primary_color` 不会报错，也不会生效）。

**做错会看到什么**：只改了 `config.toml` 没重启 → 页面颜色完全不变；把 `[theme]` 写成 `[themes]` → 所有键都不生效。

**验收**：按钮与选中态变青绿，页面底色浅灰、卡片纯白，正文变深色；`streamlit config show` 能看到 `[theme]` 的值。

## 2. 做指标卡（约 35 分钟）

### 2.1 筛选进侧边栏

统计页的主区域要留给指标与图表，筛选放 `st.sidebar`：

```python
with st.sidebar:
    st.divider()
    st.subheader("统计筛选")
    label = st.selectbox("人员", list(options.keys()), key="stats_person")
    year = st.selectbox("年份", ["2026", "2025"], key="stats_year")
```

人员下拉仍来自 `GET /personnel`，年份先给演示数据覆盖的 2026 与 2025。

### 2.2 四个指标卡

```python
m1, m2, m3, m4 = st.columns(4)
m1.metric("总执勤天数", yearly.get("total_duty_days", 0),
          icon="📅", border=True, format="%d")
m2.metric("总执勤时长（小时）", yearly.get("total_duty_hours", 0),
          icon="⏱️", border=True, format="%.1f")
m3.metric("执勤记录数", dist.get("total_records", 0),
          icon="🏅", border=True, format="%d")
m4.metric("高峰时段数", len(peak_hours), icon="📈", border=True, format="%d")
```

三条规则：

1. 指标值必须来自 `/analytics/*` 的返回字段，不手填；
2. 天数、记录数用 `%d`，时长用 `%.1f`，同一页格式统一；
3. `icon` 帮助快速识别，`border=True` 让四个数字形成一组卡片。

**做错会看到什么**：指标数字写死 → 切换人员或年份数字不变；`format` 写成 `"%.2f"` 与另一张卡不一致 → 页面显得零散。

**验收**：P001 + 2026 显示 2、16.0、3、1；切到 P002 数字随之变化；切到 2025 全部归零。

## 3. 画图表（约 45 分钟）

### 3.1 先判断空数据

24 小时分布接口始终返回 24 项，没有记录时全是 0。先筛掉计数为 0 的小时，空列表就提示：

```python
hour_rows = [row for row in dist.get("time_distribution", []) if row.get("count")]
if not hour_rows:
    st.info(f"{year} 年该人员没有执勤记录，暂不绘制分布图。")
```

月度分布同理：`days` 与 `hours` 都为 0 时不画柱状图。

### 3.2 折线图：24 小时分布

```python
df_hour = pd.DataFrame(hour_rows).set_index("hour")
df_hour.index.name = "小时"
st.line_chart(
    df_hour,
    y="count",
    color="#0D9488",
    height=260,
    width="stretch",
)
```

- 数据必须是 `DataFrame`；
- `set_index("hour")` 把小时设为横轴，也可以不设索引改用 `x="hour"`；
- `y="count"` 指定纵轴；
- `color` 用主色的邻近色，全页只用一个图表色；
- `height` 固定 260，`width="stretch"` 让图填满卡片。

### 3.3 柱状图：月度分布

```python
df_month = pd.DataFrame(yearly["duty_by_month"]).set_index("month")
df_month.index.name = "月份"
st.bar_chart(
    df_month,
    y="days",
    color="#0D9488",
    height=260,
    width="stretch",
)
```

选择依据：24 小时是时间序列，用折线看趋势；12 个月是分类比较，用柱状比大小。

**做错会看到什么**：直接传列表 → 图表报错或空白；`y` 写成不存在的列 → 空白；用饼图比较 12 个月 → 差异读不出来。

**验收**：两张图都能显示；折线在 8 时有峰值，13 时有一个点；柱状图 3 月与 4 月各 1 天；切换年份时图随数据变化。

## 4. 组合仪表盘（约 50 分钟）

### 4.1 两张图并排进卡片

```python
left, right = st.columns(2, gap="medium")

with left:
    with st.container(border=True):
        st.subheader("24 小时分布")
        st.caption("按执勤开始时间的小时统计")
        # 折线图

with right:
    with st.container(border=True):
        st.subheader("月度分布")
        st.caption("每月执勤天数")
        # 柱状图
```

容器只负责分组；不要在一张卡片里再套多层容器。窄屏时 `st.columns` 会自动堆叠，图表用 `width="stretch"` 跟随容器宽度。

### 4.2 图下补口径与数据表

```python
st.caption("高峰时段：" + "、".join(f"{hour} 时" for hour in peak_hours))
with st.expander("查看数据表"):
    st.dataframe(df_hour.reset_index(), width="stretch", hide_index=True)
```

口径说明让读者知道图在统计什么；`expander` 收起数据表，方便读屏与核对，又不占首屏。

### 4.3 明细收尾

按「总览—趋势—明细」排列，最后给当年记录：

```python
detail = [row for row in records if str(row["start_time"]).startswith(year)]
if not detail:
    st.info(f"{year} 年该人员没有执勤明细。")
else:
    render_table(detail, columns=["id", "workstation_id", "start_time",
                                  "end_time", "status"], ...)
```

**做错会看到什么**：两张图上下堆叠且很窄 → 没有用比例列；图表右侧被截断 → 写了固定宽度；空年份出现一张空白图 → 没先判断数据。

**验收**：首屏能看到四个指标；两张图并排；切到 2025 年三处提示都出现且没有图；窄屏下两张图上下堆叠、不溢出。

## 常见错误对照

| 报错/现象 | 原因 | 处理 |
| --- | --- | --- |
| 主题不生效 | 没重启，或键名拼错 | 重启；对照 19.1 的键名表 |
| 指标数字对不上 | 手填数字，或字段名写错 | 从接口取；核对 `total_duty_*`、`total_records` |
| 图表空白 | `data` 不是 `DataFrame`，或 `x`/`y` 列不存在 | 先 `pd.DataFrame(...)`，再确认列名 |
| 横轴不是小时/月份 | 没用 `set_index`，也没写 `x=` | `set_index("hour")` / `set_index("month")` |
| 两张图颜色不一致 | 各自写了不同颜色 | 抽一个 `CHART_COLOR` 常量 |
| 图表太窄或溢出 | 固定宽度，或没用比例列 | `st.columns` + `width="stretch"` |
| 空年份仍画图 | 没判断记录数 | 先筛有计数的行，空则 `st.info` |
| 页面很花 | 主色不止一个，又加 CSS | 收拢到一个主色；先用主题，不用 CSS |
| 指标与明细对不上 | 明细按 `start_time` 年份过滤，指标按接口口径 | 统一年份；跨天记录看口径说明 |
| 切页后主题丢失 | 主题写在页面级 CSS 里 | 主题只放 `.streamlit/config.toml` |
