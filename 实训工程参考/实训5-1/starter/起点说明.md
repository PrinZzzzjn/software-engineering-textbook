# 实训 5-1 学员起点说明

本目录就是综合实训 **4-1 的六文件模块产物**：`app/` 及 `app/modules/department/` 中的 `controller.py`、`service.py`、`crud.py`、`model.py`、`schema.py`、`param.py` 均与 4-1 完成态逐字一致，三个 `__init__.py` 也一并保留。这里不是 TODO 骨架，**不要重写六个模块文件，也不要新增模块文件**。

自己的 4-1 设计文档与接口验证记录应作为另外两份学习产物继续保留，并在本实训结束时同步目录说明。本起点只承载代码迁移部分。

## 根目录待补清单

复制本目录作为自己的工作目录后，按分步指南在根目录补齐：

- [ ] `main.py`：创建 FastAPI 应用、`/health`、以 `prefix=""` 挂 department 路由。
- [ ] `requirements.txt`：只写 `fastapi`、`uvicorn`。
- [ ] `.env.example`：写配置变量与示例值；本阶段只有 `DEBUG=True`。
- [ ] `.gitignore`：排除 `venv/`、`__pycache__/`、`*.pyc`、`.env`、`*.db`、`logs/`、`.pytest_cache/`。
- [ ] `README.md`：写启动命令与实际目录说明。
- [ ] 按指南建立虚拟环境并完成 Git 两次初始提交、分支合并及一次冲突解决。

起点故意不放上述根目录文件，也不放 `.env`、`venv/`、`.git/`、数据库、`app/core/` 或 `tests/`。`.env` 由本机从示例复制，虚拟环境与 Git 仓库由命令生成；数据库和第 12 章测试目录都不属于本实训。

## 起点检查

在已安装 FastAPI 的环境中，于本目录执行：

```powershell
python -c "from app.modules.department import controller; print(controller.router.prefix)"
```

预期输出 `/departments`。此检查只证明 4-1 模块可导入；根 `main.py` 尚未补齐前，不能执行 `uvicorn main:app`。
