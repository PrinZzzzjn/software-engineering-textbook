### 4.3 制造并解决一次真实冲突

先在 `feature/health-review` 将同一返回行改为 `review: "feature"` 并提交，再在 main 改为 `review: "main"` 并提交，最后合并：

```powershell

(Get-Content -Raw .\main.py).Replace('return {"status": "healthy", "version": "0.1.0"}', 'return {"status": "healthy", "version": "0.1.0", "review": "feature"}') | Set-Content -Encoding ascii -NoNewline .\main.py
git add main.py
git commit -m "feat: record feature health review"
git switch main
(Get-Content -Raw .\main.py).Replace('return {"status": "healthy", "version": "0.1.0"}', 'return {"status": "healthy", "version": "0.1.0", "review": "main"}') | Set-Content -Encoding ascii -NoNewline .\main.py
git add main.py
git commit -m "feat: record main health review"
```
