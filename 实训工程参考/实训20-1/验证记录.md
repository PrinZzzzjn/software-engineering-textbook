## 二、逐项证据

### 2.1 统一错误映射

`components/errors.py` 共 45 行，映射表：

| 状态码 | 组件输出 | 后续动作 |
| --- | --- | --- |
| 401 | 写入 `login_notice`「登录已过期，请重新登录」 | 清空会话 + `st.rerun()` |
| 403 | 「当前账号没有权限执行该操作」 | 不重试 |
| 404 | 「数据不存在，可能已被删除」 | 刷新列表 |
| 422 | 「提交内容有误：<detail>」 | 按字段修正 |
| 500 | 「服务器开小差了，请稍后重试或联系管理员」 | 看后端日志 |
| 0 | 「无法连接后端服务：<detail>」 | 检查服务 |

自测用 `AppTest.from_string` 真渲染 5 个分支：

| 探测 | 结果 |
| --- | --- |
| 404 `Department not found` | 显示「数据不存在，可能已被删除」 |
| 422 `full_name: ... at most 100 characters` | 显示「提交内容有误」并保留 `100` |
| 500 `Traceback ... SECRET-TOKEN` | 显示「稍后重试」，不含 `Traceback` 与 `SECRET-TOKEN` |
| 403 `Forbidden` | 显示「当前账号没有权限执行该操作」 |
| 0 `Connection refused` | 显示「无法连接后端服务」 |

401 不用脚本探测（会 `st.rerun()` 循环），由第 9 节真令牌失效场景验证：页面显示「登录已过期」、回到登录页、`access_token` 已清除。

源文件级检查：五页各处的 `except api.ApiError` 与 `show_api_error(exc)` 数量一一对应（共 17 处），`st.error(exc.detail)` 在三页中已不存在。
