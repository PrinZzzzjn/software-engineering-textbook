# 实训 20-1 教师版与学员版差异说明

## 一、教师版包含什么

| 内容 | 教师版 | 学员版 |
| --- | --- | --- |
| 教材步骤与验收标准 | `README.md`、`分步实现指南.md` | 保留 |
| 十步联调清单 | 完整表格 + 自动断言 + 实际结果 | 给空白清单模板，学员自己走 |
| 排查记录 | 两条完整示例（422 列表、401 误判） | 给顺序与模板，不给结论 |
| 统一错误组件 | 完整 `components/errors.py` | 给状态码与提示要求，学员自己写 |
| 五页改造 | 17 处全部改完 | 给一处示例，其余自己改 |
| 交付清单 | 六类完整样例 | 给模板，学员填 |
| 已知问题与展示提纲 | 完整样例 | 给结构与时长，学员填 |
| 自测脚本 | `verify_app.py` 144 项 | **不提供** |
| 验证记录 | 全量证据 | **不提供** |
| 难度评分与接缝表 | 提供 | **不提供** |

## 二、学员必须自己完成的部分

1. 按十步清单走一遍主流程，逐步记录期望与实际；
2. 补未登录、空结果、重复提交三条边角；
3. 选一个失败步骤，按「现象 → 状态码 → detail → 日志 → 定位」写完整排查记录；
4. 新建 `components/errors.py`，写 401/403/404/422/500/0 六类提示；
5. 把五页的 `try/except` 改为 `show_api_error(exc)`，取数失败后 `st.stop()`；
6. 处理 401：清会话、回登录页、说明原因；登录页 401 保持单独提示；
7. 补齐交付清单、已知问题与三分钟展示提纲；
8. 回归 18-1 写操作与 19-1 仪表盘。

## 三、允许提供的骨架

教师可以给不含映射细节的骨架，例如：

```python
def show_api_error(exc) -> None:
    """把接口错误转成用户可读提示。"""
    # 学员按 401/403/404/422/500/0 补分支
```

页面改造只给一处示例：

```python
except api.ApiError as exc:
    show_api_error(exc)
    st.stop()
```

但不得提供：六类状态码的完整分支、401 清会话与重跑的顺序、五页 17 处的全部改法、`verify_app.py` 的断言、十步联调的实际结果。

## 四、评分点建议（100 分）

| 维度 | 分值 | 观测点 |
| --- | ---: | --- |
| 十步联调 | 25 | 十步齐全；每步有期望与实际；三条边角至少一条 |
| 排查记录 | 20 | 顺序完整；能指出前端/接口/字段；修复后重跑清单 |
| 统一错误 | 25 | 六类提示齐全；401 清会话回登录；500 不泄露堆栈；五页都接入 |
| 交付清单 | 15 | 六类齐全；启动说明与测试账号可照做 |
| 已知问题与展示 | 10 | 已知问题说清影响与规避；三分钟四段不超时 |
| 回归 | 5 | 18-1 写操作与 19-1 仪表盘未被改坏 |

## 五、常见不合格形态

| 形态 | 问题 | 扣分建议 |
| --- | --- | --- |
| 只点单页就交 | 页面之间断在登录态或刷新 | 联调项不得分 |
| 只测正常路径 | 权限、空数据、重复提交未覆盖 | 联调项扣分 |
| 401 各页各写 | 行为不一致，容易反复弹提示 | 统一错误项扣分 |
| 500 显示堆栈 | 泄露服务器信息，用户看不懂 | 统一错误项不得分 |
| 422 显示英文列表 | 未压平、未加中文前缀 | 统一错误项扣分 |
| 交付清单缺已知问题 | 问题藏到验收才爆 | 交付项扣分 |
| 展示变成功能罗列 | 三分钟讲不完，边界不清 | 展示项扣分 |
| 为改提示动坏写操作 | 18-1 功能回退 | 回归项不得分，并要求修复 |
| 伪造 403/500 场景 | 数据或状态被污染 | 排查与统一错误项按未验证处理 |
