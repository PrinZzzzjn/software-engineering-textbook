## 二、教学目标与教材映射

完成本实训后，学生应能：

1. 按用户真实路径完成前端联调，记录每一步的期望与实际。
2. 按「现象 → 状态码 → detail → 后端日志 → 定位页面/接口/字段」的顺序排查问题。
3. 识别非状态码问题（空白页、状态错乱、重复提交）并给出排查方向。

## 三、边界与不变量

### 3.1 目录与职责

| 位置 | 职责 | 本工程做法 |
| --- | --- | --- |
| `components/errors.py` | 状态码 → 用户提示 | 新增；`show_api_error(exc)` 一处映射 |
| `app.py` | 入口、登录门禁、后端连通性 | 健康检查也走统一组件 |
| `auth.py` | 登录、登出、`require_login` | 侧边栏健康检查走统一组件；登录页 401 仍单独提示 |
| `api_client.py` | 地址、超时、令牌、错误四统一 | 不变；401 先清令牌再抛 `ApiError` |
| `components/table.py` | `render_table` 与 `pagination_bar` | 原样复用 |
| `components/feedback.py` | `set_flash` / `show_flash` | 原样复用 |
| `pages/*.py` | 业务读写 | 只替换异常处理，业务逻辑与状态规则不变 |
| `.streamlit/config.toml` | 主题与浏览器配置 | 沿用 19-1 |
| `verify_app.py` | 自测 | 在 119 项基础上增加统一错误 15 项与十步联调 10 项 |

### 3.2 统一错误映射

| 状态码 | 含义 | 提示 | 后续动作 |
| --- | --- | --- | --- |
| 401 | 没登录 / 令牌过期 | 清会话，回登录页提示「登录已过期」 | `st.rerun()` |
| 403 | 登录了但没权限 | 「当前账号没有权限执行该操作」 | 不重试 |
| 404 | 资源不存在 | 「数据不存在，可能已被删除」 | 刷新列表 |
| 422 | 参数校验失败 | 「提交内容有误：<字段原因>」 | 按字段修正 |
| 500 | 后端异常 | 「服务器开小差了，请稍后重试或联系管理员」 | 看后端日志 |
| 0 | 连不上后端 | 「无法连接后端服务：<原因>」 | 检查服务是否启动 |

- 提示里不出现令牌、密码与服务器路径；堆栈只留在后端日志；
- 登录页的 401 是账号密码错误，由 `auth.render_login()` 单独提示，不进统一映射；
- 空数据不是错误，仍用 `st.info`。

### 3.3 用户路径与联调口径

十步顺序固定：未登录访问 → 登录 → 列表 → 搜索 → 新增 → 编辑 → 删除 → 统计 → 切换条件 → 退出。每一步都要写期望与实际；失败先记录，全部走完再按影响排序修复。

### 3.4 不做的范围

- 不新增业务页面与后端接口，不改字段与状态码；
- 不改 18-1 的写操作、守卫、分页与反馈规则；
- 不改 19-1 的主题、图表与仪表盘布局；
- 不用自定义 CSS 或额外依赖修样式；
- 不改教材正文；差异记录在 `验证记录.md`。

## 六、操作步骤

1. **按路径联调（45 分钟）**：从「未登录直接访问单位页」开始，按十步清单逐项走；每步先写期望，再记录实际，失败的只记录不立刻改。主流程走完后补三条边角：未登录、空结果、重复提交。
2. **排查问题（40 分钟）**：挑一个失败步骤，按「现象 → 状态码 → detail/返回体 → 后端日志 → 定位页面/接口/字段」顺序记录；分清 401（没证件）与 403（证件不够级别），500 先看后端日志。
3. **统一错误（35 分钟）**：新建 `components/errors.py`，按 401/403/404/422/500/0 写映射；每个页面把 `try/except` 改为 `show_api_error(exc)`，取数失败后再 `st.stop()`；登录页 401 保持单独提示。
4. **整理与展示（40 分钟）**：补齐交付清单（代码、截图、联调记录、错误记录、已知问题、启动说明），按「一句话做了什么 → 演示主流程 → 说一个排查过的故障 → 说一个已知问题」写三分钟提纲并计时演练。

详细代码与验收见 [分步实现指南.md](分步实现指南.md)。

## 十、常见问题与排错

| 现象 | 先查什么 |
| --- | --- |
| 页面空白 | 接口是否返回；是否有未捕获异常；`st.stop()` 位置 |
| 状态错乱 | `session_state` 键冲突或未清理；切换页面时筛选是否复用同名 key |
| 重复提交 | 按钮是否禁用；提交后是否 `st.rerun()` |
| 跨域失败 | 后端 CORS 与前端基地址 |
| 401 反复弹 | 是否在 `show_api_error` 里清会话并 `st.rerun()` |
| 404 提示不出现 | 是否仍在页面里直接 `st.error(exc.detail)` |
| 422 显示成列表 | `api_client` 是否把 detail 压平成一句话 |
| 500 提示带堆栈 | 是否把 `detail` 直接拼进提示 |
| 提示泄露令牌 | 是否把请求头或整段异常字符串拼进提示 |
| 空结果被当错误 | 空列表应用 `st.info`，不是 `st.error` |
