# 实训 10-1 学员版差异说明

> 完整版（本目录 `项目/`）→ 学员版（`starter/` + 课堂任务）的裁剪口径。
> 原则：保留「规则怎么想、怎么排、怎么测」的训练价值，去掉机械重复与教师验收材料。

## 一、直接保留

| 内容 | 说明 |
| --- | --- |
| 9-1 完成态全部代码 | 即 `starter/`：department、personnel、user、core、23 项测试 |
| `duty_record/model.py`、`schema.py`、`param.py`、`controller.py` | 表结构、出入参、路由骨架是本章的既定输入，不让学生重复造 |
| `duty_record/crud.py` 的列表、点查、写、删 | 与第 6/7 章同构，保留以减少机械劳动 |
| `workstation/` 六文件 | 作为「已提供模块」发放（见难度评分建议 1）；不在本章考核 |
| `main.py` 的装配与 seed | 保留；只把两个新 `include_router` 与两组 seed 作为「已给」 |
| README 的规则清单七列 | 作为任务书模板，学生填自己的版本 |

## 二、必须删除或留空

| 位置 | 处理 | 原因 |
| --- | --- | --- |
| `duty_record/service.py` 的 `_validate_duty_record` 函数体 | 留函数签名与注释，清空 4 段判断 | 本章核心 |
| `duty_record/crud.py` 的 `find_overlap` | 留签名与 docstring，清空查询 | 重叠条件要学生自己写 |
| `duty_record/service.py` 的 `create_duty_record` | 保留「先校验后写入」的注释与两行调用 | 训练事务纪律，但不让学生猜结构 |
| 规则相关测试（约 9 项） | 删除 | 避免直接给出答案与边界 |
| 参赛/验收材料 `验证记录.md`、`难度评分.md`、`接缝表.md`、`分步实现指南.md` | 不进入学员版 | 教师用 |

## 三、替换为课堂任务

| 完整版 | 学员版替换 |
| --- | --- |
| 完整 `tests/test_api.py`（26 项） | 保留健康检查、哨位 CRUD 1 项、执勤记录正常新增 1 项；其余改为 TODO 列表 |

## 四、建议的学员版文件结构

```text
学员版/
├── 项目/                       # 9-1 完成态 + workstation 完整模块
│   ├── app/modules/workstation/    # 已提供
│   ├── app/modules/duty_record/    # 六文件，规则与重叠查询留空
│   ├── main.py                     # 已装配、已 seed
│   └── tests/test_api.py           # 3 项冒烟
├── 任务书.md                   # 三句需求 + 七列空表 + 验收标准
└── 提交模板.md                 # 规则清单、用例、运行记录
```

## 五、评分建议（与验收标准对应）

| 项 | 分值 | 判定 |
| --- | ---: | --- |
| 规则清单七列完整、有需求原句 | 15 | 缺列或对不上原句扣分 |
| 三条规则实现且顺序正确 | 30 | 顺序错误按半对处理 |
| 重叠条件与首尾相接边界 | 20 | 边界错一处扣 10 |
| 失败无残留（先校验后写入） | 15 | 有脏数据不得分 |
| 用例覆盖正常/冲突/边界 | 15 | 每缺一类扣 5 |
| 回归与仓库卫生 | 5 | 9-1/8-1 用例失败或提交 db/venv 扣分 |

## 六、差异化

- **基础较弱**：只要求规则一、二，规则三给 `find_overlap` 的查询，学生补 `service` 判断；测试只要求包含与首尾相接两例。
- **学有余力**：追加「已停用哨位不可排班」「跨天执勤」两条规则，并把五类区间改写成参数化用例（对应教材例 10-2）。
