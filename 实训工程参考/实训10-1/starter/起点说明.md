# 实训 10-1 起点说明

本目录是 **实训 9-1 的完成态**，作为 10-1 的学员起点。它包含：

- department、personnel、user 三个模块（六文件体例）；
- `PBKDF2` 盐哈希 + `TOKEN_STORE` 认证，以及 `get_current_admin_user` 管理员依赖；
- 9-1 的 23 项教师测试（`tests/test_api.py`）；
- `main.py` 的幂等 seed：D001/D002、P001/P002、`admin/admin123`。

起点中**没有** `workstations` 与 `duty_records` 表，也没有对应模块；`GET /workstations` 与 `GET /duty-records` 应为 404。这正是 10-1 要补的内容。

使用方式：

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m uvicorn main:app --port 8000
```

先确认起点可跑：`GET /health` 200；`GET /departments` 与 `GET /personnel` 的 `total` 都是 2；`admin/admin123` 登录 200；`GET /users` 匿名 401、管理员 200。
