# duty-simplified 接口契约清单

> 事实源：`项目参考/duty-simplified/`（后端完整参考工程）
> 用途：前端实训、各阶段快照、接缝核对的唯一接口依据；与教材不一致处以此为准并记入「已知差异」
> 认证：`Authorization: Bearer <token>`；token 存内存 `TOKEN_STORE`，服务重启即失效
> 列表响应统一：`{items: [...], total: n}`；排序后端固定，前端不传 sort_by
>
> **教学链权限演进（以本节为准）**：从实训 9-1 起，department、personnel 的写接口（POST/PUT/DELETE）要求管理员；实训 10-1 新增的 workstations、duty-records 同样「读公开、写管理员」。`duty-simplified` 参考工程本身未给这些写接口加依赖，实训快照按教学链执行；前端实训一律使用 `admin/admin123` 演示写操作。

## 状态码约定

| 状态码 | 含义 | 出现场景 |
| --- | --- | --- |
| 200 | 成功 | 列表、详情、统计、/me、/health |
| 201 | 已创建 | 所有 POST 新增 |
| 204 | 无内容 | 所有 DELETE 删除（无响应体） |
| 400 | 请求错误 | 重复资源、业务校验失败 |
| 401 | 未认证 | 缺 token / token 无效 |
| 403 | 无权限 | 非管理员访问管理接口 |
| 404 | 不存在 | 详情/修改/删除找不到资源 |
| 422 | 参数校验失败 | FastAPI 默认；`detail` 为字段错误数组，其余错误为字符串 |

> 13-1 起，五类列表统一声明 `*ListOut` 输出模型，响应结构仍是 `{items, total}`；批量写入能力只在 `duty_record/service.py` 内部，未开放 HTTP 端点。

## 用户模块 `/users`

| 方法 | 路径 | 认证 | 请求 | 响应 | 状态码 |
| --- | --- | --- | --- | --- | --- |
| POST | `/users` | 否 | `{username: str, password: str}` | `{id, username, role, is_active}` | 201 / 400 |
| POST | `/users/login` | 否 | `{username: str, password: str}` | `{access_token, token_type:"bearer", user:{id,username,role,is_active}}` | 200 / 401 |
| GET | `/users/me` | Bearer | — | 当前用户 dict | 200 / 401 |
| GET | `/users` | admin | `?page=1&page_size=10` | `{items:[{id,username,role,is_active}], total}` | 200 / 401 / 403 |
| PUT | `/users/{user_id}` | admin | `{role?: "admin"\|"normal", is_active?: 0\|1}` | `{id, username, role, is_active}` | 200 / 401 / 403 / 404 |

字段约束：username 1–100，password 注册 6–128 / 登录 1–128；role 仅 admin/normal，is_active 仅 0/1。

## 前端对接要点

- 登录：`POST /users/login`，取 `access_token` 存 `session_state["access_token"]`，取 `user` 存 `session_state["current_user"]`。
- 后续请求头：`Authorization: Bearer <access_token>`。
- 列表默认参数：`page=1&page_size=10`；翻页改 page。
- 删除成功无响应体，前端按 204 判定。
- 后端默认 `127.0.0.1:8000`；前端可用环境变量 `DUTY_API_BASE_URL` 覆盖。
- 内网 `/docs` 可能空白（Swagger UI 走公网 CDN），用 `swagger-ui-bundle` 本地化；`/openapi.json` 不受影响。
