## 判据速记

1. 标题标记「讲的东西换了」：对象、范围、阶段、问题。
2. 同一条论证链不切（现象→原因→修正、命令→参数→预期、定义→例子→边界）。
3. 不为篇幅设标题；补充说明、提示、代码说明行不立。
4. 常规小节 0–3 条，并列结构 ≤5 条。
