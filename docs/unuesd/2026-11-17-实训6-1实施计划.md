**接口范围**：只实现 3 个，与教材验收表一致。

| 接口 | 方法 | 成功 | 失败 |
| --- | --- | --- | --- |
| `/api/v1/users` 注册 | POST | 201 + `UserOut` | 重名 400；字段不合法 422 |
| `/api/v1/users/login` 登录 | POST | 200 + `{access_token, token_type}` | 密码错 401 |
| `/api/v1/users/me` 当前用户 | GET | 200 + `{id, role}` | 未带/无效令牌 401 |

**`main.py` 的新形态**（关键：两个路由都挂，建表在最后）

```python
from fastapi import FastAPI

from app.core.database import Base, engine
from app.modules.user import controller as user_controller
from app.modules.user import model  # noqa: F401  建表前必须先导入模型
from app.modules.workstation import controller as workstation_controller

app = FastAPI(title="Duty API", version="0.1.0")


@app.get("/health")
def health():
    return {"status": "healthy"}


app.include_router(workstation_controller.router, prefix="/api/v1")
app.include_router(user_controller.router, prefix="/api/v1")

Base.metadata.create_all(bind=engine)
```
