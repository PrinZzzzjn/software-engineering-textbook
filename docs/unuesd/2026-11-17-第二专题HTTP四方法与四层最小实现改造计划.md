## 一、改造目标

把两项内容前置为第二专题前期的核心，并给出可独立完成的动手环节：

1. **HTTP 四方法最小实践**：学生能在一个可运行应用里写出 GET / POST / PUT / DELETE，说清四种操作对应的成功与失败状态码，并能解释幂等性。
2. **FastAPI 四层最小实现**：学生能按 controller / service / crud / model 四层加 schema / param 两个边界，把一组接口拆成六个文件并跑通，说明请求在六文件中的走向。

两项内容都要求"写出来、跑起来、验过状态码"，不止于读懂。
