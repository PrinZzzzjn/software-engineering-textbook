# 第 15 章《常用界面组件》内容重构设计

> 方案：五节组件用法 + 实训项目案例（甲）。经对话确认后实施。

## 一、问题

原章以"怎样用组件搭出可用的管理界面，而不是每个页面复制一套代码"开篇，15.1 先讲组件复用，15.2 才把组件分类压缩成一节，15.5–15.6 讲列表过滤与假数据验证。主线是"页面模板与复用"，组件类型与基本用法反而成了配角。这与本章"认识常用组件、掌握基本用法"的定位不符，也把课次 17 教案"输入 → 展示 → 交互 → 表格配置 → 案例"的顺序倒置了。

## 二、目标

1. 以组件类别为主线：输入、展示、交互、容器，逐类讲用途、返回值、关键参数与最小示例。
2. 表格列配置归入展示组件；表单归入输入组件；容器与布局单列一节。
3. 组件复用退出主线，降为实训课后扩展中的可选技巧。
4. 实训改为"项目案例：部门管理页"，把四类组件组合起来，用假数据完成指标、表格、筛选与新增。
5. 保留原章的组件 API、表格配置、表单与空态处理等可复用内容，不新增未经验证的事实。

## 三、新结构

| 节 | 标题 | 内容 |
| --- | --- | --- |
| 15.1 | 组件与页面 | 组件定义回顾、四类划分、按用户动作选组件、查文档、本章边界；图 15-1 |
| 15.2 | 输入组件 | 文本、数字、选项、日期、文件；返回值与重跑；`st.form` 与提交 |
| 15.3 | 展示组件 | `st.dataframe`、`st.table`、`st.metric`、`st.json`、文本展示；`column_config` 列配置 |
| 15.4 | 交互组件 | `button`、`checkbox`、`toggle`、`slider`、`download_button`；返回值语义 |
| 15.5 | 容器与布局组件 | `columns`、`container`、`expander`、`tabs`、`sidebar`；比例分区，页面级布局留第 16 章 |
| 实训 15-1 | 项目案例：部门管理页 | 指标卡、搜索筛选、中文表格、新增表单、空态提示；四类组件各用上 |

- 原 15.2 的组件分类表、输入/展示/交互示例：拆入新 15.1–15.4，保留组件与参数。

- 原 15.4 表格列配置：移入新 15.3，作为展示组件的配置小节。
- 原 15.5 列表过滤、15.6 假数据验证：移入实训步骤，作为案例的"先过滤再显示"与"假数据边界"。
- 原 15.1 组件复用：删除主线讲解；`render_table` 作为实训课后扩展的可选技巧保留。
- 原 15.2 的三类图：改为四类图（增加容器组件）。
