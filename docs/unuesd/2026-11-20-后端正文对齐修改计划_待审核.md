## 〇、先澄清一个事实：`/api/v1` 到底有没有

用户提出"后端项目的路由中没有 `/api/v1`"。核对代码后的准确结论是：

- **各模块的 `controller.py` 确实没有写 `/api/v1`**，只写了资源名前缀，例如 `department/controller.py:9` 是 `router = APIRouter(prefix="/departments", ...)`。只看 controller 文件会得出"没有 `/api/v1`"的印象。
- **`main.py:23–28` 统一挂了版本前缀**：

  ```python
  app.include_router(user_controller.router, prefix="/api/v1")
  app.include_router(department_controller.router, prefix="/api/v1")
  ...  # 六个模块全部
  ```

  因此对外真实路径是 `/api/v1/departments`、`/api/v1/users/login` 等。
- **唯一例外是 `/health`**：`main.py:31` 用 `@app.get("/health")` 直接注册，不在版本前缀下。

**判定**：教材正文里写 `/api/v1/...` 是对的，不改。但由此暴露出一个真实偏差——教材多处写成**带尾斜杠**的 `/api/v1/departments/`，而代码是 `@router.get("")`，真实路径无尾斜杠（见 C3）。上一轮重建的前端按无尾斜杠实现，与代码一致，无需返工。
