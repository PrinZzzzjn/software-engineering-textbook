# 附录 I 术语速查（中英对照）

按首次出现的主题分组。正文首次出现时给中英对照，这里收口供翻阅；完整释义见 [术语表.md](术语表.md)。

## I.1 工程与需求

| 中文 | 英文 / 缩写 | 一句话 |
| --- | --- | --- |
| 软件工程 | Software Engineering | 用工程方法交付可维护的软件 |
| 生命周期 | SDLC | 需求→设计→编码→测试→部署→运维 |
| 用户故事 | User Story | 角色—目标—价值三句式需求 |
| 验收标准 | Acceptance Criteria | 可判定真假的需求判据 |
| 非功能需求 | NFR | 性能、安全、易用性等质量约束 |
| 评审 | Review | 用同一把尺子检查交付物 |

## I.2 后端与接口

| 中文 | 英文 / 缩写 | 一句话 |
| --- | --- | --- |
| 接口 / 应用程序接口 | API | 程序之间约定的调用方式 |
| 表述性状态转移 | REST / RESTful | 用资源 + HTTP 方法设计接口 |
| 超文本传输协议 | HTTP | 请求与响应的通信规则 |
| 状态码 | Status Code | 200/201/400/401/403/404/422/500 |
| JavaScript 对象表示法 | JSON | 前后端交换数据的文本格式 |
| 路由 | Route / Router | 把路径绑定到处理函数 |
| 依赖注入 | Dependency Injection / `Depends` | 把公共逻辑抽成参数传入 |
| 对象关系映射 | ORM | 用对象操作数据库表 |
| 数据校验模型 | Pydantic `BaseModel` | 声明请求/响应的字段与类型 |
| 令牌 | JWT | 登录成功后携带身份的凭证 |
| 接口文档 | OpenAPI / `/docs` | 由代码自动生成的接口说明 |

## I.3 前端与部署

| 中文 | 英文 / 缩写 | 一句话 |
| --- | --- | --- |
| 会话状态 | Session State | 页面重跑之间保留的数据 |
| 容器 | Container | 打包了运行环境的隔离进程 |
| 镜像 | Image | 容器的只读模板 |
| 镜像构建文件 | Dockerfile | 描述如何构建镜像 |
| 多服务编排 | Docker Compose | 一条命令启动多个容器 |
| 环境变量 | Environment Variable | 不写进代码的配置 |

## I.4 测试与质量

| 中文 | 英文 / 缩写 | 一句话 |
| --- | --- | --- |
| 单元测试 | Unit Test | 测最小单元的行为 |
| 集成测试 | Integration Test | 测多个部件连起来 |
| 测试客户端 | TestClient | 不起服务就能调用接口 |
| 回归 | Regression | 改动后原有功能失效 |
| 持续集成 | CI | 每次提交自动跑检查 |
| 版本控制 | Git / Commit | 记录演进、可回退 |

> 本书全部示例数据为教学模拟数据；术语按本表统一，避免同一对象出现多个叫法。
