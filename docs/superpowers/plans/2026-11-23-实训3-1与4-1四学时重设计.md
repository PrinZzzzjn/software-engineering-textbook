# 实训 3-1 与 4-1 四学时重设计实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把实训 3-1、4-1 的实践部分从 2 学时（90 分钟）改为 4 学时（180 分钟），重建 3-1/4-1 学员手册，补语法与操作讲解，削减周边负担，同时保持接口契约与 3-1→4-1→5-1 接缝不变。

**Architecture:** 教材章末实训块保留“任务 + 验收 + 时间表”，逐行语法讲解放到新建的 `实训手册/实训3-1/`、`实训手册/实训4-1/`；教师答案与自动测试继续留在 `实训工程参考/`。课时调整涉及课程计划、教材第 3/4/13/20 章、工程参考索引与 13-1/20-1 的必做切分。

**Tech Stack:** Markdown 文档、FastAPI 3-1/4-1 参考代码、Python 3.12、pytest、现有 `tools/check_links.py`。

**Spec:** `docs/superpowers/specs/2026-11-23-实训3-1与4-1四学时重设计-design.md`

## Global Constraints

- 1 学时 = 45 分钟；3-1、4-1 各 4 学时 = 180 分钟。
- 3-1 保持五个端点：`GET /health`、`GET /departments`、`GET /departments/{dept_code}`、`POST /departments`、`PUT /departments/{dept_code}`、`DELETE /departments/{dept_code}`；状态码 200/201/204/400/404；列表 `{items, total}`；删除 204 无正文。
- 4-1 保持六文件：`controller.py`、`service.py`、`crud.py`、`model.py`、`schema.py`、`param.py`；保留 `param.py` 与内存分页；状态码增加 422。
- 4-1 是 5-1 的起点；不得删文件、改文件名、合并六文件或移除分页。
- 3-1 学员最终 `main.py` 约 45 行有效代码；4-1 学员独立书写约 70–80 行（`crud` 约 20、`service` 约 35、路由函数约 25）。
- 不新增学员运行依赖；`swagger-ui-bundle` 只装在授课机 venv，由 `sitecustomize.py` 提供本地 `/docs`，不改学员 `main.py`。
- 命令以 Ubuntu bash 为主，PowerShell 作对照；每条命令给预期输出。
- 学员手册每阶段固定六段：本步目标 / 先看效果 / 语法卡片 / 代码与逐行解释 / 操作与检查点 / 常见错误与求助。
- 正文中文引号用弯引号；代码块内保持直引号和英文标点；不在代码块里混入全角括号。
- 本轮只重建 3-1、4-1 学员材料；5-1、8-1 旧手册不恢复。
- 第 3 章以未跟踪的 `03-后端开发框架 修改版.md` 为工作底稿；不改已跟踪的 `03-后端开发框架.md`，不做文件改名。
- 验收口径：教师走查 + Windows 静态核对，交付说明标注“待授课机验证”；不声称 ARM64 实测通过。
- 不提交 `venv/`、`__pycache__/`、`.pytest_cache/`、wheelhouse、数据库文件。

## Review Focus

- 学员从聊天软件或 Word 复制代码，带全角引号、全角括号、中文冒号，启动即 `SyntaxError`：每份指南必须有“代码输入规范”，代码块全部用直引号；检查时 grep 全角字符。
- 内网 `/docs` 空白，学员以为应用没启动：阶段 0 必须先测 `/docs`，空白按环境问题处理，并给 `/openapi.json` + `curl` 备用通道。
- 4-1 启动报 `ModuleNotFoundError: app` 或 `ImportError`：目录树、`__init__.py`、启动目录必须在阶段 0 写清楚，并给 `python -c` 自检。
- 删除接口返回 200 或带正文：204 的装饰器与“成功路径不 return”必须在阶段 7 单独讲，检查点要检查正文为空。
- 4-1 分页 `total` 写成当前页长度：阶段 5 必须用“第二页只剩一条”的例子说明 `total` 是切片前总数。
- 13-1/20-1 减为 2 学时后，旧文档仍写 180 分钟或完整任务：收尾时 grep “4 学时/180 分钟”，逐处确认。
