# 案例数据统一管理与编辑页面 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把执勤电子年鉴案例数据收进 `data/case_data.yaml` 单一事实源，提供 CLI 和本地 Streamlit 页面修改，并把全仓相关引用同步为一致取值。

**Architecture:** 先用 YAML 保存实体、别名、字段和同步策略；CLI 负责校验、生成 JSON、扫描引用与自动替换；Streamlit 页面只调用 CLI 暴露的同一组函数。教材、手册、工程与文档中的旧值通过登记过的别名逐处替换，历史 docs 与独立样本按例外清单保留。

**Tech Stack:** Python 3.12、PyYAML、标准库 json/pathlib/re、pytest、Streamlit AppTest。

**Spec:** `docs/superpowers/specs/2026-11-24-案例数据统一管理-design.md`

## Global Constraints

- 主线统一值：`D001 / P001 / W001`，地址 `一号营区 / 二号营区`，姓名与职级 `张伟 / 一级值班员`、`李娜 / 二级值班员`，哨位名 `一号哨位 / 二号哨位`，管理员 `admin / admin123`。
- D01/P01/W01、一号楼/一号营区、张三/张伟、班长/一级值班员等旧写法属于同一事实，必须同步；不能保留“教学简化差异”。
- `docs/` 下的历史设计/复盘文档默认不回改；检查时计入“历史记录”。
- 例外样本：`hand_calc_sample_1`（第11章5条手算记录）、`rule_sample_overlap`（第10章时间冲突判断）、`test_random_day`（第12章随机日期）、`not_found_examples`（D404/D99）。
- 不修改 `项目参考/duty-historical/`；它标记为主线外。
- 页面为本地作者工具，不做登录、数据库或多用户；启动命令 `streamlit run tools/case_data_editor/app.py`。
- 工程仍可独立启动；`data/case_data.json` 为生成产物，运行副本可被工程读取。
- 所有自动替换必须支持 dry-run，输出文件、旧值、新值和上下文；默认不直接写盘。

## Review Focus

- 别名重叠：`D01` 是 `D001` 的前缀，必须是整词/边界匹配，不能把 `D010` 改成 `D0010`；测试覆盖 `D01`、`D010`、`D001`、`/departments/D01`。
- 中文地址冲突：`一号楼` 在教学旧例中出现，但基线统一为 `一号营区`；测试确认替换后不残留旧地址（`docs/` 历史文档除外）。
- 同名不同事实：前端演示 `D003–D012` 只属 15-1，不进基准种子；测试确认 build 中数据集隔离。
- 历史文档例外：`docs/` 历史复盘不回改但 check 应能分类报告；测试确认 check 返回历史记录而不是失败。
- 工程可运行：同步后 10-1/11-1 的 pytest 与 15-1 的 AppTest 仍通过；抽测命令见 Task 6。

```python
def _load_seed_data():
    """读取仓库统一案例数据；找不到时回落到本文件内置常量。"""
    import json
    from pathlib import Path
    candidates = [Path(__file__).resolve().parents[n] / "data" / "case_data.json" for n in range(1, 7)]
    for p in candidates:
        if p.exists():
            return json.loads(p.read_text(encoding="utf-8"))
    return {}  # 回落到本文件已同步的字面量
```
`_seed_*()` 中从返回值取对应数据；若为空则用当前字面量。对每个工程重复相同改法。15-1 前端 `SEED_DEPARTMENTS` 同样改为读取 `frontend_demo.departments`，失败时用字面量。
