# 章首件「本章要解决的问题」去具体化 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按已批准的 D1–D6 判据，收紧 24 章「本章要解决的问题」中问题句之后的两段文字，使学员读到的是一类麻烦与一个方向，而不是一份待办清单。

**Architecture:** 原位改写，不动体例与位置。先建一个只读扫描器把 D2/D3 的禁用物变成可重复的检查，再以第 12、8 章为样板确认语感，随后按 01–13、14–24 两批推进，最后补裁决记录并跑全书门禁。

**Tech Stack:** Markdown 正文、Python 3 检查脚本（`tools/` 现有风格）、git。

**Spec:** `docs/superpowers/specs/2026-11-18-章首件去具体化-design.md`

## Global Constraints

- 只改 `软件工程实践-2.0/` 下各章 `## 本章要解决的问题` 一节内、加粗问题句**之后**的文字。
- 加粗问题句一字不改；`## 本章学习目标` 及其后全部内容不动。
- 不改章标题、节标题、编号、例题、习题、答案、实训、学时。
- 路径段禁用：数量与量词、顺序公式（`A → B → C`）、文件名、字段名、函数名、状态码、命令、章末结论；允许保留半句跨章边界与依赖。
- 现象段禁用：具体项目、页面、页码、地址、数值、人名；代码块、JSON、表格、截图、命令。
- 每章本节写完后必须过 D6：能否被复述成一张待办清单；能则不合格。
- 工具类章（14、15、19、21–24）保留工具名本身，去掉其 API、函数名与参数。
- 每完成一个任务提交一次，提交信息用中文，格式：`教材修订：章首件去具体化（<范围>）`。

## Review Focus

扫描器只能抓格式，抓不到下面五类问题；每处改写都要对照检查。

1. **修辞空转**：路径段写成「本章不急于给出模板，而是……」却没说方向，读者仍不知道本章关心什么。
2. **案例回流**：现象段去掉具体接口后，仍默认读者知道本课程项目，换成「那个部门页」之类的暗指。
3. **误伤边界**：为了去具体，把 06 章的认证/授权分工、21 章的「动手构建放到下一章」也删掉，读者失去位置感。
4. **工具章失焦**：把工具名一并删除，读者不知道这一章学的是什么对象。
5. **问题句被动**：改写时顺手润色加粗问题句，违反 Global Constraints。

规则与实现：

```python
#!/usr/bin/env python3
"""扫描各章「本章要解决的问题」，报告违反去具体化判据的表述。"""
import re
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent / "软件工程实践-2.0"
HEADING = "## 本章要解决的问题"
RULES = [
    (re.compile(r"```"), "代码块"),
    (re.compile(r"`[^`\n]+`"), "行内代码"),
    (re.compile(r"→"), "箭头"),
    (re.compile(r"(?<![\w.])[1-5]\d{2}(?![\w.])"), "状态码"),
    (re.compile(r"/api/|127\.0\.0\.1|localhost"), "地址"),
    (re.compile(r"\d+\s*(个|条|类|项|步|件|种)"), "数量+量词"),
    (re.compile(r"[二两三四五六七八九十]+\s*(个|条|类|项|步|件|种)"), "数量+量词"),
    (re.compile(r"[一二两三四五六七八九十]+\s*分钟"), "时长"),
    (re.compile(r"[（(][A-Za-z][A-Za-z /-]{1,30}[）)]"), "英文括注"),
]

def section_lines(path):
    lines = path.read_text(encoding="utf-8").splitlines()
    start = next((i for i, l in enumerate(lines) if l.strip() == HEADING), None)
    if start is None:
        return []
    end = next((i for i in range(start + 1, len(lines)) if lines[i].startswith("## ")), len(lines))
    return [(i + 1, lines[i]) for i in range(start, end)]

def main():
    problems = 0
    for path in sorted(ROOT.glob("[0-2][0-9]-*.md")):
        for lineno, line in section_lines(path):
            if line.startswith("## "):
                continue
            for pattern, label in RULES:
                if pattern.search(line):
                    problems += 1
                    print(f"{path.name}:{lineno}  {label}  {line.strip()[:60]}")
    print(f"\n共 {problems} 处")
    return 1 if problems else 0

if __name__ == "__main__":
    sys.exit(main())
```
