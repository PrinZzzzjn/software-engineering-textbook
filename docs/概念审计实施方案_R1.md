## 一、口径（本方案新增或确认）

1. **依据清单按专题集中，不逐章设**。每个专题只在最后一章章末列一次，覆盖本专题各章引用的标准、文献与报告。
2. 正文中的行内括注保留在首次引用处；专题依据表是该专题全部括注的汇总，二者对应，不重复解释。
3. 类型先按 12 类受控词表归一：标准定义 / 权威文献 / 官方报告 / 工具文档 / 工程实践 / 常用术语 / 课程定义 / 课程约定 / 教学安排 / 教学检查项 / 教学建议 / 教学示例。能对应标准的优先用标准原义，能对应文献的补作者年份；教学装置不冒充知识分类，正文写“本章按……”“本课程约定……”，不再使用“本书归纳”。
4. 不能对照原文核实的，登记表标「待核对原文」，正文不写“已验证”。
5. 不改写历史记录（`教材审核意见_2026-11-10.md`、`修订裁决记录_2.0.md` 等）；本轮口径变更登记在本文件与登记表。

## 四、每章流程

1. **抽取**：定位定义句、分类枚举（“三类/四步/五个文件”）、数字、标准号、带引号的权威表述。
2. **分拣**：逐条判为四类之一，或判为“无需标注”。
3. **定改法**：补括注 / 改措辞 / 标本书归纳 / 删除 / 标待核对原文。
4. **回填梳理稿**：写进该章随记的「梳理稿」，只列结论与需要作者拍板的点。
5. **改正文**：确认后同步学习目标、小结、自检、习题、98 与专题依据。
6. **登记**：写入 `docs/概念与依据登记表_3.0.md`。
7. **验证**：`tools/check_*.py` 全绿；本章无残留元话语；专题依据与正文括注一一对应。

## 五、判断标准

- **必须补依据**：定义（“X 是……”）、分类（“分为 N 类/层/步”）、比例与数字、标准名称与版本、被当作共识引用的观点。
- **可标本书归纳**：教学顺序、类比、选择启发式、章节框架、练习设计。
- **可删除**：既无来源、又不在学习目标内、也不承担教学功能的断言。
- **不强行补**：操作性描述、代码解释、项目内的约定；这些不冒充学术或标准结论即可。

## 六、验收

1. 每个专题有一个依据表，覆盖本专题所有行内括注；第 1 章不再单列。
2. 登记表中每章至少有首现概念行；「待核对原文」集中可查。
3. 正文没有无来源的“学术口吻”断言；本书归纳均已标明。
4. 门禁 10 项 GREEN；章内与 98 题头一致。
5. 专题依据不改变章节结构、不新增学习目标。
