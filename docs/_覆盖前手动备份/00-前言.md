# 软件工程实践

## 本书写给谁

本书写给有一点点 Python 基础、但几乎没有项目经验的读者：你会写基本语法，但没经历过“多人协作、长期维护、上线运行”的完整系统。本书不假设你学过 SQL、HTTP 或 Git，这些内容会在书里从零讲起。

读完这本书，你应该能独立完成一个中小型信息管理系统的需求、设计、后端、前端、测试与容器化部署，并能说清每一步“为什么这样做”。

## 怎么用这本书

本书共 26 章，按“软件工程基础与需求 → 后端服务开发 → 前端界面构建 → 软件部署与系统交付”四篇组织，章号与课程课次一一对应。

每章固定四段：

1. 概念讲解：先讲“为什么”，再给定义与例子；
2. 示范例题：完整展示解题或实现过程，跟着做一遍；
3. 引导练习：先自己想，再逐层展开提示与解答；
4. 独立习题：先独立完成，再翻参考答案。

每章开头有“本章学习目标”，结尾有“本章小结”和自检清单。读完一章，用自检清单逐条问自己做到了没有；拿不准就回看对应小节，并用指定习题自测。

独立习题的答案与验证放在 `98-参考答案.md`，章内只留题干，建议先做后对。术语与符号查 `术语表.md`；综合迁移任务见 `99-表现性任务.md`。
