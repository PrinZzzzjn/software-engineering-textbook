- 位置：16.3（第 115–201 行，约 87 行）

- 原文证据：“这一节一次给出完整的客户端代码，比前面的示例长。第一遍先看结构与 `get` / `post` 两个入口，不必逐行记住……”；`**把请求收进一个客户端**`、`**只封装四件事**`
