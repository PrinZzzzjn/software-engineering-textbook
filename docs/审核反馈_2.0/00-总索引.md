## 一、怎么用

1. 读到哪章，打开对应文件，在 `## 随记` 下随手写。
2. 想法涉及两章以上、或属于全书结构 / 体例 / 术语 / 前后衔接的，写 [00-全书随记.md](00-全书随记.md)；记在当章也可以，我梳理时归并。
3. 随时说「梳理第 N 章」或「梳理已记录的章」。我会：定位原文 → 归类 → 给出具体改法 → 回填到该章「梳理稿」→ 更新本索引状态。
4. 你审「梳理稿」，说「可以改」我就改正文；有不同意见直接写在那节下面。
5. 全部梳理完 → 做一轮全书一致性复核 → 你再审一遍结果。

> 随记阶段只有一条约定：**想到就记，不用组织**。定位、归类、取舍、一致性由我负责。
