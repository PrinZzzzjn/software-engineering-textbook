- **反馈二（22.1 层顺序读起来奇怪）**：原因是原 22.1 同时塞了“镜像大/构建慢的来源、后端 Dockerfile、构建、运行验证”四件事，标题却只写“层顺序”。现在把“第一次构建、运行、验证”独立成 22.1，把“错误写法、缓存、层顺序”独立成 22.3，两节用一句过渡连接。
