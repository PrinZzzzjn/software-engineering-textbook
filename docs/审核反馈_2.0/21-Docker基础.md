### 我准备怎么改

- **修复两处 mermaid 渲染错误**：图 21-1 的节点标签统一加引号，并把方向改为 `flowchart BT`，让基础层在下、后续层向上叠加；21.6 的流程图里 `[/health + 日志]` 的 `[/` 会被 Mermaid 当成平行四边形节点，导致解析失败，改为带引号的普通节点，并补上图注 `图 21-2`。
- **21.3 补讲“为什么分层、层是什么”**：先从镜像体积与重复构建、重复分发的问题讲分层动机；再说明层由 `RUN`、`COPY`、`ADD` 等改动文件系统的指令产生，并逐条解释这三个指令；接着说明“生成一层”是这一步的文件系统改动快照，不是整个镜像的副本，层按 Dockerfile 的书写顺序叠加，指令的拆分方式决定层的划分，容器运行时在只读层之上再加可写层；最后才给三条规则、缓存表和 Dockerfile 排序理由。
- **修正图 21-1 的概念错误**：原图把 `CMD` 标成“启动层”，但 `CMD` 是启动配置、不产生文件层；新图改标“启动配置”，并在图后说明。
