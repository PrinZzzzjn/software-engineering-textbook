# 节内小标题（x.y.N）划分与命名规范（草案 v1）

日期：2026-11-18　状态：v2 已执行（2026-11-18），待签字

## 一、为什么要有这份规范

同一本书里，小标题在三种状态下摆过：先是每章十来个小标题（C15 认定"太碎"），后来 14–24 章整体删除、改成连续段落（R8），1–13 章则保留到 134 个。结果同一本书前后两种排法，读者翻到第 14 章会突然失去节内导航。

本次要把 24 章统一：**该有小标题的地方有，不该有的地方没有，且判断标准写下来、能复核。**

## 二、判据：标题标记的是「讲的东西换了」

三个检验，前两个都通过才立标题。

**T1 对象或范围换了**　标题之下讲的东西不再是上文那一样：换了对象（构建 → 运行）、换了范围（整个项目 → 单个模块）、换了阶段（先能跑 → 再优化）、换了问题（为什么慢 → 怎样避免）。

**T2 读者会跳读**　读者可能只想看其中一块，标题能让他直接定位。若两块必须连着读才成立（上是下的前提、下是上的展开），不立标题。

**T3 各有结论**　相邻两块各自给出结论或可执行的结果，而不是同一条论证的上下句。

## 三、不立标题的情形（本规范的重点）

- **同一条论证链不切**：现象 → 原因 → 修正；命令 → 参数 → 预期输出；定义 → 例子 → 边界。这些是一条链上的环节，只在链条开头立一个标题。
- **不为篇幅设标题**：段落长、要分页、一屏放不下，都不是理由。标题是按内容分的，不是按长度切的。
- **补充说明不立**：反例、提示、代码说明行、对上一段的解释。
- **小节开头第一段不立**：节标题已经覆盖。

> 上一版按"正文字数 ≥60 字"设门槛，本质仍是按篇幅切。实际试排后小标题过多（第 9 章 15 条、第 22 章 15 条），故改为本节的结构判据。

## 四、数量

- 常规 `##` 小节：**0–3 个**。
- 并列结构（逐文件、逐规则、逐步骤、逐类型）：**≤5 个**。
- 一章总量约为节数的 1.5 倍；超出说明在按篇幅切分。
- 非并列却超过 3 个：先考虑把 `##` 拆成两个小节，而不是在节内继续加标题。

## 五、命名（沿用并补充 C15 R1）

1. **体式**：名词短语或紧凑的内容短语，4–16 字（西文词按 2 字计）；同节内结构平行（都"对象 + 动作"或都"对象"）。
2. **可指认**：优先具体对象、代码名、动作与可观察结果（如「过滤先于计数」「六个文件的分工」）。判断法：读完标题能说出"这一段要看哪样东西、做哪件事"。
3. **禁用概括后缀词**：职责、构成、契约、约束、边界、机制、模型、体系、适用、定位、取舍、维度、原则。
4. **禁用**：疑问句、第一/二人称、箭头、感叹号、完整句子（句号结尾一律不是标题）。
5. **不加反引号**：与全书 213 个 `###` 里 211 个不带反引号的现状一致；正文里再正常用代码标记。

## 六、编号与呈现

- 编号 **x.y.N**：随所在 `## x.y` 小节递增，换小节从 1 重新数。不手写，由转换脚本生成。
- **不进目录、不进书签、不被 `N.1.x` 回指**；跨章引用仍指向 `##` 层编号。
- 排版：11 pt 黑体加粗，段前 1.8 em、段后 0.7 em（已在样章验证）。

## 七、与既有口径的关系

本规范**修订 C15 R2 第 4 条**。原文是"节内加粗小标题不加编号、不进目录、不得被 `N.1.x` 回指"，现改为：

> 节内小标题按 `x.y.N` 编号印刷，仍不进目录、不被回指；命名与立标题条件见《节内小标题划分与命名规范》。

需在 `docs/修订裁决记录_2.0.md` 变更记录中追加一行，注明依据与生效范围（全 24 章）。

## 八、执行流程

1. **出对照表**（不动正文）：每章逐节列出「现有小标题 / 按新标准应删 / 应增 / 应改名」，附每处判断依据。
2. **样张三章**：各取一类——第 9 章（现有标题偏多且含薄标题）、第 16 章（R8 后无标题）、第 22 章（R8 后无标题且结构复杂）。
3. 你审样张与对照表，确认判据与命名。
4. **铺开其余 21 章**，逐章提交对照表；每章改完即出 PDF 页供你抽查。
5. 重编样书，编号自动生效；同步更新 `章节标题总表`（新增「节内小标题」列）与裁决记录。

## 九、可脚本检查的验收项

| 检查 | 判据 |
|---|---|
| 编号连续 | 每节内 1..N 无跳号、无重号 |
| 标题长度 | 6–16 字（含代码专名按词计） |
| 禁用词 | 命中 R5-3 词表即报警 |
| 句号结尾 | 出现即报错（句子不是标题） |
| 数量 | 常规节 ≤ 3；并列节 ≤ 5；超限报警 |
| 单章总量 | 不超过节数 × 2；超出报警 |
| 目录洁净 | `#outline` 只收 `##` 及以上，小标题不入目录 |

## 十、已知的取舍

- **会改动正文边界**：重新划分意味着把现有段落群切开或合并。切分处若缺过渡，需要补一句（≤ 一行），这类改动会逐条列在对照表里等你签字。
- **总量会变**：1–13 章现有 134 个，按新标准多数保留、少数薄的（如「正确写法」只有一段代码）会被合并；14–24 章按 R8 之前的 95 个作参考重划，预计落在 70–85 个。
- **不追求全书条数一致**：章与章内容量差得远，强行对齐数量会造出空标题。
