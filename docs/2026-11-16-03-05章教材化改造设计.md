# 03–05 章语体规范化改造（已实施）

> 本文记录已执行的语体改造口径与结果。此前基于叙事/案例主线的方案已废弃，不适用。

## 一、目标语体

将三章由手册/文档语体改为规范书面语与教材说明文体。要求如下：

- **语体**：规范书面语；不使用口语、网络语、情绪词、夸张与比喻；不使用“我们”“大家”等泛称；不写空泛套话。
- **准确**：术语前后统一；首次出现给出简明定义；数字、单位、公式、概念关系不改动；模糊表述改为可核查表述；不新增原文没有的事实。
- **精简**：删除重复、冗余修饰、背景铺垫与同义反复；一句表达一个主要意思；长句拆分，单句尽量不超过 40 字。
- **逻辑**：每段一个中心；按“定义—条件—结论”或“总—分—例”组织；因果、转折、并列关系使用明确连接词；先总后分，避免跳步。
- **可读性**：保留必要解释与例证；不把教材改为公文；不牺牲可教性。

## 二、改造范围

**改动**

- 章首导语、“本章要解决的问题”。
- 全部讲解小节的正文段落与不带编号的小标题。
- 例题的题目与解答表述、课堂活动块、本章小结、自检项。
- 实训块中与新语体冲突的个别措辞。

**未改动**

- 小节编号与标题（3.1–3.6、4.1–4.5、5.1–5.6）。
- 章号、题号、代码编号、图号。
- 全部代码块、表格、mermaid 图。
- 知识点覆盖、事实、数字、术语关系。
- 例题与习题的考查内容、答案。
- 实训步骤、验收表与排错清单的结构。
- 第 6–24 章（已知代价：这些章仍为原语体）。

## 三、统一处理

| 项 | 处理 |
| --- | --- |
| 人称 | 删除“你”“我们”“大家”；改用无人称句、“本节”“本章”或“学生” |
| 概念呈现 | 先界定对象与范围，再给定义；不用“**术语**是……”式词条连排 |
| 句式 | 长句拆分；一句一个主要意思；避免反问、感叹、口语连接词 |
| 连接词 | 显式使用“因此”“若……则……”“其一……其二……”“反之” |
| 修辞 | 删除比喻、夸张与情绪表达，如“门卫”“打补丁”“黑箱”“花样”“长这样” |
| 术语 | “四件机制”统一为“四项机制”；“小例子”统一为“示例” |
| 代码块 | 内容不改；前后引导语改为说明其作用与结果 |
| 表格 | 内容不改；仅将口语化单元格改为书面表述 |
