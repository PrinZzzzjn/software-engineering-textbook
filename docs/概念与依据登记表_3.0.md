# 概念与依据登记表（3.0）

> **用途**：逐条登记教材中的定义、分类、数字、标准条款与教学归纳，回答每个论断“依据是什么”。
> **口径**：本书自建的教学框架、判断启发式与对比，一律记为「本书归纳」，并在正文标注；不能对照原文核实的，记「待核对原文」，不写「已验证」。
> **轮次**：R1（2026-11-15）从第 1 章试点；随后理论章 02、03、04、14、21，再覆盖其余章节的首现概念。
> **相关文件**：[事实核校记录_2.0.md](事实核校记录_2.0.md)（案例数字与标准版本年份的专项核对）、[审核反馈_2.0/00-修改计划_R1.md](审核反馈_2.0/00-修改计划_R1.md)（本轮方案）。

## 一、类型与状态

| 类型 | 含义 | 正文处理 |
| --- | --- | --- |
| 标准定义 | 国际标准、国家标准中的定义或条款 | 行内括注标准号；措辞与标准不一致时注明“教学归并/改写” |
| 权威文献 | 学术论文、经典著作、行业知识体系 | 行内括注“作者, 年份”；章末「本章依据」列全 |
| 官方报告 | 事故调查委员会等官方调查报告 | 行内括注报告名与年份；数字无法核原文时标“待核对原文” |
| 本书归纳 | 教学框架、判断启发式、作者自建的分类与对比 | 正文明确“本书”“为便于教学”“工作定义”等字样，不冒充标准 |

| 状态 | 含义 |
| --- | --- |
| 已标注 | 正文已按上述体例处理，来源可追溯 |
| 待核对原文 | 来源名称可确认，具体表述/数字/译法须付印前按原文复核 |
| 待补 | 尚未处理，留待对应阶段 |
