# 实训 7-1 分步实现指南（B 档）

> 课堂达标：department 过滤 + 固定排序
> 课堂主动概念：查询参数、过滤/排序
> 事实源：`实训工程参考/实训7-1/` 的教师工程；本指南只讲 B 档主任务。

## 六段式说明

每个阶段按“本步目标 / 先看效果 / 语法卡片 / 代码与逐行解释 / 操作与检查点 / 常见错误与求助”组织；代码块只写课堂必做片段。

## 阶段 0：承接检查（10 分钟）

### 本步目标

确认 `starter/` 能启动，并找到本次要改的文件。

### 先看效果

启动应用，访问 `/docs`；能看到上一节 B 档产物即可。

### 语法卡片

项目按目录组织：`app/` 是包，`app/modules/` 放业务模块；当前目录下的 `main.py` 是启动入口。

### 操作与检查点

```bash
python -m uvicorn main:app --port 8000
```

- [ ] `/docs` 可打开
- [ ] 上一节 B 档接口仍可访问
