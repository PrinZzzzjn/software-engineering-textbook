# 实训 17-1：前端页面设计

> 课堂达标（B 档）：页面守卫 + 翻页
> 课堂主动概念：多页导航、分页状态
> 验证：未登录被拦回；翻页后列表与页码更新
> 步骤见 [分步实现指南.md](分步实现指南.md)。

## 一、验收

- [ ] 页面守卫 + 翻页
- [ ] 成功与失败至少一次：未登录被拦回；翻页后列表与页码更新
- [ ] 能说出两个课堂主动概念的用途
- [ ] 提交页面/工程与验证记录

## 三、排错

页面空白先看后端 `/health`；数据不对先看请求参数和接口返回；状态混乱先看 `session_state` 键。教师完整版不作为课堂达标条件。
