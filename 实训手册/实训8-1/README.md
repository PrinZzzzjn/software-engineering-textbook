# 实训 8-1：用户模块：注册与登录

> 课堂达标（B 档）：注册 → 登录 → 带令牌访问 /me
> 课堂主动概念：密码哈希、令牌与 401
> 验证：201 注册、200 登录、无令牌 401
> 每一步的语法、代码、命令与检查点见 [分步实现指南.md](分步实现指南.md)。

## 一、任务

1. 按课堂 B 档完成主任务：注册 → 登录 → 带令牌访问 /me。
2. 验证至少 1 个成功状态和 1 个失败状态：201 注册、200 登录、无令牌 401。
3. 填写一页验证记录，说明本次增量与承接产物的关系。

## 二、课前准备

- 已按上一实训 B 档达标；若未完成，使用教师 `snapshot-b/`。
- 领取本目录 `starter/`；注意当前终端位于 `main.py` 所在目录。
- Python 3.12 或兼容版本；依赖见 `starter/requirements.txt`。

## 四、验收（课堂达标 B 档）

- [ ] 主任务完成：注册 → 登录 → 带令牌访问 /me
- [ ] 成功状态与失败状态各至少一次真实记录
- [ ] 能说出两个课堂主动概念的用途
- [ ] 提交可运行产物、验证记录和一页说明

## 五、排错

| 现象 | 先查什么 |
| --- | --- |
| 启动失败 | 当前目录是否含 `main.py`；依赖是否安装 |
| 接口 404 | 路由前缀、HTTP 方法、服务是否重启 |
| 验证失败 | 先看状态码，再看请求体/路径参数，再看终端日志 |
