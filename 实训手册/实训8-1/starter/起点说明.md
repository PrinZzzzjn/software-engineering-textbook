# 实训 8-1 学员起点说明

本目录是**实训 7-1 的完成态**：department 与 personnel 都已落库，列表支持分页、过滤与固定排序；`app/core/database.py` 提供 `engine`、`SessionLocal`、`Base`、`get_db`；启动时建表并幂等写入 D001/D002 与 P001/P002。此时还没有 `users` 表、`app/core/security.py` 与 user 模块。

本实训要在**不破坏 department 与 personnel** 的前提下，安装登录认证：新建 users 表、密码哈希与令牌，实现注册、登录与当前用户三个接口。这里不给答案代码，请按教材 8.1–8.4 与任务书完成。

## 要新增的文件

```text
app/
├── core/
│   └── security.py          密码盐哈希、令牌生成与校验、get_current_user
└── modules/
    └── user/
        ├── __init__.py      空包文件
        ├── model.py         users 表模型，继承 Base
        ├── schema.py        注册/登录输入、UserOut、TokenOut
        ├── crud.py          带 db 的按用户名/按 id 查询与写入
        ├── service.py       查重、哈希、验密码、签发令牌
        ├── param.py         六文件体例占位（第 9 章列表分页用）
        └── controller.py    POST /users、POST /users/login、GET /users/me
```

`app/core/database.py` 沿用，不修改。

## 要修改的文件

1. **`main.py`**
   - 在 `create_all` 之前导入 user 模型，`create_all` 才会建出 `users` 表。
   - 挂载 user 路由，仍用 `prefix=""`，路径不带版本化前缀。
   - 增加幂等的管理员 seed：`admin / admin123`，供登录验收与第 9 章使用。
   - 保留 department 与 personnel 的模型导入、路由挂载和原有 seed。

2. **`README.md`**
   - 补充 `/users` 三个接口、令牌头写法、重启后令牌失效、users 表与旧库兼容的说明。

3. **`tests/test_api.py`（仅教师验证，学生不必扩展）**
   - 保留 7-1 的 23 项回归；新增注册、登录、`/me` 的 201/400/422/200/401 用例。

## 依赖检查清单

本章**不新增第三方依赖**，密码哈希与令牌都用标准库：

| 检查项 | 命令 | 预期 |
| --- | --- | --- |
| Python 版本 | `python --version` | 3.10 及以上 |
| 运行依赖 | `python -m pip install -r requirements.txt` | `fastapi`、`uvicorn`、`sqlalchemy` 可用 |
| 标准库可用 | `python -c "import hashlib, secrets; print('ok')"` | 输出 `ok` |
| 起点可启动 | `python -m uvicorn main:app --port 8000` | `/health` 200 |
| 旧接口可用 | 访问 `/departments`、`/personnel` | 均为 200，`total=2` |
| 认证尚未存在 | 访问 `/users` | 404（起点状态，不是错误） |

## 起点检查

在已安装依赖的环境中，于本目录执行：

```powershell
python -c "from app.modules.personnel import controller; print(controller.router.prefix)"
python -m uvicorn main:app --port 8000
```

第一条预期输出 `/personnel`。第二条启动后，`GET /departments` 与 `GET /personnel` 应各返回 2 条 seed 数据；访问 `/users` 得到 404，`duty.db` 中还没有 `users` 表，这都是起点状态。

`tests/test_api.py` 是 7-1 留下的教师测试，可用于确认改造前后 department 与 personnel 行为未变；本实训不要求扩展测试，教材第 12 章才系统讲测试。

## 不要做的事

- 不要把 `duty.db`、`venv/`、`.env`、`__pycache__/` 提交进仓库。
- 不要加版本化路径前缀；集合路径写成 `/users`，不带尾斜杠。
- 不要引入第三方密码或签名库；本章只用 `hashlib` 与 `secrets`。
- 不要给 users 表建到 departments 的外键，也不要给 department/personnel 接口加认证依赖。
- 不要做管理员权限依赖（403）、用户列表、修改角色或禁用；这些属于第 9 章。
- 不要删除或改写 department、personnel 的任何接口、字段与排序。
