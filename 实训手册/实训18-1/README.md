# 实训 18-1：数据编辑与页面状态

> 课堂达标（B 档）：单位页新增 + 编辑 + 删除反馈
> 课堂主动概念：写入刷新、表单回填
> 验证：三种写操作各一次；失败有反馈
> 步骤见 [分步实现指南.md](分步实现指南.md)。

## 一、验收

- [ ] 单位页新增 + 编辑 + 删除反馈

- [ ] 能说出两个课堂主动概念的用途
- [ ] 提交页面/工程与验证记录

## 二、时间

| 环节 | 分钟 |

页面空白先看后端 `/health`；数据不对先看请求参数和接口返回；状态混乱先看 `session_state` 键。教师完整版不作为课堂达标条件。
