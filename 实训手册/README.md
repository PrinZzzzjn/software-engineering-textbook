# 实训手册（学员版）

本目录是《软件工程实践》（2.0）实训 3-1、4-1 的学员材料。教师答案、自动测试、验证记录与难度评分在 `实训工程参考/`，不随本手册发放。

## 一、本目录有什么

```text
实训手册/
├── 实训3-1/
│   ├── README.md               任务、4 学时安排、验收与提交
│   ├── 分步实现指南.md         每步的语法讲解、完整代码、操作命令与检查点
│   ├── 记录表.md               状态码记录与幂等说明
│   └── starter/                起点：空白 main.py、语法热身、依赖
└── 实训4-1/
    ├── README.md
    ├── 分步实现指南.md
    ├── 设计文档模板.md
    ├── 记录表.md
    └── starter/                起点：六文件骨架（含 TODO，不含答案）
```

## 二、怎么用

1. **先读本实训的 `README.md`**：知道要做成什么、怎么验收、交什么。
2. **再按 `分步实现指南.md` 的顺序做**：每阶段六段——本步目标、先看效果、语法卡片、代码与逐行解释、操作与检查点、常见错误与求助。
3. **`starter/` 是起点，不是答案**：`main.py` 只有任务注释；`crud.py`、`service.py`、`controller.py` 里的 `NotImplementedError` 需要你补。
4. **每阶段做完先过检查点**：检查点不过，不进入下一阶段；先按“常见错误”查，再问教师。
5. **代码自己敲一遍**：可以先读完整代码，但至少有一处要自己改（改字段、改提示文字、改一个判断），并说清改了什么。

## 三、代码输入规范（每次写代码前看一遍）

- 输入法切到英文，代码里的引号、括号、冒号、逗号都用英文半角。
- 字符串用直引号 `"..."`，不要用中文弯引号 `“...”`。
- 缩进用 4 个空格，不要用 Tab；同一层代码左对齐。
- 文件保存为 UTF-8；文件名不要带空格。
- 启动前确认终端当前目录就是 `main.py` 所在目录。

## 四、命令与验证

- 课堂以 Ubuntu（bash）为主，PowerShell 只作对照。每条命令后面都给了预期输出。
- 内网安装依赖：

```bash
python -m pip install --no-index --find-links=<wheelhouse 路径> -r requirements.txt
```

- 正常安装：

```bash
python -m pip install -r requirements.txt
```

- 启动后端：

```bash
uvicorn main:app --reload --port 8000
```

- 浏览器打开 `http://127.0.0.1:8000/docs`。如果页面空白，说明内网拿不到 Swagger UI 的 CDN 资源；改用 `http://127.0.0.1:8000/openapi.json` 查看接口清单，或用教师提供的 `curl` 脚本验证。`/docs` 空白不是你的代码错误。

## 五、提交什么

- 3-1：自己的 `main.py`、填好的 `记录表.md`、100 字以内幂等说明。
- 4-1：设计文档、补全后的六文件代码、填好的 `记录表.md`。

不要提交 `venv/`、`__pycache__/`、`.pytest_cache/`、教师答案或自动测试。
