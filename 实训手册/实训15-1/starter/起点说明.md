# 实训 15-1 起点说明

本目录是第 14 章完成后的单页骨架，作为 15-1 的学员起点：

```text
starter/
├── app.py            # 只有 set_page_config、标题与一句待完成提示
├── requirements.txt  # streamlit + pandas
└── 起点说明.md
```

起点**没有**：假数据、指标、表格、筛选、空态、新增表单、`verify_app.py`。

## 起步

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

浏览器打开 <http://127.0.0.1:8501>，应只看到标题与提示。

## 本实训要补的五块

1. 假数据：10–20 条单位，字段为 `dept_code`、`full_name`、`address`，放进 `st.session_state`。
2. 指标：单位总数、已填地址数、当前筛选结果。
3. 表格：`st.dataframe` + `column_config`，列名中文、隐藏索引。
4. 筛选：名称/编码搜索 + 「只看有地址」复选框，无结果给 `st.info`。
5. 新增：`st.form` + `st.form_submit_button`，校验必填与编码重复，写回 `session_state`。

## 验收

- 四类组件（输入、展示、交互、容器）各至少用一个；
- 表格可读，空结果显示提示而不是空白表；
- 表单可用，新增后列表能看到；
- 页面完整，从标题到新增不出现报错。
