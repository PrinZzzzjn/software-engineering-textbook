## 开始之前：三个约定

### 约定一：代码里只用英文标点

下面这些字符在代码里必须是英文半角：

| 用这个 | 不要用这个 |
| --- | --- |
| `"` 直引号 | `“` `”` 弯引号 |
| `(` `)` 半角括号 | `（` `）` 全角括号 |
| `:` 半角冒号 | `：` 全角冒号 |
| `,` 半角逗号 | `，` 全角逗号 |

中文输入法下打出的引号和括号看起来很像，但 Python 不认识，启动时会报 `SyntaxError`。写代码前先把输入法切到英文。

### 约定二：缩进用 4 个空格

Python 靠缩进判断“哪些行属于同一个函数”。本实训统一用 4 个空格，不用 Tab。同一个函数体内的行，左边要对齐。

### 约定三：先保存，再启动

改完代码先按 `Ctrl+S` 保存，再回到终端启动。终端里看到的是最后一次保存的文件，不是编辑器里没保存的内容。

### 先看效果


```text

0.115.0
```

### 语法卡片

**终端当前目录。** 终端每一行前面显示的是“你现在在哪个文件夹”。`pwd` 打印当前目录，`ls` 列出当前目录的文件，`cd 目录名` 进入目录。

```bash
pwd
ls
cd starter
```

**`python` 命令。** `python --version` 让 Python 打印自己的版本；`python -c "..."` 让 Python 执行一段很短的代码。

**安装依赖。** `pip` 是 Python 的包安装工具。`python -m pip install -r requirements.txt` 的意思是：用当前这个 Python，按照 `requirements.txt` 里列出的名字安装依赖。

**内网安装。** 如果教室不能上公网，用本地 wheelhouse：

```bash
python -m pip install --no-index --find-links=<wheelhouse 路径> -r requirements.txt
```

把 `<wheelhouse 路径>` 换成教师给的目录，例如 `/opt/wheels`。`--no-index` 表示不访问公网，`--find-links` 表示从这个目录找安装包。

```text
├── warmup.py          语法热身
```

### 常见错误与求助

## 阶段 1：最小应用与 `/health`（25 分钟）

### 本步目标

写出一个只有 7 行的 FastAPI 应用，启动后能在 `/docs` 看到 `/health`，访问它返回 200 和 `{"status": "ok"}`。

### 先看效果

完成后，浏览器打开 `http://127.0.0.1:8000/docs`，应看到 `/health` 一项；再访问 `http://127.0.0.1:8000/health`，应看到：

```json
{"status": "ok"}
```

### 语法卡片

**`from ... import ...`。** 从 `fastapi` 这个包里取出 `FastAPI` 这个名字，后面直接用。

```python
from fastapi import FastAPI
```

**创建应用对象。** `FastAPI()` 创建一个应用；`app` 是我们给它起的变量名。后面的装饰器都挂在 `app` 上。

```python
app = FastAPI()
```

**装饰器 `@app.get("/health")`。** 它的作用是：把下面那个函数登记为“当有人用 GET 方法访问 `/health` 时，调用这个函数”。现在不需要理解装饰器的内部原理，只要会照着写。

```python
@app.get("/health")
def health():
    return {"status": "ok"}
```

**函数 `def` 与 `return`。** `def health():` 定义一个没有参数的函数；函数体缩进 4 个空格；`return` 把结果交回去。

**字典与 JSON。** `{"status": "ok"}` 是 Python 字典；FastAPI 会自动把它转成 JSON。JSON 里的 `true`/`false`/`null` 对应 Python 的 `True`/`False`/`None`，写代码时用 Python 的写法。

### 代码与逐行解释

把下面 7 行写进 `starter/main.py`：

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/health")
def health():
    return {"status": "ok"}
```

| 行 | 代码 | 在做什么 | 为什么需要 |
| --- | --- | --- | --- |
| 1 | `from fastapi import FastAPI` | 导入框架 | 不导入就没有 `FastAPI` 这个名字 |
| 2 | 空行 | 分隔导入与应用 | 让代码好读，不影响运行 |
| 3 | `app = FastAPI()` | 创建应用 | 后面所有路由都登记在 `app` 上 |
| 4–5 | 空行 | 分隔 | 好读 |
| 6 | `@app.get("/health")` | 登记 GET `/health` | 告诉框架“这个路径由下面的函数处理” |
| 7 | `def health():` | 定义处理函数 | 收到请求时执行它 |
| 8 | `    return {"status": "ok"}` | 返回字典 | 框架把它转成 JSON 响应 |

### 操作与检查点

在 `starter/` 目录启动：

```bash
uvicorn main:app --reload --port 8000
```

命令的意思是：`main` 是文件 `main.py`（省略 `.py`），`app` 是文件里的变量名，`--reload` 表示改代码后自动重启，`--port 8000` 表示用 8000 端口。

预期终端输出：

```text
INFO:     Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
INFO:     Application startup complete.
```

另开一个终端，验证 `/health`：

```bash
curl -i http://127.0.0.1:8000/health
```

PowerShell 对照：

```powershell
Invoke-RestMethod -Uri "http://127.0.0.1:8000/health" -Method Get
```

预期：状态行是 `200 OK`，正文是 `{"status":"ok"}`。

检查点：

- [ ] `/docs` 能打开，页面里有 `/health`
- [ ] `/health` 返回 200
- [ ] 正文是 `{"status":"ok"}`

### 常见错误与求助

| 现象 | 先查什么 | 怎么改 |
| --- | --- | --- |
| `ModuleNotFoundError: fastapi` | 依赖是否装在当前 Python | 在 `starter/` 执行 `python -m pip install -r requirements.txt` |
| `Could not import module "main"` | 当前目录有没有 `main.py` | `pwd` 确认在 `starter/`；文件名不要写错 |
| `Address already in use` | 8000 端口是否被占用 | 换端口 `--port 8001`，或关掉旧进程 |
| `/docs` 空白 | 内网拿不到 Swagger UI 的 CDN 资源 | 打开 `http://127.0.0.1:8000/openapi.json` 看接口清单；或问教师要本地 Swagger 的启动方式 |
| 改代码后没变化 | 是否保存；`--reload` 是否生效 | `Ctrl+S` 保存；看终端有没有 `Reloading...` |

## 阶段 2：字典与列表热身（20 分钟）

### 本步目标

先不碰接口，单独把“字典怎么存一条记录、怎么增、怎么查、怎么删”练熟。后面的五个端点都在重复这几个动作。

### 先看效果

运行 `starter/warmup.py`：

```bash
python warmup.py
```

预期输出（节选）：

```text
D01 的记录： {'dept_code': 'D01', 'full_name': '一中队', 'address': '一号楼'}
D99 的记录： None
D01 在字典里吗？ True
D99 在字典里吗？ False
记录条数： 1
```

### 语法卡片

**字典字面量。** 字典用 `{键: 值, 键: 值}` 表示。本实训的“键”是单位编码，“值”是另一条字典。

```python
departments = {
    "D01": {"dept_code": "D01", "full_name": "一中队", "address": "一号楼"},
}
```

**按键取值。** `departments["D01"]` 取出 D01 那条记录；键不存在时会报 `KeyError`。

**`.get()`。** `departments.get("D99")` 在键不存在时返回 `None`，不会报错。判断“有没有”时先用 `in`，不要直接取值。

**`in`。** `"D01" in departments` 判断键在不在字典里，返回 `True` 或 `False`。

**`.values()` 与 `list()`。** `departments.values()` 取出所有“值”；`list(...)` 把它们变成一个列表。列表端点的 `items` 就是它。

**`len()`。** `len(departments)` 返回字典里有多少个键，也就是多少条记录。列表端点的 `total` 就是它。

**新增与删除。** `departments["D02"] = {...}` 新增一条；`del departments["D02"]` 删除一条。

**遍历。** `for code, item in departments.items():` 一次取出“键”和“值”。

### 代码与逐行解释

`warmup.py` 已经写好，先读懂，再改末尾的 TODO。核心几行：

```python
departments = {
    "D01": {"dept_code": "D01", "full_name": "一中队", "address": "一号楼"},
}

print(departments["D01"])
print(departments.get("D99"))
print("D01" in departments)
print(list(departments.values()))
print(len(departments))
```

| 代码 | 在做什么 | 后面用在哪 |
| --- | --- | --- |
| `departments = {...}` | 建一个内存字典 | 列表、详情、新增、修改、删除都读写它 |
| `departments["D01"]` | 按键取记录 | 详情端点返回记录 |
| `.get("D99")` | 取不到返回 `None` | 新增时判断编码是否重复 |
| `"D01" in departments` | 判断键是否存在 | 详情、修改、删除先判断存在 |
| `list(departments.values())` | 所有记录变成列表 | 列表端点的 `items` |
| `len(departments)` | 记录条数 | 列表端点的 `total` |
| `departments["D02"] = {...}` | 新增一条 | 新增端点 |
| `del departments["D02"]` | 删除一条 | 删除端点 |

### 操作与检查点

1. 运行 `python warmup.py`，对照输出，确认每行都看懂了。
2. 完成文件末尾的 TODO 1：把 D01 的 `full_name` 改成 `"第一中队"`，再打印。
3. 完成 TODO 2：新增 D03，再删除 D01，打印剩余记录。
4. 完成 TODO 3：把两个 `in` 判断改成 `if` 语句。

检查点：

- [ ] 能说出 `departments["D99"]` 和 `departments.get("D99")` 的区别
- [ ] 能说出 `items` 和 `total` 分别对应哪一行
- [ ] 改完 TODO 后脚本还能正常运行

### 常见错误与求助

| 现象 | 先查什么 | 怎么改 |
| --- | --- | --- |
| `KeyError: 'D99'` | 是否直接用了 `["D99"]` | 改用 `.get("D99")`，或先用 `in` 判断 |
| `TypeError` | 把列表当字典，或把字典当列表 | 看清 `[]` 与 `{}`：列表用 `[]`，字典用 `{}` |
| 输出是 `None` | `.get()` 没取到 | 这是正常结果，不是错误；先确认键是否存在 |
| `SyntaxError` | 引号、括号、冒号是不是全角 | 切英文输入法，改成半角 |

## 阶段 3：列表端点（20 分钟）

### 本步目标

让 `GET /departments` 返回 `{"items": [...], "total": 1}`。先返回一条写死的记录，确认契约，再换成从字典读取。

### 先看效果

```bash
curl -s http://127.0.0.1:8000/departments
```

预期：

```json
{"items": [{"dept_code": "D01", "full_name": "一中队", "address": "一号楼"}], "total": 1}
```

### 语法卡片

**返回字典套列表。** 响应最外层是字典，里面有两个键：`items` 是记录列表，`total` 是条数。不要直接返回一个列表，前端无法按同一个契约取数。

```python
return {
    "items": [{"dept_code": "D01", "full_name": "一中队", "address": "一号楼"}],
    "total": 1,
}
```

**`DEPARTMENTS` 常量。** 把记录移到一个模块级字典里，多个端点共享同一份数据：

```python
DEPARTMENTS = {
    "D01": {"dept_code": "D01", "full_name": "一中队", "address": "一号楼"},
}
```

**`list(DEPARTMENTS.values())`。** 取出所有记录，变成列表，作为 `items`。

**`len(DEPARTMENTS)`。** 当前记录数，作为 `total`。

### 代码与逐行解释

先写静态版本，确认接口能通：

```python
@app.get("/departments")
def list_departments():
    return {
        "items": [
            {"dept_code": "D01", "full_name": "一中队", "address": "一号楼"}
        ],
        "total": 1,
    }
```

确认能返回后，把记录移到字典，列表改成读取字典：

```python
DEPARTMENTS = {
    "D01": {"dept_code": "D01", "full_name": "一中队", "address": "一号楼"},
}


@app.get("/departments")
def list_departments():
    return {"items": list(DEPARTMENTS.values()), "total": len(DEPARTMENTS)}
```

| 代码 | 在做什么 | 为什么需要 |
| --- | --- | --- |
| `DEPARTMENTS = {...}` | 建共享字典 | 后面新增、修改、删除都要改它 |
| `DEPARTMENTS.values()` | 取所有记录 | 列表要展示全部 |
| `list(...)` | 变成列表 | JSON 数组对应 Python 列表 |
| `len(DEPARTMENTS)` | 数条数 | `total` 必须跟着数据变化 |
| `return {...}` | 组装响应 | 契约要求 `items` 与 `total` 两个键 |

### 操作与检查点

1. 保存，等终端出现 `Reloading...`。
2. 访问 `http://127.0.0.1:8000/departments`。
3. 预期 200，正文含 `items` 和 `total`，`total` 为 1。

PowerShell 对照：

```powershell
Invoke-RestMethod -Uri "http://127.0.0.1:8000/departments" -Method Get
```

检查点：

- [ ] 返回 200
- [ ] 正文同时有 `items` 和 `total`
- [ ] `items` 里是 D01，`total` 是 1
- [ ] 能说出 `total` 为什么不能写死为 1

### 常见错误与求助

| 现象 | 先查什么 | 怎么改 |
| --- | --- | --- |
| 直接返回数组 | 响应最外层是不是 `[...]` | 改成 `{"items": [...], "total": n}` |
| 把字典写成列表 | 外层用的是 `[]` 还是 `{}` | 外层用 `{}`；`items` 里才是列表 |
| `total` 一直是 1 | 是否写死 | 改成 `len(DEPARTMENTS)` |
| 所有接口 404 | 装饰器路径、HTTP 方法、是否启动了正确目录 | 对照 `/departments`；确认在 `starter/` 启动 |

## 阶段 4：详情端点与 404（15 分钟）

### 本步目标

增加 `GET /departments/{dept_code}`：存在返回记录和 200，不存在返回 404 和“单位不存在”。

### 先看效果

```bash
curl -i http://127.0.0.1:8000/departments/D01
curl -i http://127.0.0.1:8000/departments/D404
```

预期：D01 是 `200 OK` 加记录；D404 是 `404 Not Found`，正文：

```json
{"detail": "单位不存在"}
```

### 语法卡片

**路径参数。** URL 里的 `{dept_code}` 是一个占位符；访问 `/departments/D01` 时，`dept_code` 的值就是 `"D01"`。

```python
@app.get("/departments/{dept_code}")
```

**函数参数接收路径参数。** 函数参数名要和花括号里的名字一致：

```python
def get_department(dept_code: str):
```

`dept_code: str` 是类型注解，表示它应该是字符串。类型注解不改变运行，但帮助阅读，FastAPI 也会用它做转换。

**`not in`。** `dept_code not in DEPARTMENTS` 表示“这个编码不在字典里”。

**`raise` 与 `HTTPException`。** 不存在时主动抛出一个 404 异常，而不是让字典自己报 `KeyError`（那会变成 500）。

```python
raise HTTPException(status_code=404, detail="单位不存在")
```

### 代码与逐行解释

先把导入补全：

```python
from fastapi import FastAPI, HTTPException
```

再加详情端点：

```python
@app.get("/departments/{dept_code}")
def get_department(dept_code: str):
    if dept_code not in DEPARTMENTS:
        raise HTTPException(status_code=404, detail="单位不存在")
    return DEPARTMENTS[dept_code]
```

| 行 | 代码 | 在做什么 | 为什么需要 |
| --- | --- | --- | --- |
| 1 | `@app.get("/departments/{dept_code}")` | 登记详情路由 | `{dept_code}` 是路径参数 |
| 2 | `def get_department(dept_code: str):` | 定义处理函数 | 参数名必须与路径参数一致 |
| 3 | `if dept_code not in DEPARTMENTS:` | 先判断存在 | 不判断就直接取值会 500 |
| 4 | `raise HTTPException(...)` | 主动返回 404 | 资源不存在是调用方问题，用 4xx |
| 5 | `return DEPARTMENTS[dept_code]` | 返回记录 | 存在时正常返回 200 |

### 常见错误与求助

| 现象 | 先查什么 | 怎么改 |
| --- | --- | --- |
| 不存在时返回 500 | 是否直接 `return DEPARTMENTS[dept_code]` | 先 `if dept_code not in DEPARTMENTS` |
| `NameError: HTTPException` | 导入里有没有它 | 改成 `from fastapi import FastAPI, HTTPException` |
| 详情和列表冲突 | 详情路径是否写成了 `/departments` | 详情必须是 `/departments/{dept_code}` |
| 404 的 `detail` 不是中文 | 文件编码、引号 | 文件保存 UTF-8；字符串用直引号 |
