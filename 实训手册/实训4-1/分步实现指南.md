# 综合实训 4-1 代码分步实现指南

本指南以单位为例，演示 starter 从“能启动”到“五个接口全部通过”的过程。自选资源的字段与路径自行替换，文件结构与调用顺序不变。

## 零、开始之前

### 0.1 目录

```text
starter/
├── main.py
├── requirements.txt
└── app/
    └── modules/
        └── department/
            ├── controller.py
            ├── service.py
            ├── crud.py
            ├── model.py
            ├── schema.py
            └── param.py
```

### 0.2 先让它启动

```bash
cd starter
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

打开 `http://127.0.0.1:8000/docs`。此时页面可打开，但还没有接口，这是正常的；`controller.py` 只有路由骨架。

### 0.3 先读一遍六个文件的职责

| 文件 | 职责 | 本实训要做什么 |
| --- | --- | --- |
| `model.py` | 记录有哪些字段，`TABLE` 充当表 | 换成自选对象的字段 |
| `schema.py` | 什么能进、什么能出 | 换成对应字段与约束 |
| `param.py` | 查询参数 | 已给出，按需改上限 |
| `crud.py` | 只读写，不判断规则 | 补全五个函数 |
| `service.py` | 业务规则与 404 | 补全五个函数 |
| `controller.py` | 接请求、返回结果 | 登记五个接口 |
| `main.py` | 创建应用、挂路由 | 不改 |

## 阶段 1：改 model、schema 与 param（15 分钟）

以“图书”为例，`model.py` 改为：

```python
from dataclasses import dataclass


@dataclass
class Book:
    isbn: str
    title: str
    author: str | None = None


TABLE: list[Book] = []
```

对应地，`schema.py` 写三个模型：

```python
class BookCreate(BaseModel):
    isbn: str = Field(..., min_length=3, max_length=20)
    title: str = Field(..., min_length=1, max_length=100)
    author: str | None = Field(default=None, max_length=50)


class BookUpdate(BaseModel):
    title: str | None = Field(default=None, min_length=1, max_length=100)
    author: str | None = Field(default=None, max_length=50)


class BookOut(BaseModel):
    model_config = ConfigDict(from_attributes=True)

    isbn: str
    title: str
    author: str | None = None


class BookPage(BaseModel):
    items: list[BookOut]
    total: int
```

`param.py` 把 `DeptQuery` 改名为 `BookQuery`，字段保持 `page` / `page_size`。完成后 `python -c "from app.modules.book import model; print(model.Book)"` 应无报错。

**做错会看到什么**：`model.py` 改了字段，`schema.py` 还是单位字段；两处必须同步。

## 阶段 2：写 crud（20 分钟）

`crud.py` 只做存取，不判断规则：

```python
from . import model


def list_all() -> list[model.Book]:
    return model.TABLE


def get(isbn: str) -> model.Book | None:
    for item in model.TABLE:
        if item.isbn == isbn:
            return item
    return None


def create(item: model.Book) -> model.Book:
    model.TABLE.append(item)
    return item


def update(item: model.Book, data: dict) -> model.Book:
    for key, value in data.items():
        setattr(item, key, value)
    return item


def delete(item: model.Book) -> None:
    model.TABLE.remove(item)
```

**做错会看到什么**：在 `crud` 里写 `if get(isbn): raise HTTPException(400)`。规则属于 `service`，`crud` 只回答“查得到/查不到”。

## 阶段 3：写 service（15 分钟）

```python
from fastapi import HTTPException

from . import crud, model, schema


def list_books(page: int, page_size: int) -> dict:
    items = crud.list_all()
    start = (page - 1) * page_size
    return {
        "items": [schema.BookOut.model_validate(item) for item in items[start : start + page_size]],
        "total": len(items),
    }


def get_book(isbn: str) -> model.Book:
    item = crud.get(isbn)
    if item is None:
        raise HTTPException(status_code=404, detail="图书不存在")
    return item


def create_book(data: schema.BookCreate) -> model.Book:
    if crud.get(data.isbn) is not None:
        raise HTTPException(status_code=400, detail="ISBN 已存在")
    return crud.create(model.Book(**data.model_dump()))


def update_book(isbn: str, data: schema.BookUpdate) -> model.Book:
    item = crud.get(isbn)
    if item is None:
        raise HTTPException(status_code=404, detail="图书不存在")
    return crud.update(item, data.model_dump(exclude_unset=True))


def delete_book(isbn: str) -> None:
    item = crud.get(isbn)
    if item is None:
        raise HTTPException(status_code=404, detail="图书不存在")
    crud.delete(item)
```

**做错会看到什么**：编码重复返回 422。422 由 Pydantic 在进入函数前产生，只处理字段格式；重复要查现有数据，属于业务规则，返回 400。

## 阶段 4：写 controller 五个接口（20 分钟）

```python
from fastapi import APIRouter, Depends, status

from . import param, schema, service

router = APIRouter(prefix="/books", tags=["图书"])


@router.get("", response_model=schema.BookPage)
def list_books(params: param.BookQuery = Depends()):
    return service.list_books(params.page, params.page_size)


@router.get("/{isbn}", response_model=schema.BookOut)
def get_book(isbn: str):
    return service.get_book(isbn)


@router.post("", response_model=schema.BookOut, status_code=status.HTTP_201_CREATED)
def create_book(data: schema.BookCreate):
    return service.create_book(data)


@router.put("/{isbn}", response_model=schema.BookOut)
def update_book(isbn: str, data: schema.BookUpdate):
    return service.update_book(isbn, data)


@router.delete("/{isbn}", status_code=status.HTTP_204_NO_CONTENT)
def delete_book(isbn: str):
    service.delete_book(isbn)
```

保存后刷新 `/docs`，应出现“图书”分组与五个端点。

**做错会看到什么**：

- 全部 404：`main.py` 的 `include_router(..., prefix="/api/v1")` 与模块 `prefix` 少写了一段。
- 删除返回 200 或带正文：装饰器没有 `status_code=204`，或函数返回了内容。
- 列表 422：`param.BookQuery` 的字段与查询参数名不一致。

## 阶段 5：验证状态码（10 分钟）

在 `/docs` 中按顺序操作，并把结果填入记录表：

| 请求 | 预期 |
| --- | --- |
| `GET /api/v1/books` | 200，返回 `items` 与 `total` |
| `POST /api/v1/books`，提交完整字段 | 201 |
| 重复提交同一 ISBN | 400 |
| 提交缺 `title` 的正文 | 422 |
| `GET /api/v1/books/{isbn}` | 200 |
| `GET /api/v1/books/不存在` | 404 |
| `PUT /api/v1/books/{isbn}` | 200 |
| `DELETE /api/v1/books/{isbn}` | 204，无响应体 |
| 再次删除同一 ISBN | 404 |

**做错会看到什么**：所有错误都是 500。按第 3 章 3.2 的责任表逐项判断该由 Pydantic、service 还是 controller 拒绝。

## 每阶段都要问的三个问题

1. 这段代码属于哪个文件？判断依据是“它回答什么问题”，不是“放在哪里方便”。
2. 这个失败由哪一层产生？字段格式交 Pydantic（422），业务规则交 service（400），资源不存在交 service（404）。
3. 换一个资源时，哪些文件必须改？`model.py`、`schema.py`、`controller.py` 的路径与字段必改；`crud.py` 与 `service.py` 改字段名；`param.py` 通常不改。
