# 实训 20-1：前端开发综合实践

> 课堂达标（B 档）：6 步用户路径 + 一个页面统一错误 + 交付清单

> 验证：6 步路径走通；一个错误码显示中文提示
> 步骤见 [分步实现指南.md](分步实现指南.md)。

- [ ] 6 步用户路径 + 一个页面统一错误 + 交付清单

## 三、排错

页面空白先看后端 `/health`；数据不对先看请求参数和接口返回；状态混乱先看 `session_state` 键。教师完整版不作为课堂达标条件。
