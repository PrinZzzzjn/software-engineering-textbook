# 实训 6-1：数据模块：增删查改

> 课堂达标（B 档）：列表 + 新增 + 重复编码 400
> 课堂主动概念：ORM 模型、数据库会话
> 验证：3 条命令：建表/列表/新增；一个失败状态 400
> 每一步的语法、代码、命令与检查点见 [分步实现指南.md](分步实现指南.md)。

## 一、任务

1. 按课堂 B 档完成主任务：列表 + 新增 + 重复编码 400。
2. 验证至少 1 个成功状态和 1 个失败状态：3 条命令：建表/列表/新增；一个失败状态 400。
3. 填写一页验证记录，说明本次增量与承接产物的关系。

## 二、课前准备

- 已按上一实训 B 档达标；若未完成，使用教师 `snapshot-b/`。
- 领取本目录 `starter/`；注意当前终端位于 `main.py` 所在目录。
- Python 3.12 或兼容版本；依赖见 `starter/requirements.txt`。

## 五、排错

| 现象 | 先查什么 |
| --- | --- |
| 启动失败 | 当前目录是否含 `main.py`；依赖是否安装 |
| 接口 404 | 路由前缀、HTTP 方法、服务是否重启 |
| 验证失败 | 先看状态码，再看请求体/路径参数，再看终端日志 |
