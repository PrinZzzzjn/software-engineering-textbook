# 实训 16-1 起点说明

本目录是 15-1 的完成态单位管理页，作为 16-1 的学员起点：

```text
starter/
├── app.py            # 单位管理页，仍使用 12 条假数据
├── requirements.txt  # streamlit + pandas + requests
└── 起点说明.md
```

起点**没有**：`config.py`、`api_client.py`、登录表单、真实接口调用、加载/空/错误三态。

## 起步

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

浏览器打开 <http://127.0.0.1:8501>，页面应正常显示 12 条假数据；新增只在当前会话可见。

同时启动后端（13-1 项目，另一个终端）：

```powershell
python -m uvicorn main:app --port 8000
```

确认 <http://127.0.0.1:8000/health> 返回 `{"status": "healthy"}`，再开始改造。

## 本实训要补的五块

1. 建 `config.py`：`API_BASE_URL`、`API_PREFIX`、`REQUEST_TIMEOUT`、`DEFAULT_PAGE_SIZE`。
2. 建 `api_client.py`：`ApiError`、`_url`、`_headers`、`_request` 与 `get/post/put/delete`。
3. 加登录：表单收集用户名与密码，`POST /users/login`，令牌存进 `st.session_state`。
4. 换数据源：删掉 `SEED_DEPARTMENTS` 与 `_init_state`，列表改用 `GET /departments`。
5. 补三态：`st.spinner` 加载、`st.info` 空态、`st.error + st.stop` 错误态；新增改 `POST /departments`。

## 验收

- 登录后能看到后端返回的单位，退出或令牌过期后回到登录页；
- 列表、新增都通过 `api.get` / `api.post`，页面里没有完整 URL；
- 加载、空、错误三种状态都有可读提示；
- 新增重复编码出现「已存在」，超长字段出现可读的 422 提示；
- 能按「状态码 → detail → `/docs` → 代码」复述一次排错过程。
