### 第 1 章 软件工程基本概念

- **课次 / 学时**：1 / 2 理论
- **本章工程问题**：一个“能跑起来”的程序，和一个“可以交付”的系统，中间差什么？
- **核心概念**：K1 工程化交付（引）
- **支撑概念**：生命周期、过程模型
- **复现概念**：无（全书起点）
- **新术语预算**：5（软件工程、生命周期、瀑布、迭代、敏捷）
- **认知负荷**：低
- **理解台阶**：
  1. **事故不是“代码写错了”**：阿丽亚娜 5 号同时暴露复用、测试、规格、冗余四类问题（印刷标题：阿丽亚娜 5 号事故）
  2. **软件 = 程序 + 数据 + 文档**：交付源代码不等于交付软件（印刷标题：软件的三部分）
  3. **四个根本挑战**：复杂性、变化、协作、质量，共同指向“越晚发现越贵”（印刷标题：四个根本挑战）
  4. **生命周期与过程模型**：六阶段各留什么交付物；瀑布、迭代、敏捷各自回答什么问题（印刷标题：生命周期与三种过程模型）
- **C18 印刷节**：1.1.1 工程化交付 / 1.1.2 软件的三部分 / 1.1.3 四个根本挑战 / 1.1.4 软件开发生命周期 / 1.1.5 三种过程模型与选择 / 1.1.6 流程的适用边界与角色分工
- **落地物**：事故时间线与损失数字、六阶段交付物表、三模型对照表
- **反例 / 取舍**：敏捷不是“不写文档”；瀑布不是“落后”；文档不是越多越好——三者是对需求稳定性与反馈频率的不同回应
- **迁移问题**：给一个 8 周、4 人、需求可调整的课程项目选主导模型，说明坚持两项实践、裁剪一项，并指出裁剪风险

### 第 4 章 HTTP 与接口设计

- **课次 / 学时**：4 / 2 理论
- **本章工程问题**：前后端分离后，两边靠什么对话，才不会在联调时互相猜？
- **核心概念**：K3 接口契约（引）
- **支撑概念**：请求/响应、HTTP 方法、状态码、REST
- **复现概念**：K2（验收标准如何落成接口字段）
- **新术语预算**：5（请求/响应、方法、状态码、JSON；REST 为背景概念）
- **认知负荷**：中
- **理解台阶**：
  1. **没有契约的联调**：地址、字段、状态码三处对不上，页面就是空的（印刷标题：联调失败的三个来源）
  2. **请求与响应四要素**：URL、方法、请求头、请求体（印刷标题：请求与响应的四要素）
  3. **状态码的语义**：2xx 成功、4xx 调用方问题、5xx 服务方问题（印刷标题：状态码的三段语义）
  4. **RESTful 资源设计**：URL 用名词，方法表示动作（印刷标题：资源与动作的分离）
- **C18 印刷节**：4.1.1 接口契约（并入契约最终口径） / 4.1.2 请求与响应的四要素 / 4.1.3 状态码的三段语义 / 4.1.4 资源与动作的分离（FastAPI 最小应用归第 5 章 5.1.1）

- **反例 / 取舍**：用 200 返回错误；URL 里放动词；所有错误都返回 500
- **迁移问题**：为“器材”资源设计列表、详情、新增、删除四个端点，并写出成功与失败状态码

### 第 5 章 FastAPI 核心机制

- **课次 / 学时**：4 / 2 理论（与第 4 章共同承载课次 4）
- **本章工程问题**：一份写在文档里的契约，怎样变成可运行、可校验、可测试的服务？
- **核心概念**：K3（实现）、K7（先导：数据模型与校验）
- **支撑概念**：路由、Pydantic、依赖、数据库会话
- **复现概念**：K3（第 4 章的契约）
- **新术语预算**：4 必学（`APIRouter`、`BaseModel`、`Depends`、`Session`）；`HTTPException` 与 `Optional/Literal` 的语法说明并入正文，不额外计入核心预算
- **认知负荷**：中（语法说明全部并入正文；三文件最小工程是本章成果，不要求一次背下全部语法）
- **理解台阶**：
  1. **最小服务**：一个路由怎样接请求、返回 JSON（印刷标题：最小可运行路由）
  2. **路由与挂载**：`APIRouter` 创建、`include_router` 挂载（印刷标题：APIRouter 与挂载）
  3. **数据校验**：`BaseModel` 与 `Field` 在进入函数前拦住非法输入；`Optional` 与 `Literal` 表示可选值与固定取值（印刷标题：Pydantic 的输入校验）
  4. **依赖与会话**：`Depends` 把公共逻辑抽成参数，`Session` 管数据库连接（印刷标题：Depends 与数据库会话）
  5. **错误与完整工程**：`HTTPException` 与 422 的分工；三文件最小工程把四件机制串起来（印刷标题：错误返回与完整最小工程）
- **C18 印刷节**：5.1.1 最小可运行路由 / 5.1.2 APIRouter 与挂载 / 5.1.3 Pydantic 的输入校验（并入可选值与固定取值） / 5.1.4 Depends 与数据库会话 / 5.1.5 规则性失败与错误返回 / 5.1.6 最小工程：三个文件
- **落地物**：最小 FastAPI 应用、`/docs` 页面、422 响应、8 处语法说明（并入正文）、三文件最小工程（`schemas.py` / `deps.py` / `main.py`）、交给第 6 章的归位说明
- **反例 / 取舍**：把校验写在函数里；路由里直接拼 SQL；只照着敲最小工程、说不清每个文件负责什么

### 第 6 章 软件设计与建模

- **课次 / 学时**：5 / 2 理论
- **本章工程问题**：一个系统怎样划分成若干部分，使每部分可以独立理解、替换和验证？
- **核心概念**：K4 分层与职责（引；正式命名耦合、内聚、信息隐藏）；K7 数据建模作为本章的前置支撑，第 10 章正式深化
- **支撑概念**：模块图、ER 图、接口组
- **复现概念**：K2（需求如何变成模块）、K3（接口如何定义边界）
- **新术语预算**：5（分层、职责、耦合、内聚、信息隐藏）；另 3 个背景方法名（用例驱动、接口优先、领域驱动），不计数、不考
- **认知负荷**：中
- **理解台阶**（6 个；已按“翻译链 + 目录落位”重构）：链条是需求 → 业务对象 → 表 → 模块 → 接口 → 分层与目录 → 文档，每一步的产出是下一步的输入。
  1. **从需求到结构**：设计不是写文档，而是六步翻译链；顺序依据是先定变化最慢、代价最高的决定；补替代方法与适用边界（用例驱动／接口优先／领域驱动，背景了解）（印刷标题：从需求到结构）
  2. **业务对象与表结构**：需求里的名词 → 业务对象 → 表；外键放在“多”的一方（印刷标题：业务对象与表结构）
  3. **模块划分与接口组**：表由谁操作 → 模块按业务能力切，不按页面切；接口组由模块职责推出，跨模块约定一致（印刷标题：从业务对象到模块、模块的接口组）
  4. **模块内的分层与目录**：请求进来经过谁 → 四层 + schema/param 两个边界 = 六类职责；耦合/内聚/信息隐藏；六文件落到 `app/modules/<模块>/`（印刷标题：模块内的分层与目录）
  5. **第 5 章三文件的归位与组装**：归位表、`main.py` 与 `database.py` 的组装、一条请求走一遍（印刷标题：第 5 章三文件的归位与组装）
  6. **设计文档与一致性**：前五步的产物汇总；表字段、接口返回、页面输入、模块职责、模块目录五者对齐（印刷标题：设计文档与一致性）
- **C18 印刷节**：6.1.1 从需求到结构 / 6.1.2 业务对象与表结构 / 6.1.3 模块划分与接口组 / 6.1.4 模块内的分层与目录 / 6.1.5 第 5 章三文件的归位与组装 / 6.1.6 设计文档与一致性
- **落地物**：翻译链图（图 6-1）、duty 三张表与 ER 图（图 6-2）、模块清单、接口组清单、六类职责表、目录树、第 5 章三文件归位表、一条请求路径图（图 6-3）、部门模块设计文档示例（代码 6-1-4）、`database.py` / `controller.py` / `main.py` 代码（代码 6-1-1～6-1-3）
- **反例 / 取舍**：直接写代码跳过设计；外键放反；按页面分模块；模块切得过细；controller 写业务；六个文件都在但职责没分；设计文档写成项目介绍
- **迁移问题**：为“培训管理”设计模块划分、表关系、模块目录与一个模块的 5 个接口（习题 6-2）

### 第 8 章 用户模块：登录认证

- **课次 / 学时**：7 / 4 实践
- **本章工程问题**：系统怎样确认“你是谁”，并让后续请求带着这个身份？
- **核心概念**：K6 认证与授权（引：认证部分）
- **支撑概念**：哈希、令牌、认证依赖
- **复现概念**：K3（登录接口的契约）、K4（security 与 dependencies 的分层）
- **新术语预算**：4（哈希、令牌、认证、依赖注入）
- **认知负荷**：中（现 2.0 在此处有 11 个新概念，3.0 压到 4 个，其余全部在第 5 章先导）
- **理解台阶**：
  1. **没有认证的接口**：任何人直接调用就能拿到全部数据（印刷标题：未受保护的接口）
  2. **密码怎么存**：哈希与盐，为什么不能明文（印刷标题：密码哈希）
