## 二、教学目标

**知识与技能**

- 能说清两个统计需求：年度总天数/总时长/月度分布；24 小时时段分布。
- 能从 `duty_record` 查出某人某年的记录。
- 能用循环和聚合算出：总天数、总时长、按月统计、按小时统计。
- 能处理空数据：没有记录时返回 0 或空列表。
- 能说清统计口径：同一天多条记录算 1 天；跨月按开始时间归月；无记录返回 0/空。
- 知道"统计是只读"；统一异常与事务边界放课次14。

**过程与方法**

- 经历"定需求 → 查数据 → 算指标 → 返回结果"的统计开发过程。
- 学会用边界数据测试：无记录、只有一条、跨月、跨年。

**情感态度与价值观**

- 建立"统计口径要写清楚"的意识。
- 养成"先想指标，再写循环"的习惯。

## 教学内容

> 对应教学计划：专题二基本内容第 9 条"业务模块：统计校验"，以及第 8 条的"典型业务功能"。
> 本课次只做**执勤记录**相关的两个简单统计；查勤、节假日、天气等统计放课后/扩展。
> 本课次只讲统计与口径；统一异常、事务边界放到课次14。

1. **统计需求一：年度统计**：某人某年的总值班天数、总时长、按月分布。
2. **统计需求二：时段分布**：某人某年按开始时间的 24 小时分布、高峰时段。
3. **数据来源**：`duty_record` 表；按人员和年份过滤。
4. **计算指标**：时长 = 结束 - 开始；天数 = 不同日期数；按月/按小时分组。
5. **空数据**：没有记录时返回 0 或空列表；空数据不是异常。
6. **统计口径与数据校验**：同一天多条记录算 1 天；跨月按开始时间归月；按开始小时计数。
7. **结果核对**：用 3 条记录手算，和接口结果对比。
8. **扩展**：贡献度排名、节假日统计、天气统计（课后）。

## 三、重点与难点

**重点**

- 从 `duty_record` 查数据。
- 年度统计：总天数、总时长、月度分布。
- 时段分布：按小时计数。
- 统计口径与结果核对。

**难点**

- 时长计算和天数去重。
- 按月/按小时分组。
- 空数据与统计口径。

## 四、学情分析与教学策略

学生已经完成执勤记录的列表和新增，知道 `duty_record` 的字段。本课次把"记录"变成"统计"：

- 不写新表，只查 `duty_record`；
- 用循环累加，不用复杂 SQL；
- 先算总数，再按月/按小时分组；
- 只做两个统计，不贪多。

策略：

- **先手算，再写代码**：用 3 条记录手算总天数/总时长，再写循环；
- **一个指标一个函数**：年度统计、时段分布分开写；
- **空数据先测**：先测没有记录的情况，返回 0/空，不是异常；
- **统一异常/事务不在这里**：放课次14；
- **扩展放课后**：贡献度排名等不占课堂。

## 六、教学过程

### 环节1：导入与任务说明（5 分钟）

**教师展示**

- 打开 duty 的数据统计页：KPI 卡、时间分布图、月度图。
- 说明这些数字从哪里来。

**任务**

> 今天做两个统计接口：
> 1. `GET /analytics/staff-duty-yearly`：某人某年的总天数、总时长、月度分布；
> 2. `GET /analytics/duty-time-distribution`：某人某年的 24 小时分布、高峰时段。

**验收标准**

- 有记录时返回正确数字；
- 无记录时返回 0/空，不报 500；
- 年份格式错 → 400；
- 人员不存在 → 400。

---

### 环节2：统计需求与数据来源（10 分钟）

**教师讲清两个口径**

| 指标 | 怎么算 |
|---|---|
| 总值班天数 | 不同日期的个数（同一天多条算 1 天） |
| 总值班时长 | 每条记录 `结束 - 开始`，再累加 |
| 月度分布 | 按 `start_time.month` 分组，累加天数和时长 |
| 时段分布 | 按 `start_time.hour` 分组，计数 |

**数据来源**

```python
records = db.query(DutyRecord).filter(
    DutyRecord.personnel_certificate_number == cert,
    extract("year", DutyRecord.start_time) == int(year),
).all()
```

**强调**

- 统计口径要先说清，再写代码；
- 同一天多条记录，天数只算 1 天；
- 时段分布按"开始时间的小时"计数（简化口径）。

---

### 环节3：年度统计（25 分钟）

**教师先手算**

给 3 条记录，让学生算：总天数、总时长、各月天数。

**教师演示**

```python
total_hours = 0.0
days = set()
monthly = {m: {"days": 0, "hours": 0} for m in range(1, 13)}

for r in records:
    hours = (r.end_time - r.start_time).total_seconds() / 3600
    total_hours += hours
    days.add(r.start_time.date())
    m = r.start_time.month
    monthly[m]["days"] += 1
    monthly[m]["hours"] += hours

return {
    "personnel_certificate_number": cert,
    "year": year,
    "total_duty_days": len(days),
    "total_duty_hours": round(total_hours, 2),
    "duty_by_month": [
        {"month": m, "days": monthly[m]["days"], "hours": round(monthly[m]["hours"], 2)}
        for m in range(1, 13)
    ],
}
```

**学生任务**

- 写年度统计 service；
- 用有记录的人员测试；
- 核对总天数、总时长、月度数字。

**强调**

- 天数用 `set` 去重；
- 时长用 `total_seconds() / 3600`；
- 月度要补齐 12 个月（没有记录的月份返回 0）。

---

### 环节4：时段分布（20 分钟）

**教师演示**

```python
hour_counts = {h: 0 for h in range(24)}
for r in records:
    hour_counts[r.start_time.hour] += 1

max_count = max(hour_counts.values()) if records else 0
peak_hours = [h for h, c in hour_counts.items() if c == max_count] if max_count else []

return {
    "year": year,
    "personnel_certificate_number": cert,
    "time_distribution": [{"hour": h, "count": c} for h, c in hour_counts.items()],
    "peak_hours": peak_hours,
    "total_records": len(records),
}
```

**学生任务**

- 写时段分布 service；
- 测试：有记录、无记录；
- 检查高峰时段是否和手算一致。

**强调**

- 24 个小时都要返回，没有记录的小时返回 0；
- 高峰时段可能有多个；
- 无记录时高峰时段为空列表。

---

### 环节5：空数据与输入检查（15 分钟）

**教师演示**

1. **无记录**：返回 0/空列表，不报 500；
2. **年份格式错**：`year` 不是 4 位数字 → 400；
3. **人员不存在**：查一下人员表，没有 → 400。

**参考代码**

```python
if len(year) != 4 or not year.isdigit():
    raise HTTPException(status_code=400, detail="年份格式错误")

person = db.query(Personnel).filter(
    Personnel.certificate_number == cert
).first()
if not person:
    raise HTTPException(status_code=400, detail="人员不存在")
```

**强调**

- 统计接口最容易在"没数据"时 500；
- 先查人员，再查记录；
- 这里只做必要的输入检查；统一异常与事务放课次14。

---

### 环节6：测试与小结（15 分钟）

**测试清单**

- [ ] 有记录人员 → 数字正确；
- [ ] 无记录人员 → 0/空，不报错；
- [ ] 年份格式错 → 400；
- [ ] 人员不存在 → 400；
- [ ] 月度 12 项齐全；
- [ ] 时段 24 项齐全；
- [ ] 高峰时段正确。

**教师总结**

> 统计 = 查数据 + 算指标 + 处理空数据。
>
> 两个口径：按天/月、按小时。
>
> 统计是只读；统一异常与事务边界放课次14。
