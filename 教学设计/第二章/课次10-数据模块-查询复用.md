### 环节2：分页（20 分钟）

**教师讲授两个参数**

| 参数 | 默认 | 说明 |
|---|---|---|
| page | 1 | 第几页 |
| page_size | 10 | 每页几条，最大 100 |

**返回五个字段**

```json
{
  "items": [...],
  "total": 23,
  "page": 2,
  "page_size": 10,
  "pages": 3
}
```

**教师演示**

```python
@router.get("/departments")
def list_departments(
    page: int = 1,
    page_size: int = 10,
    db: Session = Depends(get_db),
):
    page = max(page, 1)
    page_size = min(max(page_size, 1), 100)

    query = db.query(Department)
    total = query.count()
    items = query.offset((page - 1) * page_size).limit(page_size).all()
    pages = (total + page_size - 1) // page_size

    return {
        "items": items,
        "total": total,
        "page": page,
        "page_size": page_size,
        "pages": pages,
    }
```

**学生任务**

- 给 dept 列表加分页；
- 用 `page=1/2`、`page_size=5` 测试；
- 检查 `total`、`pages` 是否正确。

**强调**

- `offset = (page - 1) * page_size`；
- `pages = ceil(total / page_size)`；
- `page` 不能小于 1，`page_size` 不能太大。

### 环节5：抽取通用 CRUD 基类（20 分钟）

**教师提问**

> "dept 和 personnel 的 `get`、分页列表、`create` 几乎一样，能不能只写一次？"

**教师演示（最小版本）**

```python
class CRUDBase:
    def __init__(self, model, pk: str = "id"):
        self.model = model
        self.pk = pk

    def get(self, db, obj_id):
        return db.query(self.model).filter(getattr(self.model, self.pk) == obj_id).first()

    def get_multi(self, db, page: int = 1, page_size: int = 10):
        page = max(page, 1)
        page_size = min(max(page_size, 1), 100)
        query = db.query(self.model)
        total = query.count()
        items = query.offset((page - 1) * page_size).limit(page_size).all()
        pages = (total + page_size - 1) // page_size
        return {
            "items": items,
            "total": total,
            "page": page,
            "page_size": page_size,
            "pages": pages,
        }

    def create(self, db, data):
        obj = self.model(**data.model_dump())
        db.add(obj)
        db.commit()
        db.refresh(obj)
        return obj
```

**使用**

```python
dept_crud = CRUDBase(Department, pk="dept_code")
personnel_crud = CRUDBase(Personnel, pk="certificate_number")
```

**学生任务**

- 把 dept、personnel 里重复的 `get`、分页列表、`create` 换到 `CRUDBase`；
- 两个模块各自保留自己的业务校验（查重、部门存在）；
- 回归测试：两个模块的列表、详情、新增都还能用。

> 若你的 crud 还是函数，先把这三个函数包成一个类，再用 `CRUDBase`；不要求一次改完，先改 dept 一个模块。

**强调**

- 基类只放"完全重复"的通用操作；业务规则留在各自 service；
- 主键不一定是 `id`：dept 用 `dept_code`，personnel 用 `certificate_number`，基类要能指定主键；
- 先有重复，再抽基类；不要一上来就设计大而全的框架；
- duty 的 `app/core/base_crud.py` 是完整版（含泛型、日志、回滚），课堂只看最小版本；
- 抽完必须回归测试，避免改坏原有功能。
