# 第四章 软件部署与系统交付 · 教学说明

> 对应课程专题四（12 学时：理论 2 + 实践 10），共 4 个课次（课次23–26）。
> 教材对应：第18章《容器化基础》、第19章《服务部署与编排》、第20章《运维、监控与交付》。
> 主线项目：值班数据统计系统后端 `duty` 与前端 `duty_frontend` 的容器化部署。

## 一、本章定位

前三个专题解决了"做得出来"：需求、后端、前端都已完成。本章解决"交得出去"——把 `duty` 和 `duty_frontend` 打包成镜像，让它们在任意一台装了 Docker 的机器上以同样的方式运行，最后用 Compose 一键启动，并能通过日志和健康检查排查问题。

本章结束时，学生应能：

- 读懂并修改 `duty/Dockerfile`、`duty_frontend/Dockerfile`；
- 独立构建后端、前端镜像，并用容器跑起来；
- 用环境变量、端口映射和容器网络把前后端连通；
- 用 `docker-compose.yml` 编排两个服务；
- 按"端口 → 网络 → 环境变量 → 日志"的顺序排查部署问题；
- 写出一份可执行的部署文档。

## 二、理论课与实践课的分工

| 课次 | 类型 | 定位 | 与 duty 的关系 | 是否动手构建 |
|---|---|---|---|---|
| 23 Docker基础 | 理论 | 容器与虚拟机、镜像/容器/仓库、镜像分层、Dockerfile 指令、部署流程 | 以 `duty/Dockerfile` 为读本，演示为主 | 否（只看不建） |
| 24 Docker打包与测试 | 实践 | 编写后端/前端 Dockerfile、构建镜像、运行容器、体积优化 | 后端、前端各自构建并单独运行 | 是（两个镜像） |
| 25 前后端服务部署 | 实践 | 端口映射、容器网络、环境变量、数据持久化、前后端联通 | 两个容器放进同一网络打通登录与列表 | 是（部署与联调） |
| 26 软件部署综合实践 | 实践 | Compose 编排、健康检查、日志排查、部署文档与验收 | 用 `docker-compose.yml` 一键启动整套系统 | 是（编排） |

**进度原则**：

- **23 先建立概念**：只在教师演示中"看见"容器，不要求完整构建；
- **24 先单个跑通**：先后端、再前端，各自能构建、能运行、能访问；
- **25 再连起来**：用自定义网络和环境变量把两个容器打通；
- **26 最后收口**：用 Compose 固化配置，补上排障、日志与部署文档。

**23/24/25/26 的边界**：

- 23 讲"是什么、为什么、Dockerfile 怎么写"，不重复第 24 课的构建实操；
- 24 只做"单镜像能构建、能运行、能访问"，**不解决前后端联通**；
- 25 只做"两个容器手工部署 + 环境变量 + 自定义网络"，**Compose 放 26**；
- 26 只做"编排、排障、文档、验收"，不重讲 Dockerfile 语法。

**与考核的衔接**：

- 专题四形成性成果为"容器化部署 + 部署文档"，权重 5%；
- 项目答辩与终结性考核不占 80 学时，于课次26 之后另行安排；
- 课次26 负责整理提交物与答辩材料，不把答辩内容挤进正课。

## 四、参考实现

- 后端镜像：`项目参考/duty/Dockerfile`（Python 3.12 slim，端口 8000，`python main.py`）
- 前端镜像：`项目参考/duty_frontend/Dockerfile`（Streamlit，端口 8501，`--server.headless=true`）
- 构建排除：`项目参考/duty/.dockerignore`、`项目参考/duty_frontend/.dockerignore`
- 环境变量：`项目参考/duty/.env.example`（`DATABASE_URL`、`SECRET_KEY`、`ALGORITHM`、`DEBUG`）
- 编排文件：`项目参考/docker-compose.yml`（`backend` + `frontend`，健康检查与 `depends_on`）
- 关键代码：
  - `duty/main.py`：`/health` 返回 `{"status":"healthy"}`；`X-Process-Time` 响应头
  - `duty/app/core/logger.py`：`logs/app.log`、`logs/error.log`、`logs/sql.log`
  - `duty_frontend/config.py`：`DUTY_API_BASE_URL` 环境变量，默认 `http://127.0.0.1:8000`

## 五、教学准备总清单

- Docker Desktop / Docker Engine 可运行，`docker version`、`docker compose version` 正常。
- 预拉取 `python:3.12.9-slim` 或课程约定的同款基础镜像（内网环境提前准备离线镜像）。
- `duty`、`duty_frontend` 完整代码，且本机直接运行可登录。
- `docker-compose.yml`、两个 Dockerfile、两个 `.dockerignore`、`.env.example` 的投影。
- 端口 8000、8501 空闲；测试账号 `admin/admin123`。
- 数据与日志目录：`duty/logs/`、部署时新建的 `data/`。
- 部署文档模板、验收清单、故障演练清单。
- 计时器；分组（4–6 人/组）。

## 六、与前后章节的衔接

## 七、无 AI 环境说明

本章不依赖 AI：

- 23 以讲授、演示、读 Dockerfile 为主；
- 24–25 以参考 Dockerfile 为模板，学生"照抄 → 改 → 构建 → 验证"；
- 26 以编排文件阅读、故障演练、文档编写为主；
- AI 仅作为可选辅助（如解释报错），不进入必须环节。
