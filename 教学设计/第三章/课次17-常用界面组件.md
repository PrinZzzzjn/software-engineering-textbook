## 二、教学目标

**知识与技能**

- 能使用输入类组件：`st.text_input`、`st.number_input`、`st.selectbox`、`st.date_input`、`st.form`。
- 能使用展示类组件：`st.dataframe`、`st.table`、`st.metric`、`st.json`。
- 能使用交互类组件：`st.button`、`st.checkbox`、`st.slider`、`st.file_uploader`、`st.download_button`。
- 能用 `column_config` 把表格列改成中文表头、格式化日期/数字。
- 能把重复的表格、表单抽成函数复用。
- 能用假数据做出"部门管理页"：列表 + 搜索 + 新增表单。

**过程与方法**

- 经历"先静态展示 → 再加交互 → 再抽复用"的过程。
- 学会用假数据先验证界面，再接后端。

**情感态度与价值观**

- 建立"组件是为用户服务的"意识。
- 养成"先能看、再能点、最后复用"的习惯。

## 教学内容

> 对应教学计划：专题三基本内容第 2 条"常用界面组件"。

1. **输入类组件**：`st.text_input`、`st.number_input`、`st.selectbox`、`st.date_input`、`st.form`。
2. **展示类组件**：`st.dataframe`、`st.table`、`st.metric`、`st.json`。
3. **交互类组件**：`st.button`、`st.checkbox`、`st.slider`、`st.file_uploader`、`st.download_button`。
4. **表格列配置**：`column_config`——中文表头、日期格式、数字格式、列宽。
5. **组件组合与自定义**：把重复的表格/表单抽成函数。
6. **案例**：部门管理页的"列表 + 搜索 + 新增表单"，**先用假数据**，不接后端。

## 三、重点与难点

**重点**

- 表单 `st.form` 与输入组件。
- 表格 `st.dataframe` 与 `column_config`。
- 组件组合与复用。

**难点**

- 表单提交与页面重跑。
- 表格列配置的写法（日期类型、列宽、隐藏列）。
- 把组件抽成可复用函数。

## 四、学情分析与教学策略

学生已经知道 Streamlit 能跑页面，但没有系统用过组件。零基础学生容易被"组件太多"吓到。

策略：

- **先静态、后交互**：先显示表格，再加搜索/按钮；
- **一次只学一类**：输入、展示、交互分开；
- **假数据**：不接后端，避免联调干扰；
- **抄参考实现**：以 `duty_frontend` 部门页为样板，先复现再改；
- **复用只抽一次**：只抽"表格 + 分页"这一处，不追求完整组件库。

## 五、教学准备

- Streamlit 环境可用（`duty_frontend` 虚拟环境或独立练习目录）。
- 假数据：10–20 条部门数据（`dept_code`、`full_name`、`address`、`created_at`）。
- 组件速查表（输入/展示/交互/表格配置）。
- `duty_frontend` 部门管理页截图或代码。
- 不需要启动后端。

### 环节2：输入类组件（30 分钟）

**教师演示**

```python
import streamlit as st

full_name = st.text_input("部门名称", placeholder="输入关键字后回车")
page_size = st.number_input("每页条数", min_value=5, max_value=50, value=10, step=5)
sort_by = st.selectbox("排序字段", ["dept_code", "full_name", "created_at"])
created_at = st.date_input("成立日期")
```

**讲清四个组件**

| 组件 | 用途 | 关键参数 |
|---|---|---|
| `st.text_input` | 单行文本 | `placeholder`、`value`、`type="password"` |
| `st.number_input` | 数字 | `min_value`、`max_value`、`step` |
| `st.selectbox` | 单选下拉 | 选项列表、`index` |
| `st.date_input` | 日期 | `value`、`min_value`、`max_value` |

**引入表单**

```python
with st.form("create_dept", clear_on_submit=True):
    col1, col2 = st.columns(2)
    with col1:
        dept_code = st.text_input("部门编码 *", placeholder="例如 1001")
    with col2:
        full_name = st.text_input("部门名称 *")
    address = st.text_input("地址")
    submitted = st.form_submit_button("提交")
```

**讲清 `st.form` 的意义**

- 不用表单时，每输入一个字符都可能触发一次重跑；
- 用表单后，只有点"提交"才重跑一次；
- `clear_on_submit=True`：提交成功后自动清空输入。

**强调**

> 表单把多个输入"攒在一起"提交，既减少重跑，也让"提交"这个动作更明确。

**学生任务（10 分钟）**

把四个输入组件放进一个表单，点提交后打印出输入值：

```python
if submitted:
    st.write(dept_code, full_name, address)
```

### 环节3：展示类组件与表格（35 分钟）

**教师准备假数据**

```python
import pandas as pd

departments = [
    {"dept_code": "1001", "full_name": "指挥中心", "address": "1 号楼", "created_at": "2025-01-06"},
    {"dept_code": "1002", "full_name": "保障部", "address": "2 号楼", "created_at": "2025-02-11"},
    {"dept_code": "1003", "full_name": "通信科", "address": "3 号楼", "created_at": "2025-03-02"},
]

df = pd.DataFrame(departments)
```

**演示四种展示组件**

```python
st.dataframe(df, width="stretch", hide_index=True)

st.table(df.head(3))

st.metric("部门总数", len(df), delta="本月新增 2 个")

st.json({"total": len(df), "items": departments})
```

**对比 `dataframe` 与 `table`**

| 组件 | 特点 | 适合 |
|---|---|---|
| `st.dataframe` | 可排序、可滚动、可交互 | 数据列表 |
| `st.table` | 静态展示，全部铺开 | 少量汇总数据 |
| `st.metric` | 一个大数字 + 说明 | 关键指标 |
| `st.json` | 结构化展示 JSON | 调试接口返回 |

**强调**

- 列表页优先用 `st.dataframe`，不要用 `st.table` 铺几十行；
- `hide_index=True` 隐藏 Pandas 自带的行号；
- `width="stretch"` 让表格填满容器。

**学生任务（15 分钟）**

- 准备 10 条假数据；
- 用 `st.dataframe` 显示；
- 在表格上方用 `st.metric` 显示"部门总数"。

### 环节4：交互类组件与表单（35 分钟）

**教师演示**

```python
if st.button("查询"):
    st.write("按关键字查询")

only_with_address = st.checkbox("只看有地址的部门")

top_n = st.slider("显示前 N 条", min_value=1, max_value=len(df), value=min(5, len(df)))

uploaded = st.file_uploader("导入部门 CSV", type=["csv"])

st.download_button(
    "导出 CSV",
    data=df.to_csv(index=False).encode("utf-8-sig"),
    file_name="departments.csv",
    mime="text/csv",
)
```

**讲清交互组件与"重跑"的关系**

- `st.button` 返回 `True` 只在点击的那一次重跑中成立；
- `st.checkbox`、`st.slider` 的值变化也会触发重跑；
- 所以"点击后执行的代码"要放在 `if st.button(...):` 里面。

**把交互接回列表**

```python
keyword = st.text_input("部门名称", placeholder="输入关键字")
filtered = df[df["full_name"].str.contains(keyword)] if keyword else df
if only_with_address:
    filtered = filtered[filtered["address"].notna()]
st.dataframe(filtered.head(top_n), width="stretch", hide_index=True)
```

**强调**

- 先过滤、再显示，不要把所有逻辑堆在页面末尾；
- 上传/下载是"加分项"，今天知道怎么用即可；
- 交互组件的 `key` 在同一个页面里不能重复。

**学生任务（15 分钟）**

- 加一个搜索框，按 `full_name` 过滤；
- 加一个复选框，过滤掉没有地址的部门；
- 加一个"导出 CSV"按钮。

### 环节5：表格列配置 `column_config`（25 分钟）

**教师演示**

```python
dept_config = {
    "dept_code": st.column_config.TextColumn("部门编码", width="small"),
    "full_name": st.column_config.TextColumn("部门名称"),
    "address": st.column_config.TextColumn("地址"),
    "created_at": st.column_config.DateColumn("成立日期", format="YYYY-MM-DD"),
}

display_df = df.copy()
display_df["created_at"] = pd.to_datetime(display_df["created_at"])

st.dataframe(
    display_df,
    width="stretch",
    hide_index=True,
    column_config=dept_config,
)
```

**讲清三件事**

1. `column_config` 是一个字典：键是原字段名，值告诉 Streamlit"这一列怎么显示"；
2. `TextColumn`、`DateColumn`、`NumberColumn` 是最常用的三种；
3. 日期列要先转成日期类型，否则 `DateColumn` 格式化不生效。

**常用配置**

| 配置 | 作用 |
|---|---|
| `TextColumn("中文名")` | 改表头 |
| `width="small"` | 控制列宽 |
| `DateColumn(..., format="YYYY-MM-DD")` | 日期格式 |
| `NumberColumn(..., format="%d")` | 数字格式 |
| `None` | 隐藏该列 |

**常见问题**

| 现象 | 原因 |
|---|---|
| 表头还是英文 | `column_config` 的键和字段名不一致 |
| 日期显示成一串数字 | 没转成 `datetime` |
| 列没显示 | 字段不在 DataFrame 里，或配置成了 `None` |

**学生任务（15 分钟）**

给 5 列都配置中文表头；把 `created_at` 格式化为 `YYYY-MM-DD`；隐藏 `address` 列再恢复。

### 环节6：组件组合与复用（20 分钟）

**教师展示重复代码**

```python
# 部门列表
st.dataframe(pd.DataFrame(dept_rows), width="stretch", hide_index=True, column_config=dept_config)

# 人员列表：几乎一样
st.dataframe(pd.DataFrame(person_rows), width="stretch", hide_index=True, column_config=person_config)
```

**抽成函数**

```python
def render_table(items, column_config=None):
    """把一组字典渲染成表格；空数据时给提示。"""
    if not items:
        st.info("暂无数据")
        return
    st.dataframe(
        pd.DataFrame(items),
        width="stretch",
        hide_index=True,
        column_config=column_config,
    )
```

**再抽表单**

```python
def dept_form():
    """渲染新增部门表单，返回 (是否提交, 数据字典)。"""
    with st.form("create_dept", clear_on_submit=True):
        col1, col2 = st.columns(2)
        with col1:
            dept_code = st.text_input("部门编码 *", placeholder="例如 1001")
        with col2:
            full_name = st.text_input("部门名称 *")
        address = st.text_input("地址")
        submitted = st.form_submit_button("提交")

    return submitted, {
        "dept_code": dept_code.strip(),
        "full_name": full_name.strip(),
        "address": address.strip() or None,
    }
```

**强调**

- 抽函数的标准：**同样的代码出现第二次**；
- 函数只负责"显示/收集"，不要把业务逻辑塞进去；
- 抽完必须再跑一遍，确认输出没变。

**学生任务（10 分钟）**

把表格抽成 `render_table`，分别渲染"部门"和"人员"两组假数据。

### 环节7：案例整合——假数据部门管理页（20 分钟）

**教师说明**

> 为了让"新增"在当前会话里看得见，先把假数据放进 `st.session_state`。
> 正式的状态管理在课次20 讲，这里只借用一下。

```python
if "departments" not in st.session_state:
    st.session_state.departments = departments

keyword = st.text_input("部门名称", placeholder="输入关键字")
submitted, data = dept_form()

if submitted:
    if not data["dept_code"] or not data["full_name"]:
        st.error("部门编码和部门名称不能为空")
    elif any(d["dept_code"] == data["dept_code"] for d in st.session_state.departments):
        st.error("部门编码已存在")
    else:
        st.session_state.departments.append(
            {**data, "created_at": "2025-09-01"}
        )
        st.success("新增成功")

rows = st.session_state.departments
if keyword:
    rows = [d for d in rows if keyword in d["full_name"]]

render_table(rows, column_config=dept_config)
```

## 七、板书设计

```
组件三类：
  输入：text_input / number_input / selectbox / date_input / form
  展示：dataframe / table / metric / json
  交互：button / checkbox / slider / file_uploader / download_button

表格：
  st.dataframe(df, hide_index=True, column_config=...)
  column_config = {字段: TextColumn("中文名"), ...}
  日期列先 pd.to_datetime

表单：
  with st.form(...): 多个输入 → 一次提交
  减少了逐字符重跑

复用：
  同样代码出现第二次 → 抽函数
  render_table(items, column_config)
```
