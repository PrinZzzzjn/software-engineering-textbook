# 第三章 前端界面构建 · 教学说明

> 对应课程专题三（26 学时：理论 2 + 实践 24），共 7 个课次（课次16–22）。
> 教材对应：第13章 Streamlit 与前端基础、第14章 常用组件、第15章 前后端联调、
> 第16章 数据可视化与仪表盘、第17章 前端体验优化。
> 主线项目：值班数据统计系统前端 `duty_frontend`（基础版 / 美化版参考实现）。

## 一、本章定位

后端已经能提供接口，本章解决"**用户怎么看到、怎么使用**"的问题。学生从"能跑一个页面"开始，逐步完成登录、部门管理、数据统计三个页面，最后做视觉优化与整体联调。

## 二、理论课与实践课的分工

| 课次 | 类型 | 定位 | 是否接后端 |
|---|---|---|---|
| 16 前端开发框架基础 | 理论 | 前端技术栈、Streamlit 架构与事件模型、单页布局、设计原则、适用边界 | 否 |
| 17 常用界面组件 | 实践 | 输入/展示/交互组件、表格列配置、组件复用 | 否（假数据） |
| 18 前端页面设计 | 实践 | 项目结构、多页面、导航、页面区域规划、守卫、响应式 | 否（空壳页） |
| 19 数据读取与展示 | 实践 | API 调用、token、加载状态、数据传递 | 是 |
| 20 数据编辑与页面状态 | 实践 | 新增/编辑/删除、列表刷新、分页/筛选状态、session_state | 是 |
| 21 前端视觉优化与数据仪表盘 | 实践 | 主题、卡片、指标卡、图表、仪表盘 | 是（统计接口） |
| 22 前端开发综合实践 | 实践 | 常见问题、整体联调、成果整理 | 是 |

**进度原则**：

- **16–18 先不接后端**：先用假数据和空壳页，把"界面怎么组织、组件怎么用"搞清楚；
- **19–20 再接后端**：统一用 `api_client.py` / `auth.py` 参考实现；
- **21 做视觉**：用基础版 → 美化版对比；
- **22 整合**：把登录、部门、统计三页串起来。

**16/17/18 的边界**：

- 16 讲"一个页面怎么运行、怎么摆"：框架、事件模型、单页布局、设计原则、适用边界；
- 17 讲"页面里用什么组件"：输入/展示/交互、表格配置、组件复用；
- 18 讲"多个页面怎么组织"：项目结构、`pages/`、导航、页面区域规划、守卫、响应式。

三节课不重复同一层内容；18 直接引用 16 的布局和 17 的组件，不再重讲。

**19/20/22 的边界**：

- 19 **读路径**：登录、拿 token、调列表、显示数据、加载状态；
- 20 **写路径**：新增/编辑/删除、列表刷新、分页/筛选状态、`session_state`；
- 22 **异常路径**：401/403/404/422/500 排查、统一错误处理、整体联调、成果展示。

20 只做表单级基本提示（422 缺字段、400 重复）；401/403/500 的深入处理放 22。

## 四、参考实现

- 美化版：`项目参考/duty_frontend/`（青绿主题、卡片化、tabs、column_config、KPI、图表）
- 基础版：`项目参考/duty_frontend_basic/`（课次21 对比素材）
- 关键文件：
  - `app.py`：入口、登录门禁、首页
  - `auth.py`：登录、登出、页面守卫
  - `api_client.py`：统一请求、Bearer token、401 处理
  - `pages/1_部门管理.py`：CRUD 样板
  - `pages/2_数据统计.py`：指标卡 + 两张图
  - `ui.py`：主题色、CSS、Hero、卡片
- 后端接口：`duty`（`http://localhost:8000`，`/docs`）

## 五、教学准备总清单

- duty 后端可运行；`/docs` 可用。
- Streamlit 前端虚拟环境（`duty_frontend/.venv`）与依赖。
- 基础版、美化版参考实现。
- 假数据：部门列表、人员列表（课次17 用）。
- 页面骨架模板：`app.py` + `pages/` 空页（课次18 用）。
- `api_client.py`、`auth.py` 参考（课次19–20 用）。
- 测试账号：管理员、普通用户。

## 六、与前后章节的衔接

- 第二章的接口（登录、部门、人员、执勤记录、统计）→ 本章 19–22 直接调用；
- 课次21 的仪表盘 → 使用第二章的两个统计接口；
- 课次22 的成果 → 专题四部署（前后端一起打包上线）。

## 七、无 AI 环境说明

本章不依赖 AI：

- 16 理论课以演示和讲解为主；
- 17–18 用假数据和空壳页，先不接后端；
- 19–22 以参考实现为模板，学生"改 → 扩 → 调"；
- AI 仅作为可选辅助，不进入必须环节。
