## 二、教学目标

**知识与技能**

- 能用 `.streamlit/config.toml` 配置主题色、背景色、字体。
- 能用 `st.container(border=True)` 做卡片化布局。
- 能用 `st.metric` 做 KPI 指标卡。
- 能用 `st.line_chart` / `st.bar_chart` 画图，并设置颜色。
- 能说出图表类型的选择：比较用柱状、趋势用折线、占比用饼图。
- 能搭建一个数据仪表盘：4 个指标卡 + 2 张图。
- 能对比基础版与美化版，说明差异。

**过程与方法**

- 经历"看基础版 → 看美化版 → 找差异 → 自己改"的过程。
- 学会用"布局、配色、信息层级"解释视觉优化。

**情感态度与价值观**

- 建立"美观是为了更好用"的意识。
- 养成"配色一致、信息有层级"的习惯。

## 教学内容

> 对应教学计划：专题三基本内容第 6 条"前端视觉优化与数据仪表盘"。

1. **主题配置与样式定制**：`.streamlit/config.toml`；主色、背景、字体。
2. **卡片化布局**：`st.container(border=True)`；分组与留白。
3. **指标卡**：`st.metric`；图标、数值、边框。
4. **数据可视化与图表绘制**：折线、柱状；颜色与坐标。
5. **数据仪表盘的构建**：指标卡 + 时间分布图 + 月度图。
6. **界面美观性与易用性的平衡**：基础版 → 美化版对比；哪些改动提升体验，哪些只是装饰。

## 三、重点与难点

**重点**

- 主题配置。
- `st.metric` 指标卡。
- 两张图的绘制与布局。

**难点**

- 图表类型与数据的匹配。
- 配色一致性（界面色、图表色）。
- 仪表盘的信息层级与留白。

## 四、学情分析与教学策略

学生已经能接后端、做 CRUD。本课次从"能用"走向"好用"：

- 用基础版/美化版对比，先看到差异；
- 只加 4 类改动：主题、卡片、指标卡、图表；
- 不追求复杂 CSS，避免"好看靠魔法"。

策略：

- **对比先行**：先看两个版本，再说改了什么；
- **一次一类**：主题 → 卡片 → 指标 → 图表；
- **配色少而稳**：一个主色 + 一个图表色；
- **数据说话**：指标卡和图表来自真实统计接口。

## 五、教学准备

- 基础版、美化版 `duty_frontend`。

### 环节2：主题配置（25 分钟）

**教师展示 `.streamlit/config.toml`**

```toml
[theme]
primaryColor = "#0F766E"
backgroundColor = "#F8FAFC"
secondaryBackgroundColor = "#FFFFFF"
textColor = "#0F172A"
font = "sans serif"

[browser]
gatherUsageStats = false
```

**讲清四个颜色**

| 配置 | 作用 | 本课取值 |
|---|---|---|
| `primaryColor` | 按钮、链接、选中态 | 青绿 `#0F766E` |
| `backgroundColor` | 页面底色 | 浅灰白 `#F8FAFC` |
| `secondaryBackgroundColor` | 卡片、侧边栏底色 | 纯白 `#FFFFFF` |
| `textColor` | 正文颜色 | 深蓝黑 `#0F172A` |

**讲清三条原则**

1. **一个主色**：全站只用一个主色，按钮、选中态、图表都用它或它的邻近色；
2. **底色和卡片分开**：页面浅灰、卡片纯白，层次自然出来；
3. **对比度够**：正文与背景对比要清楚，不能"浅灰字配白底"。

**强调**

- 改完 `config.toml` 要重启 Streamlit 才生效；
- 主色不要超过一个，否则页面会"花"；
- 主题能解决 80% 的视觉问题，不需要一上来写 CSS。

**学生任务（10 分钟）**

- 复制参考配置，改成自己的主色；
- 重启应用，观察按钮、链接、选中态的变化；
- 把主色改成红色再改回来，体会"主色统一"的影响。

### 环节3：卡片化布局（25 分钟）

**教师演示**

```python
with st.container(border=True):
    st.subheader("筛选条件")
    col1, col2, col3 = st.columns([2, 1, 1])
    with col1:
        st.text_input("部门名称", placeholder="输入关键字")
    with col2:
        st.selectbox("排序字段", ["create_time", "full_name", "dept_code"])
    with col3:
        st.selectbox("排序方式", ["desc", "asc"])
```

**再包内容区**

```python
with st.container(border=True):
    st.subheader("部门列表")
    st.dataframe(df, width="stretch", hide_index=True)
```

**讲清卡片的作用**

- 把"一类内容"装进一个框，视觉上形成分组；
- 卡片之间留白，信息不再挤在一起；
- 不需要写 CSS，`border=True` 就有边框和内边距。

**讲清"分组"的粒度**

| 分组方式 | 适合 |
|---|---|
| 筛选区一张卡片 | 查询条件较多 |
| 列表区一张卡片 | 表格、分页 |
| 操作区一张卡片 | 新增、编辑、删除 |
| `st.tabs` 分区 | 列表/新增/编辑三块并列 |

**强调**

- 卡片不是越多越好，一屏 3–4 张就够；
- 同类内容才放同一张卡片；
- 卡片里不要再套卡片，层次会乱。

**学生任务（10 分钟）**

把部门页拆成"筛选卡片 + 列表卡片 + 操作卡片"，截图对比改前改后。

### 环节4：指标卡 `st.metric`（30 分钟）

**教师演示**

```python
m1, m2, m3, m4 = st.columns(4)

m1.metric("总值班天数", 18, icon="📅", border=True, format="%d")
m2.metric("总值班时长（小时）", 30.0, icon="⏱️", border=True, format="%.1f")
m3.metric("部门排名", 1, icon="🏅", border=True)
m4.metric("贡献度", "71.48%", icon="📈", border=True)
```

**讲清参数**

| 参数 | 作用 |
|---|---|
| 第一个位置参数 | 指标名称 |
| 第二个位置参数 | 指标值 |
| `icon` | 图标，帮助快速识别 |
| `border=True` | 加卡片边框 |
| `format` | 数字格式，如 `%d`、`%.1f` |
| `delta` | 与上期对比（可选） |

**讲清"指标卡选什么"**

- 选 3–5 个"一眼要看到"的数字；
- 每个数字都要有明确口径（如"总值班小时"）；
- 不要把明细表硬塞进指标卡。

**强调**

- 指标卡来自真实统计接口，不要手填假数字；
- 四个指标卡要横向对齐，用 `st.columns(4)`；
- 格式统一：天数整数、时长一位小数、百分比带 `%`。

**学生任务（15 分钟）**

用上一课次拿到的统计 JSON，做 4 个指标卡；确认数字与接口返回一致。

### 环节5：图表绘制（40 分钟）

**教师演示折线图**

```python
import pandas as pd
import streamlit as st

time_rows = distribution["time_distribution"]
df_time = pd.DataFrame(time_rows).set_index("hour")
df_time.index.name = "小时"

st.line_chart(df_time, y="count", color="#0D9488", height=260)
```

**演示柱状图**

```python
month_rows = yearly["duty_by_month"]
df_month = pd.DataFrame(month_rows).set_index("month")
df_month.index.name = "月份"

st.bar_chart(df_month, y="days", color="#0D9488", height=260)
```

**讲清数据形状**

- `st.line_chart` / `st.bar_chart` 要的是"表格"；
- 把 JSON 列表转成 `DataFrame`；
- 用 `set_index` 把"小时/月份"设为横轴；
- `y="count"` 指定纵轴用哪一列。

**图表类型选择**

| 目的 | 图表 | 例子 |
|---|---|---|
| 比大小 | 柱状图 | 每月值班天数 |
| 看趋势 | 折线图 | 24 小时值班分布 |
| 看占比 | 饼图/条形图 | 部门贡献度 |
| 看分布 | 直方图 | 值班时长分布 |

**讲清配色**

- 图表色用主色的邻近色（本课 `#0D9488`）；
- 同一页面只用一个图表色；
- 颜色是为了"看清"，不是为了"好看"。

**强调**

- 图表必须配标题和口径说明（"按值班开始时间的小时统计"）；
- 空数据要提示，不要画一张空图；
- 图表之外提供"查看数据表"，方便读屏和核对（无障碍）。

**学生任务（20 分钟）**

- 用教师给的统计 JSON，画一张折线图和一张柱状图；
- 给两张图各写一句口径说明；
- 在图表下方加 `st.expander("查看数据表")`。

**讲清仪表盘的三个层次**

1. **第一眼**：4 个指标卡，回答"总体怎么样"；
2. **第二眼**：两张图，回答"分布和趋势怎么样"；
3. **需要时**：数据表，回答"具体是多少"。

**强调**

- 信息层级从上到下：总览 → 趋势 → 明细；
- 两张图并排时，纵轴口径要写清楚；
- 空数据、加载失败都要有提示；
- 不要堆十几张图，一屏放不下就失去"仪表盘"的意义。

### 环节7：两版对比与小结（20 分钟）

**教师展示对比表**

| 改动 | 基础版 | 美化版 | 提升点 |
|---|---|---|---|
| 主题 | 默认色 | 青绿主色 + 浅灰底 | 统一、专业 |
| 分组 | 一长串 | 卡片 + tabs | 好找、不累 |
| 表头 | 英文 | 中文 + 日期格式 | 看得懂 |
| 指标 | 无 | 4 个指标卡 | 一眼看到重点 |
| 图表 | 无 | 折线 + 柱状 | 看出趋势 |
| 反馈 | 无 | toast | 操作有回应 |

**讲清"真提升"与"纯装饰"**

- 真提升：分组、中文表头、指标卡、图表、操作反馈；
- 纯装饰：过多渐变、花哨图标、无意义的动画；
- 判断标准：**是否帮助用户更快完成任务**。

**出口题（口头）**
